## واژه‌نامه‌ی سریع

| اصطلاح | معادل فارسی | یک‌خطی |
|---|---|---|
| Artificial Intelligence | هوش مصنوعی | هر سیستمی که کاری شبیه هوش انسان انجام دهد |
| Machine Learning | یادگیری ماشین | مدل از داده الگو یاد می‌گیرد، نه از قاعده‌ی دستی |
| Deep Learning | یادگیری عمیق | یادگیری ماشین با شبکه‌های عصبی چندلایه |
| Feature | ویژگی | ستون ورودی مدل |
| Label | برچسب | جواب درست در داده‌ی آموزشی |
| Model | مدل | تابعی با پارامترهای قابل تنظیم |
| Training | آموزش | تنظیم پارامترها برای کم کردن خطا |
| Loss | خطا | عددی که بدی پیش‌بینی را می‌سنجد |
| Overfitting | بیش‌برازش | حفظ کردن داده‌ی آموزش، شکست در داده‌ی جدید |
| Epoch | دور | یک بار عبور کامل از کل داده‌ی آموزش |
| Learning Rate | نرخ یادگیری | اندازه‌ی قدم در هر به‌روزرسانی |
| Validation Set | مجموعه‌ی اعتبارسنجی | داده‌ای برای تنظیم، جدا از آموزش و آزمون |
| Token | توکن | واحد کوچک متن (کلمه یا بخشی از کلمه) |
| LLM | مدل زبانی بزرگ | مدلی که توکن بعدی را پیش‌بینی می‌کند |
