# هوش مصنوعی برای برنامه‌نویس‌ها

کتابچه‌ای جامع و عملی برای برنامه‌نویس‌ها — از سواد پایه تا پیاده‌سازی قابلیت‌های AI در محصول. **تمرکز بر «استفاده از AI» است، نه ساخت مدل** — بدون نیاز به دانش ریاضی یا یادگیری ماشین.

## مخاطب

- برنامه‌نویس با هر سطحی، از «کمی آشنا» تا «متوسط»
- کسی که می‌خواهد هم برای بهره‌وری شخصی و هم برای ساخت قابلیت AI در محصول از LLM استفاده کند
- کسی که **نمی‌خواهد** دانشمند یادگیری ماشین شود — و می‌خواهد بداند چه چیزهایی را آگاهانه لازم نیست یاد بگیرد

## نحوه‌ی استفاده

1. از [فایل ۰۱](Article/AI/ai-for-programmers/01-Introduction.md) شروع کن — نقشه‌ی راه و آماده‌سازی محیط (۱۵ دقیقه).
2. هر فصل، **حداقل یک اجرای واقعی + یک تغییر آگاهانه در مثال** — خواندن منفعل کار نمی‌کند.
3. فایل ۱۱ (پروژه‌ی جامع) را حتماً بساز؛ بدون آن، کتابچه «خوانده شده» است نه «تمام شده».
4. سطح ۴ (فایل ۱۰) را رد نکن — مرزهای آگاهانه بخشی از مهارت است.
5. در پایان، [فایل ۱۲](12-Roadmap-and-Checklist.md): چک‌لیست خودارزیابی + برنامه‌ی هشت‌هفته‌ای.

مجموع: **۱۲ فایل، ۵۱ فصل، حدود ۴۱ ساعت مطالعه و تمرین.**

## قواعد ثابت کتابچه

- ابتدای هر فصل، برچسب سطح (۱ تا ۴) و توضیح پوشش آن.
- ساختار ثابت هر فصل: مقدمه، مفاهیم اساسی، مثال‌های عملی، مقایسه و الگوها، اشکال شایع، نکته‌ها، خلاصه.
- کدها کامل و قابل اجرا (Python / TypeScript)؛ **کلید API همیشه از متغیر محیطی**.
- منابع و مراجع در انتهای هر فایل.
- ارجاع متقابل بین فصل‌ها — هر مفهوم قبل از استفاده توضیح داده شده.
