# مبانی DevOps از صفر تا تولید

> راهنمای جامع مفاهیم، فرهنگ و بهترین روش‌ها — از اصول تا پیاده‌سازی

---

## این کتابچه چیست؟

یک دوره‌ی کامل و **مفهوم‌محور** درباره DevOps. برخلاف کتاب‌هایی که به مقایسه ابزارها می‌پردازند، این کتابچه **چرا** و **چگونه فکر کردن** را آموزش می‌دهد.

اگر ابزار عوض شود (و می‌شود)، اصول می‌مانند. این کتابچه روی اصول تمرکز دارد.

## ویژگی‌های این کتابچه

- **مفهوم‌محور، نه ابزارمحور** — اصول می‌مانند، ابزارها عوض می‌شوند
- **از ساده به پیچیده** — هر مفهوم قبل از استفاده توضیح داده شده
- **علت، نه فقط روش** — چرا این کار درست است
- **مثال‌های واقعی** — با عدد و شرایط
- **ضدالگوها** — چه کاری نکن و چرا
- **۱۲ تمرین عملی** — برای تثبیت یادگیری
- **چک‌لیست‌های قابل استفاده** — تیم، سازمان، SRE
- **واژه‌نامه ۸۰+ اصطلاح** — با معادل فارسی
