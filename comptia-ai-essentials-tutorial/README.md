# CompTIA AI Essentials — سواد هوش مصنوعی برای محیط کار

> از صفر تا استفادهٔ مؤثر، ایمن و مسئولانه از دستیارهای AI — مطابق با سرفصل‌های رسمی دوره و ساختار موضوعی منابع آمادگی

این مخزن یک کتابچهٔ آموزشی فارسی و تمرین‌محور برای دورهٔ **CompTIA AI Essentials** است. از «هوش مصنوعی چیست» شروع می‌شود و به نوشتن پرامپت، راستی‌آزمایی خروجی، حاکمیت، امنیت، حریم خصوصی و طراحی گردش‌کار با AI می‌رسد. هر فصل یک **سناریوی آزمایشگاهی (Lab Scenario)** واقعی دارد.

---

## این کتابچه برای چه کسی است؟

- **مبتدی کامل** — هیچ پیش‌نیاز فنی یا تجربهٔ قبلی در AI لازم نیست.
- **متخصص فناوری اطلاعات** که می‌خواهد بداند همکارانش با چه ابزارهایی کار می‌کنند و ریسک کجاست.
- **نقش غیرفنی** (بازاریابی، عملیات، طراحی، منابع انسانی، مالی) که می‌خواهد از AI واقعاً استفاده کند، نه فقط درباره‌اش بشنود.
- **مدیر یا سرپرست** که باید برای تیمش خط‌مشی و گردش‌کار تعریف کند.

## چطور بخوانم؟

**مسیر پیشنهادی (۶ هفته، هفته‌ای ۳ تا ۴ ساعت):**

```
هفته ۱: ۰۱–۰۲   (دوره چیست + مبانی)
هفته ۲: ۰۳–۰۴   (چطور یاد می‌گیرد + داده)
هفته ۳: ۰۵–۰۶   (مدل مولد + دستیارها)
هفته ۴: ۰۷–۰۹   (پرامپت + راستی‌آزمایی)   ← قلب دوره
هفته ۵: ۱۰–۱۳   (حاکمیت، مقررات، امنیت، حریم خصوصی)
هفته ۶: ۱۴–۱۸   (کسب‌وکار + آزمایشگاه + آمادگی ارزیابی)
```

**مسیرهای کوتاه:**

- **فقط برای ارزیابی:** ۰۱ → ۰۵ → ۰۶ → ۰۷ → ۰۹ → ۱۰ → ۱۲ → ۱۸
- **برای مدیر:** ۰۱ → ۱۰ → ۱۱ → ۱۲ → ۱۳ → ۱۴ → ۱۵
- **برای کار روزمره:** ۰۶ → ۰۷ → ۰۸ → ۰۹ → ۱۶
- **برای امنیت:** ۰۵ → ۱۲ → ۱۳ → ۱۱

## سلب مسئولیت

- این کتابچه منبع رسمی CompTIA نیست و وابستگی به آن ندارد. نام‌ها و علائم تجاری متعلق به صاحبانشان هستند.
- قیمت، مدت، کد دوره و محتوای ارزیابی ممکن است تغییر کنند؛ **صفحهٔ رسمی محصول ملاک است**.
- اعداد مربوط به وزن موضوعی از منابع آموزشی ثالث آمده‌اند و **رسمی نیستند**.
- مثال‌های امنیتی صرفاً دفاعی و آموزشی‌اند. هر آزمون نفوذ یا آزمایش حمله را فقط روی سیستم خودت یا با اجازهٔ کتبی انجام بده.
- هیچ بخشی از این کتابچه مشاورهٔ حقوقی نیست. برای انطباق با GDPR، EU AI Act یا مقررات محلی، با حقوق‌دان مشورت کن.
- پرامپت‌ها و سناریوها نمونه‌اند؛ قبل از استفاده در محیط کار، با خط‌مشی سازمان خودت تطبیق بده.
