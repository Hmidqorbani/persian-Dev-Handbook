# کتابچهٔ جامع DevOps از صفر تا تولید

راهنمای کامل CI/CD، ابر، کانتینر و SRE — از مبانی تا پروژه‌های واقعی.

## دربارهٔ این کتابچه

این مجموعه یک مسیر یادگیری کامل و مرحله‌به‌مرحله برای تبدیل‌شدن به یک مهندس DevOps حرفه‌ای است. محتوا از فرهنگ DevOps شروع می‌شود و تا ابزارهای پیشرفته (Kubernetes، Terraform، Prometheus، SRE، DevSecOps) ادامه می‌یابد. هر مفهوم با مثال‌های عملی و قابل اجرا همراه است و در پایان با پروژه‌های واقعی ترکیب می‌شود.

## مخاطب هدف

- **مبتدی:** کسی که با لینوکس، Git و یک زبان برنامه‌نویسی آشنایی مقدماتی دارد.
- **متوسط:** کسی که با بخشی از ابزارها کار کرده و می‌خواهد دانش خود را سیستماتیک کند.
- **حرفه‌ای:** کسی که می‌خواهد مفاهیم را عمیق‌تر بفهمد و به‌روز بماند.

## چطور از این کتابچه استفاده کنیم

1. **مطالعهٔ ترتیبی:** فایل‌ها را به ترتیب بخوانید؛ هر مفهوم پیش‌نیاز مفهوم بعدی است.
2. **تمرین عملی:** هر مثال را در محیط خود اجرا کنید. DevOps بدون دست‌های عملی یاد گرفته نمی‌شود.
3. **ساخت پروژه:** از همان ابتدا یک پروژهٔ کوچک شروع کنید و در طول کتابچه آن را کامل کنید.
4. **مرور با چیت‌شیت:** فایل ۲۸ برای مرور سریع.
5. **پروژهٔ نهایی:** فایل ۲۷ چهار پروژهٔ واقعی را گام‌به‌گام می‌سازد.

## پیش‌نیازها

- یک کامپیوتر با حداقل ۸ گیگابایت رم (برای اجرای کانتینرها و Kubernetes).
- آشنایی مقدماتی با خط فرمان لینوکس.
- Git نصب‌شده.
- یک حساب GitHub یا GitLab.
- (اختیاری) Docker Desktop یا Podman.
- (اختیاری) دسترسی به یک ابر (AWS/Azure/GCP) — بسیاری از مثال‌ها با tier رایگان کار می‌کنند.
