# 📚 Persian Dev Handbook
### مجموعه کتابچه‌ها و آموزش‌های جامع فارسی در دنیای برنامه‌نویسی، فناوری اطلاعات و هوش مصنوعی

**Persian Dev Handbook**:

 یک مجموعه آموزشی فارسی و ساختارمند است که با هدف جمع‌آوری، تدوین و ارائه آموزش‌های کاربردی در حوزه‌های مختلف فناوری ایجاد شده است.

در این مخزن تلاش شده مفاهیم از سطح مقدماتی تا پیشرفته، به زبان ساده اما با نگاه حرفه‌ای توضیح داده شوند؛ به‌گونه‌ای که هم برای افراد تازه‌وارد به دنیای فناوری مفید باشند و هم برای توسعه‌دهندگان و متخصصانی که قصد گسترش دانش و مهارت‌های خود را دارند.

این مجموعه شامل آموزش‌های برنامه‌نویسی، هوش مصنوعی، زیرساخت، لینوکس، شبکه، DevOps، ابزارهای توسعه و فناوری‌های مدرن است.

هدف این پروژه صرفاً آموزش مفاهیم نیست؛ بلکه کمک به ساخت یک مسیر یادگیری منظم، عمیق و کاربردی است.

---

## 🎯 اهداف پروژه

- ایجاد یک مرجع آموزشی فارسی برای حوزه‌های مختلف فناوری.
- ارائه آموزش‌های مرحله‌به‌مرحله از مقدماتی تا پیشرفته.
- توضیح مفاهیم پیچیده با زبانی ساده و قابل فهم.
- ترکیب مباحث تئوری با مثال‌های عملی و پروژه‌های واقعی.
- کمک به توسعه مهارت‌های فنی و تفکر مهندسی.
- فراهم کردن یک منبع رایگان برای یادگیری و مرور مطالب.
- ایجاد بستری برای مشارکت و توسعه مستمر محتوای آموزشی.

## ✨ ویژگی‌های آموزشی

محتوای این مخزن با تمرکز بر یادگیری عمیق و کاربردی تهیه شده است.

- **ساختار فصل‌بندی‌شده:** مطالب به بخش‌های مستقل و منظم تقسیم شده‌اند.
- **آموزش مرحله‌به‌مرحله:** مفاهیم از پایه شروع شده و به مباحث پیشرفته می‌رسند.
- **زبان ساده و تخصصی:** توضیحات فارسی همراه با اصطلاحات استاندارد انگلیسی.
- **مثال‌های عملی:** استفاده از مثال‌ها، دستورات و کدهای کاربردی.
- **مقایسه فناوری‌ها:** بررسی تفاوت‌ها، مزایا، معایب و موارد استفاده.
- **نکات مهندسی:** توجه به Best Practices، معماری، امنیت و نگه‌داری.
- **عیب‌یابی:** بررسی مشکلات متداول و روش‌های حل آن‌ها.
- **نقشه راه یادگیری:** ارائه مسیرهای پیشنهادی برای ادامه یادگیری.
- **منابع تکمیلی:** معرفی مستندات رسمی، کتاب‌ها، مقالات و منابع معتبر.

## 📂 ساختار مخزن

هر آموزش در یک پوشه مستقل قرار گرفته است و ساختار کلی آن به شکل زیر است:

```text
persian-Dev-Handbook/
│
├── ai-for-programmers/
├── ai-from-zero-tutorial/
├── ai-tutorial/
│
├── comptia-ai-essentials-tutorial/
├── comptia-secai-plus-tutorial/
├── comptia-server-plus-tutorial/
├── comptia-tech-plus-tutorial/
│
├── devops-fundamentals-tutorial/
├── git-jenkins-tutorial/
├── github-tutorial/
│
├── lpic-tutorial/
├── vercel-tutorial/
├── web-servers-tutorial/
│
└── README.md
```

هر پوشه معمولاً شامل فایل‌های زیر است:

```text
tutorial/
├── 01-Introduction.md
├── 02-Fundamentals.md
├── 03-Advanced-Concepts.md
├── ...
├── README.md
└── SUMMARY.md
```

- فایل‌های شماره‌گذاری‌شده: محتوای اصلی آموزش و فصل‌ها.
- `README.md`: معرفی و راهنمای مطالعه مجموعه.
- `SUMMARY.md`: فهرست مطالب و نمای کلی فصل‌ها.

## 🚀 نحوه استفاده

استفاده از این مجموعه بسیار ساده است و به نصب هیچ نرم‌افزار خاصی نیاز نداری.

### روش اول: مطالعه مستقیم در GitHub

۱. وارد پوشه آموزش موردنظر شو.

۲. فایل `README.md` را برای آشنایی با مجموعه مطالعه کن.

۳. از فصل اول شروع کن و به ترتیب پیش برو.

۴. برای مشاهده نمای کلی مطالب از `SUMMARY.md` استفاده کن.

### روش دوم: دریافت مخزن

مخزن را با دستور زیر دریافت کن:

```bash
git clone https://github.com/Hmidqorbani/persian-Dev-Handbook.git
```

سپس وارد پوشه پروژه شو:

```bash
cd persian-Dev-Handbook
```

حالا می‌توانی فایل‌های Markdown را با ابزارهایی مانند VS Code، Obsidian یا هر Markdown Reader دیگری مطالعه کنی.
