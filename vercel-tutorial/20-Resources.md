## نکات استفاده از منابع

1. **مستندات رسمی اولویت اول است** — همیشه به‌روز و دقیق.
2. **ترتیب مطالعه را رعایت کنید** — از ساده به پیچیده.
3. **تمرین عملی** مهم‌تر از خواندن است.
4. **بلاگ‌ها** برای روندهای جدید، **مستندات** برای مرجع.
5. **جوامع** برای حل مشکلات واقعی.
6. **نسخه‌ها** را بررسی کنید — API ممکن است تغییر کند.
