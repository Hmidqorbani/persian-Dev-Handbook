## فصل ۲: استراتژی مطالعه

### مقدمه

یک برنامه مطالعه **ساختاریافته** (۵۰–۷۰ ساعت) شانس قبولی را بسیار بالا می‌برد.

### مفاهیم اساسی

**برنامه پیشنهادی (۸ هفته، ~۶۰ ساعت):**

| هفته | فایل‌ها | تمرکز | ساعت |
|------|---------|-------|------|
| ۱ | 01–03 | مبانی + آزمایشگاه | ۸ |
| ۲ | 04–06 | Recon + Scan + Enum | ۹ |
| ۳ | 07–09 | Vuln + System + Malware | ۹ |
| ۴ | 10–11 | Sniffing + SE | ۷ |
| ۵ | 12–14 | DoS + Session + Evasion | ۸ |
| ۶ | 15–16 | Web + SQLi | ۹ |
| ۷ | 17–20 | Wireless + Mobile/IoT + Cloud + Crypto | ۱۰ |
| ۸ | 21–22 + مرور | قوانین + آزمون + تمرین | ۸ |

**روش مطالعه مؤثر:**
1. **فعال بخوانید:** یادداشت بردارید، خلاصه بسازید.
2. **عملی تمرین کنید:** هر ابزار را در آزمایشگاه اجرا کنید.
3. **فلش‌کارت بسازید:** برای پورت‌ها، پروتکل‌ها، ابزارها.
4. **آزمون تمرینی بدهید:** قبل از آزمون اصلی.
5. **مرور فاصله‌دار:** هر موضوع را در بازه‌های مختلف مرور کنید.

### مثال عملی

```text
# چک‌لیست مطالعه روزانه:
[ ] یک فصل خواندم
[ ] در آزمایشگاه تمرین کردم
[ ] خلاصه/فلش‌کارت ساختم
[ ] سوال تمرینی حل کردم
[ ] اشتباهات را مرور کردم
```

### اشکال شایع

- **مشکل:** فقط خواندن بدون تمرین → در آزمون سناریومحور شکست می‌خورید.
- **مشکل:** حفظ کردن بدون فهم → فراموشی سریع.
- **مشکل:** پراکنده خواندن → یک برنامه منظم داشته باشید.

### نکات مهم (Tips & Tricks)

- **۸۰٪ تمرین، ۲۰٪ خواندن** (برعکس تصور رایج).
- ابزارها و **دستورات کلیدی** را به خاطر بسپارید.
- **آزمون‌های تمرینی** (Boson، کتاب Study Guide) ضروری‌اند.
- به **سوالات AI** (جدید در v13) توجه ویژه کنید.

### خلاصه فصل

- برنامه ۸ هفته‌ای، ~۶۰ ساعت.
- مطالعه فعال + تمرین عملی.
- آزمون تمرینی قبل از اصلی.

## فصل ۳: نمونه سوالات

### مقدمه

نمونه سوالات به شما **سبک آزمون** را نشان می‌دهند.

### مفاهیم اساسی — نمونه سوالات

**۱.** کدام نوع هکر با مجوز و برای افزایش امنیت کار می‌کند؟
- الف) Black Hat
- ب) White Hat ✅
- ج) Grey Hat
- د) Script Kiddie

**۲.** کدام ابزار برای اسکن پورت استفاده می‌شود؟
- الف) Wireshark
- ب) Nmap ✅
- ج) Hydra
- د) John the Ripper

**۳.** ARP Spoofing در کدام لایه OSI رخ می‌دهد؟
- الف) لایه ۳
- ب) لایه ۲ ✅
- ج) لایه ۴
- د) لایه ۷

**۴.** کدام حمله SQL Injection را خودکار می‌کند؟
- الف) Burp Suite
- ب) SQLMap ✅
- ج) Metasploit
- د) Nikto

**۵.** EternalBlue از کدام آسیب‌پذیری استفاده می‌کند؟
- الف) SMBv1 ✅
- ب) HTTP/2
- ج) TLS 1.0
- د) FTP

**۶.** کدام پروتکل بدون رمزنگاری است؟
- الف) HTTPS
- ب) SSH
- ج) HTTP ✅
- د) SFTP

**۷.** WPA3 از کدام مکانیزم استفاده می‌کند؟
- الف) RC4
- ب) SAE ✅
- ج) TKIP
- د) WEP

**۸.** مدل مسئولیت مشترک ابر یعنی چه؟
- الف) ارائه‌دهنده مسئول همه‌چیز است
- ب) امنیت بین ارائه‌دهنده و مشتری تقسیم می‌شود ✅
- ج) مشتری مسئول همه‌چیز است
- د) هیچ‌کس مسئول نیست

**۹.** کدام حمله نشست فعال کاربر را تصاحب می‌کند؟
- الف) DoS
- ب) Session Hijacking ✅
- ج) Phishing
- د) Sniffing

**۱۰.** کدام تکنیک بدون اجرا، بدافزار را تحلیل می‌کند؟
- الف) Dynamic Analysis
- ب) Static Analysis ✅
- ج) Sandboxing
- د) Fuzzing

### نکات مهم (Tips & Tricks)

- پاسخ‌های **چهارگزینه‌ای** اغلب دو گزینه نزدیک دارند؛ دقت کنید.
- به **کلمات کلیدی** سوال توجه کنید («کدام یک...»، «بهترین...»).
- سوالات **سناریومحور** نیاز به تحلیل دارند.

### خلاصه فصل

- سبک سوال: دانش فنی + سناریو.
- تمرین زیاد = سرعت و دقت.
- کلمات کلیدی را تشخیص دهید.

## فصل ۴: CEH Practical

### مقدمه

**CEH Practical** آزمون عملی است که مهارت واقعی شما را می‌سنجد.

### مفاهیم اساسی

**مشخصات:**
- **۲۰ چالش** در **۶ ساعت**.
- محیط واقعی (شبیه‌سازی شبکه هدف).
- نمره قبولی حدود **۷۰٪**.
- اختیاری، اما برای اعتبار شغلی **بسیار توصیه‌شده**.

**مهارت‌های مورد نیاز:**
- اسکن و Enumeration
- کرک پسورد
- بهره‌برداری (Metasploit)
- SQL Injection
- تحلیل ترافیک
- Privilege Escalation
- Web Exploitation

**نکات کلیدی محیط Practical:**
- از **Parrot OS** یا Kali استفاده می‌شود.
- ابزارهای محدود در دسترس (کتابخانه سفید).
- پاسخ‌ها معمولاً **فلگ** هستند.

### مثال عملی

```text
# نمونه چالش‌ها:
1. یافتن فلگ در سرویس SMB
2. کرک Handshake بی‌سیم
3. SQL Injection و استخراج داده
4. بهره‌برداری از سرویس آسیب‌پذیر با Metasploit
5. تحلیل pcap و یافتن Credential
6. Privilege Escalation در لینوکس
7. XSS و دزدیدن کوکی
8. رمزگشایی فایل با یافتن کلید
```

### اشکال شایع

- **مشکل:** وقت کم می‌آید → چالش‌های آسان را اول حل کنید.
- **مشکل:** ابزار مورد علاقه در دسترس نیست → به ابزارهای جایگزین مسلط باشید.
- **مشکل:** فلگ را اشتباه وارد می‌کنید → دقت در فرمت فلگ.

### نکات مهم (Tips & Tricks)

- **مدیریت زمان:** چالش‌های سریع را اول بگیرید.
- **یادداشت‌برداری:** همه یافته‌ها را ثبت کنید.
- به **چند ابزار برای یک کار** مسلط باشید.
- تمرین با **VulnHub** و **HackTheBox** بهترین آمادگی است.

### خلاصه فصل

- Practical: ۲۰ چالش، ۶ ساعت، قبولی ۷۰٪.
- مهارت‌های عملی واقعی لازم است.
- تمرین با HTB و VulnHub.

## فصل ۵: CEH در مقابل OSCP و PenTest+

### مقدمه

انتخاب مدرک مناسب به **هدف شغلی** شما بستگی دارد.

### مفاهیم اساسی

| ویژگی | CEH | OSCP | CompTIA PenTest+ |
|-------|-----|------|------------------|
| ارائه‌دهنده | EC-Council | Offensive Security | CompTIA |
| تمرکز | دانش + روش‌شناسی | عملی خالص | عملی + مدیریتی |
| آزمون | ۱۲۵ سوال MCQ | ۲۴ ساعت عملی | MCQ + عملی |
| سختی | متوسط | سخت | متوسط |
| اعتبار | خوب برای HR | عالی فنی | خوب |
| مناسب | ورود، انطباق | حرفه‌ای نفوذ | ورود به تست نفوذ |
| ارزش عملی | متوسط | بسیار بالا | بالا |

**راهنمای انتخاب:**
- **CEH:** اگر می‌خواهید دانش پایه + اعتبار سازمانی (مناسب برای الزامات شغلی/دولتی).
- **OSCP:** اگر می‌خواهید هکر نفوذ حرفه‌ای شوید (سخت‌ترین اما باارزش‌ترین).
- **PenTest+:** اگر می‌خواهید تعادل دانش + عملی با هزینه کمتر.

**مسیر پیشنهادی:**
```
مبتدی → CEH (پایه) → PenTest+ (عملی) → OSCP (حرفه‌ای)
یا
مبتدی → CEH → OSCP (مسیر مستقیم حرفه‌ای)
```

### اشکال شایع

- **مشکل:** «CEH کافی است برای هکر شدن» → CEH پایه است؛ برای عمق، OSCP.
- **مشکل:** «OSCP راحت‌تر است» → برعکس؛ OSCP بسیار چالشی‌تر است.

### نکات مهم (Tips & Tricks)

- **CEH** برای ورود و انطباق سازمانی؛ **OSCP** برای مهارت فنی عمیق.
- ترکیب **CEH + OSCP** رزومه قوی می‌سازد.
- هزینه و زمان هرکدام را در نظر بگیرید.

### خلاصه فصل

- CEH: دانش + اعتبار، OSCP: عملی سخت، PenTest+: تعادل.
- بر اساس هدف شغلی انتخاب کنید.
- ترکیب مدارک ارزش بیشتری دارد.

## فصل ۶: پروژه نهایی + چک‌لیست + واژه‌نامه + منابع

### مقدمه

در پایان، یک **پروژه واقعی** انجام می‌دهیم که همه آموخته‌ها را به کار می‌گیرد.

### مثال عملی — پروژه نهایی (Capstone)

**هدف:** تست نفوذ کامل روی یک ماشین آسیب‌پذیر (مثلاً VulnHub یا HTB).

```bash
# ============================================
#  پروژه نهایی: تست نفوذ کامل
# ============================================

# === فاز ۰: آماده‌سازی ===
# - دریافت مجوز / انتخاب ماشین تمرینی
# - تنظیم آزمایشگاه
mkdir -p project/{recon,scan,enum,exploit,report}

# === فاز ۱: شناسایی ===
# - کشف میزبان
sudo nmap -sn 10.10.10.0/24 -oA project/recon/hosts
# - اسکن پورت
sudo nmap -sV -sC -p- 10.10.10.5 -oA project/scan/full

# === فاز ۲: Enumeration ===
enum4linux -a 10.10.10.5 | tee project/enum/smb.txt
gobuster dir -u http://10.10.10.5 -w /usr/share/wordlists/dirb/common.txt -o project/enum/web.txt

# === فاز ۳: تحلیل آسیب‌پذیری ===
searchsploit <service> <version>
nikto -h http://10.10.10.5 -o project/scan/nikto.txt

# === فاز ۴: بهره‌برداری ===
msfconsole
# انتخاب و اجرای اکسپلویت مناسب
# گرفتن shell

# === فاز ۵: ارتقای دسترسی ===
# - local_exploit_suggester
# - بررسی SUID، sudo -l، Cron
# - دسترسی root

# === فاز ۶: مستندسازی ===
# - استخراج فلگ/شواهد
# - تهیه گزارش کامل (فایل ۲۱)
# - تهیه PoC برای هر یافته
```

### چک‌لیست قبل از آزمون

```text
# ===== چک‌لیست آمادگی آزمون CEH =====

## دانش فنی
[ ] ۲۰ ماژول را مطالعه کرده‌ام
[ ] پورت‌ها و پروتکل‌های کلیدی را می‌دانم
[ ] انواع حملات و دفاع‌ها را می‌فهمم
[ ] نقش AI در هر ۵ فاز را می‌دانم

## مهارت عملی
[ ] با Nmap، Metasploit، Burp، SQLMap کار کرده‌ام
[ ] در محیط آزمایشگاهی بهره‌برداری انجام داده‌ام
[ ] کرک پسورد را تمرین کرده‌ام
[ ] SQL Injection را دستی و با SQLMap تست کرده‌ام

## آمادگی آزمون
[ ] حداقل ۲ آزمون تمرینی داده‌ام
[ ] اشتباهات را مرور کرده‌ام
[ ] مدیریت زمان را تمرین کرده‌ام
[ ] فلش‌کارت‌ها را مرور کرده‌ام

## آماده‌سازی نهایی
[ ] تاریخ آزمون رزرو شده
[ ] سیستم و اینترنت تست شده
[ ] استراحت کافی قبل از آزمون
[ ] قوانین آزمون (Open Book؟) را خوانده‌ام
```

### مسیر ادامه یادگیری

```text
پس از CEH:
1. تمرین بیشتر: HackTheBox, TryHackMe, VulnHub
2. مدرک بعدی: OSCP / PenTest+
3. تخصص: Web, Cloud, Red Team, Malware Analysis
4. مشارکت: Bug Bounty، CTF، پروژه‌های متن‌باز
5. جامعه: انجمن‌های امنیتی، کنفرانس‌ها (DEF CON, Black Hat)
```

### نکات مهم (Tips & Tricks)

- **تمرین مداوم** کلید موفقیت است.
- در **CTF**ها شرکت کنید.
- **Bug Bounty** درآمد و تجربه واقعی می‌دهد.
- **شبکه‌سازی** حرفه‌ای فرصت‌های شغلی می‌سازد.
- **اخلاق** را همیشه حفظ کنید — این مهم‌ترین دارایی شماست.

### خلاصه فصل

- پروژه نهایی: زنجیره کامل از Recon تا گزارش.
- چک‌لیست، واژه‌نامه و مسیر ادامه.
- تمرین، اخلاق و یادگیری مداوم.
