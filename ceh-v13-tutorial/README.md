# 📚 کتابچه آموزشی CEH v13 — از صفر تا آزمون

**راهنمای جامع هکر اخلاقی با تمرکز بر CEH v13 و هوش مصنوعی**

---

## این کتابچه برای کیست؟

این کتابچه برای **مبتدی تا متوسط** نوشته شده است؛ یعنی حتی اگر فقط آشنایی مقدماتی با شبکه، TCP/IP، ویندوز و لینوکس دارید، می‌توانید از اینجا شروع کنید و تا آمادگی کامل برای آزمون **CEH (Certified Ethical Hacker)** پیش بروید.

**پیش‌نیازها:**
- آشنایی مقدماتی با مفاهیم شبکه (اینترنت، IP، مرورگر)
- کار ساده با ویندوز یا لینوکس
- علاقه و کنجکاوی برای یادگیری امنیت
- یک سیستم با حداقل ۸ گیگابایت رم (ترجیحاً ۱۶ گیگابایت) برای اجرای ماشین‌های مجازی

---

## 🎯 هدف نهایی

1. **آموزش کامل و عملی** هک اخلاقی از پایه
2. **آمادگی برای آزمون CEH v13** (نظری و عملی)
3. **قابل انتشار در گیت‌هاب** به‌عنوان یک مرجع فارسی
4. **ساخت یک آزمایشگاه امن شخصی** برای تمرین

## 🤖 نقش هوش مصنوعی در این کتابچه

CEH v13 نخستین نسخه‌ای است که **هوش مصنوعی را در تمام ۵ فاز هک اخلاقی** یکپارچه کرده است. در این کتابچه، در هر فایل بخشی اختصاصی به کاربرد AI اختصاص داده شده است:

- **AI-Powered OSINT** — خودکارسازی شناسایی و تحلیل اطلاعات عمومی
- **تحلیل بدافزار با AI** — شناسایی الگو و مهندسی معکوس هوشمند
- **تحلیل آسیب‌پذیری با AI** — اولویت‌بندی و پیش‌بینی اکسپلویت
- **فیشینگ مبتنی بر AI و دیپ‌فیک** — تولید محتوای فریبنده
- **تشخیص مبتنی بر AI** — سمت مدافع

## 📖 نحوه استفاده

1. فایل‌ها را به‌ترتیب شماره مطالعه کنید (پیشرونده از ساده به پیچیده).
2. هر فایل شامل چند **فصل** است؛ هر فصل ساختار یکسان دارد: مقدمه، مفاهیم، مثال عملی، اشکال شایع، نکات، خلاصه.
3. **آزمایشگاه‌های عملی** را حتماً اجرا کنید — هک اخلاقی بدون تمرین عملی معنا ندارد.
4. **منابع و مراجع** در انتهای هر فایل قرار دارد.
5. برای تمرین، از محیط ایزوله آزمایشگاهی (فایل 03) استفاده کنید و **هرگز** روی سیستم‌های واقعی بدون مجوز کتبی کار نکنید.
