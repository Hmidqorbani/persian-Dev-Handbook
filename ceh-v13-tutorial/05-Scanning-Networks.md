## فصل ۱: مقدمه اسکن

### مقدمه

پس از شناسایی، باید بفهمیم کدام دستگاه‌ها **روشن**، کدام **پورت‌ها باز** و چه **سرویس‌هایی** در حال اجراست. این فاز **Scanning** است و ابزار اصلی آن **Nmap** است.

> **تشبیه:** Recon مثل نگاه کردن به بیرون ساختمان است؛ Scanning مثل زدن به همه درها و پنجره‌ها برای یافتن درِ باز.

### مفاهیم اساسی

**سه نوع اسکن:**

| نوع | هدف | مثال |
|-----|-----|------|
| **Port Scanning** | یافتن پورت‌های باز | Nmap |
| **Network Scanning** | یافتن میزبان‌های فعال | `nmap -sn` |
| **Vulnerability Scanning** | یافتن آسیب‌پذیری | Nessus (فایل ۰۷) |

**وضعیت پورت‌ها:**
- **Open:** سرویس فعال، پذیرای اتصال.
- **Closed:** بسته، اما میزبان پاسخ می‌دهد.
- **Filtered:** فایروال جلوی آن است.
- **Unfiltered:** پاسخ می‌دهد اما وضعیت نامشخص.

### نکات مهم (Tips & Tricks)

- قبل از اسکن، **مجوز** داشته باشید. اسکن بدون مجوز = جرم.
- با اسکن **آرام** شروع کنید تا لو نروید.
- نتایج را در **دفترچه** با تاریخ و ساعت ثبت کنید.

### خلاصه فصل

- Scanning = کشف میزبان، پورت و سرویس.
- وضعیت پورت‌ها: Open، Closed، Filtered.
- Nmap ابزار اصلی این فاز.

## فصل ۲: کشف میزبان

### مقدمه

**Host Discovery** یعنی پیدا کردن اینکه کدام IPها فعال‌اند، بدون اسکن کامل پورت‌ها.

### مفاهیم اساسی

**روش‌های کشف:**
- **ARP (لایه ۲):** دقیق‌ترین در شبکه محلی.
- **ICMP Echo (ping):** کلاسیک، اما اغلب مسدود.
- **TCP SYN/Ping:** ارسال به پورت‌های رایج.
- **UDP Ping:** به پورت‌های خاص.

### مثال عملی

```bash
# --- کشف ساده در شبکه محلی ---
sudo nmap -sn 192.168.56.0/24
# -sn : بدون اسکن پورت (فقط کشف میزبان)

# --- با ARP (فقط شبکه محلی) ---
sudo nmap -PR -sn 192.168.56.0/24

# --- با لیست ورودی ---
nmap -sn -iL targets.txt

# --- ابزار netdiscover ---
sudo netdiscover -r 192.168.56.0/24

# --- fping ---
fping -a -g 192.168.56.0/24 2>/dev/null
```

### اشکال شایع

- **مشکل:** همه میزبان‌ها Up نشان داده می‌شوند → فایروال پاسخ جعلی می‌دهد؛ از ARP استفاده کنید.
- **مشکل:** هیچ میزبانی پیدا نمی‌شود → بررسی کنید در همان شبکه هستید (`ip a`).

### نکات مهم (Tips & Tricks)

- در شبکه محلی، **ARP همیشه دقیق‌تر از ICMP** است.
- `-sn` برای کشف سریع، `-Pn` برای نادیده گرفتن کشف میزبان.

### خلاصه فصل

- کشف میزبان = یافتن IPهای فعال.
- ARP در شبکه محلی، ICMP/TCP در اینترنت.
- `-sn` سریع‌ترین روش Nmap.

## فصل ۳: اسکن پورت با Nmap

### مقدمه

**Nmap** (Network Mapper) استاندارد صنعتی اسکن پورت است. در این فصل کامل یاد می‌گیریم.

### مفاهیم اساسی

**انواع اسکن Nmap:**

| نوع | سوییچ | توضیح |
|-----|-------|-------|
| TCP Connect | `-sT` | کامل، قابل ردیابی |
| TCP SYN | `-sS` | نیمه‌باز، مخفی‌تر (نیاز روت) |
| UDP | `-sU` | کند، سرویس‌های UDP |
| FIN | `-sF` | فرار از فایروال |
| Xmas | `-sX` | فلگ‌های FIN/PSH/URG |
| Null | `-sN` | بدون فلگ |
| ACK | `-sA` | تشخیص فایروال |

**محدوده پورت:**
- `-p 80` یک پورت
- `-p 1-1000` محدوده
- `-p-` همه ۶۵۵۳۵ پورت
- `--top-ports 100` صد پورت رایج

### مثال عملی

```bash
# --- اسکن پایه ---
nmap 192.168.56.101

# --- اسکن سریع همه پورت‌ها ---
nmap -p- --min-rate 1000 192.168.56.101

# --- اسکن SYN مخفی ---
sudo nmap -sS -p 1-1000 192.168.56.101

# --- اسکن UDP ---
sudo nmap -sU --top-ports 50 192.168.56.101

# --- اسکن پرخاشگرانه (شامل OS/SVC/اسکریپت) ---
sudo nmap -A -T4 192.168.56.101

# --- اسکن چند هدف ---
nmap 192.168.56.101 192.168.56.102
nmap 192.168.56.0/24

# --- ذخیره خروجی در چند فرمت ---
nmap -oA scan_result 192.168.56.101
```

### اشکال شایع

- **مشکل:** `-sS` خطای روت می‌دهد → با `sudo` اجرا کنید یا `-sT` بزنید.
- **مشکل:** اسکن بسیار کند → `-T4` یا `--min-rate` استفاده کنید.
- **مشکل:** نتایج ناقص → `-Pn` برای نادیده گرفتن کشف میزبان.

### نکات مهم (Tips & Tricks)

- زمان‌بندی: `-T0` (بدون لو رفتن) تا `-T5` (سریع/پرخطر).
- `-oA` خروجی در سه فرمت (Normal/XML/Grepable) می‌دهد — برای مستندسازی عالی.
- `--reason` دلیل وضعیت هر پورت را نشان می‌دهد.

### خلاصه فصل

- Nmap انواع اسکن TCP/UDP دارد.
- `-sS` مخفی، `-sT` کامل، `-sU` برای UDP.
- `-A` جامع‌ترین اسکن است.

## فصل ۴: تشخیص سیستم‌عامل و سرویس

### مقدمه

بعد از یافتن پورت‌های باز، باید بفهمیم چه **سرویس** و چه **نسخه‌ای** روی آن‌ها اجرا می‌شود و سیستم‌عامل چیست.

### مفاهیم اساسی

**Service/Version Detection (`-sV`):** با ارسال پروب‌های خاص، سرویس و نسخه را تشخیص می‌دهد.

**OS Detection (`-O`):** با تحلیل پاسخ‌های TCP/IP، سیستم‌عامل را حدس می‌زند.

**NSE (Nmap Scripting Engine):** اسکریپت‌های Lua برای کارهای پیشرفته (کشف آسیب‌پذیری، شمارش، brute-force).

### مثال عملی

```bash
# --- تشخیص سرویس و نسخه ---
nmap -sV 192.168.56.101

# --- تشخیص سیستم‌عامل ---
sudo nmap -O 192.168.56.101

# --- هر دو + اسکریپت پیش‌فرض ---
sudo nmap -A 192.168.56.101

# --- اجرای اسکریپت‌های NSE ---
nmap --script vuln 192.168.56.101
nmap --script smb-enum-shares 192.168.56.101
nmap --script http-title 192.168.56.101

# --- لیست اسکریپت‌ها ---
ls /usr/share/nmap/scripts/ | grep smb
```

### اشکال شایع

- **مشکل:** تشخیص OS اشتباه است → Nmap حدس می‌زند؛ با ابزارهای دیگر تأیید کنید.
- **مشکل:** اسکریپت NSE خطا می‌دهد → `nmap --script-updatedb`.

### نکات مهم (Tips & Tricks)

- `--script vuln` مجموعه اسکریپت‌های بررسی آسیب‌پذیری را اجرا می‌کند.
- **Banner Grabbing** دستی: `nc -v 192.168.56.101 80` و ارسال `HEAD / HTTP/1.0`.
- نسخه دقیق سرویس = کلید یافتن CVE مناسب (فایل ۰۷).

### خلاصه فصل

- `-sV` سرویس، `-O` سیستم‌عامل را تشخیص می‌دهد.
- NSE قدرت اصلی Nmap است.
- `-A` ترکیب همه این‌هاست.

## فصل ۵: تکنیک‌های فرار از فایروال

### مقدمه

فایروال‌ها و IDSها اسکن را مسدود می‌کنند. برای عبور، تکنیک‌های فرار (Evasion) لازم است.

### مفاهیم اساسی

| تکنیک | سوییچ | توضیح |
|-------|-------|-------|
| Fragmentation | `-f` | تقسیم بسته به قطعات کوچک |
| Decoy | `-D` | مخفی کردن IP در میان آدرس‌های جعلی |
| Spoofing | `-S` | جعل IP مبدأ |
| Source Port | `--source-port` | استفاده از پورت مجاز (مثل 53) |
| Timing | `-T0/-T1` | اسکن آهسته |
| MTU | `--mtu` | تغییر اندازه بسته |
| Data Length | `--data-length` | افزودن داده تصادفی |

### مثال عملی

```bash
# --- تکه‌تکه کردن بسته ---
sudo nmap -f 192.168.56.101

# --- استفاده از Decoy ---
sudo nmap -D RND:10 192.168.56.101

# --- جعل پورت مبدأ ---
sudo nmap --source-port 53 192.168.56.101

# --- اسکن آهسته و مخفی ---
sudo nmap -T1 --scan-delay 5s 192.168.56.101

# --- تغییر اندازه MTU ---
sudo nmap --mtu 16 192.168.56.101
```

### اشکال شایع

- **مشکل:** Decoy با شبکه محلی کار نمی‌کند → Decoy برای شبکه‌های دور مناسب است.
- **مشکل:** اسکن آهسته زمان زیادی می‌برد → صبور باشید؛ مخفی بودن هزینه دارد.

### نکات مهم (Tips & Tricks)

- ترکیب تکنیک‌ها مؤثرتر از یکی است.
- همیشه فرض کنید **لاگ گرفته می‌شود**؛ فرار یعنی «سخت‌تر شدن تشخیص»، نه نامرئی شدن.
- جزئیات بیشتر در فایل ۱۴ (فرار از IDS/فایروال).

### خلاصه فصل

- Evasion = عبور از فایروال/IDS.
- Fragmentation، Decoy، Spoofing، Timing.
- ترکیب تکنیک‌ها مؤثرتر است.

## فصل ۶: ابزارهای مکمل و آزمایشگاه

### مقدمه

علاوه بر Nmap، ابزارهای تخصصی سرعت و دقت را بالا می‌برند.

### مفاهیم اساسی

| ابزار | کاربرد |
|-------|--------|
| **masscan** | اسکن بسیار سریع کل اینترنت |
| **hping3** | ساخت بسته دلخواه |
| **netcat (nc)** | اتصال خام، Banner Grabbing |
| **Unicornscan** | اسکن غیرهمزمان |
| **Zmap** | اسکن اینترنت‌مقیاس |
| **arp-scan** | اسکن ARP سریع |

### مثال عملی — آزمایشگاه کامل

```bash
# ===== آزمایشگاه کامل اسکن =====
# ۱. کشف میزبان
sudo nmap -sn 192.168.56.0/24 -oA lab/hosts

# ۲. اسکن سریع پورت‌های رایج
sudo nmap -sS --top-ports 1000 -T4 192.168.56.101 -oA lab/top1000

# ۳. اسکن کامل + سرویس + OS
sudo nmap -sS -sV -O -A -p- 192.168.56.101 -oA lab/full

# ۴. اسکن UDP رایج
sudo nmap -sU --top-ports 20 192.168.56.101 -oA lab/udp

# ۵. اسکن آسیب‌پذیری با NSE
sudo nmap --script vuln 192.168.56.101 -oA lab/vuln

# --- ابزارهای مکمل ---
# masscan (سریع)
sudo masscan -p1-65535 192.168.56.101 --rate=1000

# hping3 (ساخت بسته سفارشی)
sudo hping3 -S 192.168.56.101 -p 80 -c 3

# netcat (Banner Grabbing)
nc -v 192.168.56.101 22

# arp-scan
sudo arp-scan --interface=eth0 --localnet
```

### اشکال شایع

- **مشکل:** masscan با Nmap تداخل دارد → تنها اجرا کنید.
- **مشکل:** hping3 نیاز به روت دارد → با sudo.

### نکات مهم (Tips & Tricks)

- **Nmap برای دقت، masscan برای سرعت.**
- خروجی همه ابزارها را در پوشه `lab/` سازمان دهید.
- نتایج را با `xsltproc` به HTML تبدیل کنید: `xsltproc lab/full.xml -o lab/full.html`.

### خلاصه فصل

- masscan سریع، hping3 انعطاف‌پذیر، netcat ساده.
- آزمایشگاه کامل: کشف → اسکن → سرویس → آسیب‌پذیری.
- مستندسازی با `-oA` و HTML.
