## فصل ۱: مقدمه و روانشناسی

### مقدمه

**Social Engineering (مهندسی اجتماعی)** یعنی فریب **انسان** برای افشای اطلاعات یا انجام کار خطرناک. چون هدف‌گیری انسان آسان‌تر از هک فنی است، مهاجمان اغلب از این راه وارد می‌شوند.

> **تشبیه:** لازم نیست در بانک را بشکنی؛ کافی است به نگهبان بقولی که کلید را جا گذاشته‌ای.

### مفاهیم اساسی

**اصول روانشناسی (Cialdini):**
1. **Authority (اقتدار):** اطاعت از مقام.
2. **Urgency (فوریت):** فشار زمانی.
3. **Social Proof (تأیید اجتماعی):** «همه این کار را می‌کنند».
4. **Scarcity (کمیابی):** «فقط امروز».
5. **Liking (دوست‌داشتن):** اعتماد به افراد خوش‌برخورد.
6. **Reciprocity (عمل متقابل):** لطف در برابر لطف.
7. **Fear (ترس):** تهدید به پیامد.

**چرخه مهندسی اجتماعی:** تحقیق → برقراری ارتباط → بهره‌برداری → اجرا.

### نکات مهم (Tips & Tricks)

- مهندسی اجتماعی **مهارت انسانی** است، نه فقط فنی.
- **Pretexting:** ساخت یک داستان باورپذیر (مثلاً «از پشتیبانی IT هستم»).
- آموزش کارکنان بهترین دفاع است.

### خلاصه فصل

- SE = فریب انسان، نه سیستم.
- اصول روانشناسی: اقتدار، فوریت، تأیید اجتماعی و...
- تحقیق → ارتباط → بهره‌برداری → اجرا.

## فصل ۲: انواع حملات

### مقدمه

مهندسی اجتماعی اشکال متنوعی دارد — از ایمیل تا تماس تلفنی و حضور فیزیکی.

### مفاهیم اساسی

| نوع | کانال | توضیح |
|-----|-------|-------|
| **Phishing** | ایمیل | ارسال ایمیل جعلی انبوه |
| **Spear Phishing** | ایمیل | هدفمند یک فرد خاص |
| **Whaling** | ایمیل | هدف مدیران ارشد |
| **Vishing** | تلفن | فریب صوتی |
| **Smishing** | پیامک | فریب با SMS |
| **Pretexting** | متنوع | ساخت داستان جعلی |
| **Baiting** | فیزیکی/دیجیتال | طعمه (USB آلوده) |
| **Tailgating** | فیزیکی | ورود پشت فرد مجاز |
| **Quid Pro Quo** | متنوع | خدمت در برابر اطلاعات |
| **Watering Hole** | وب | آلوده‌کردن سایت پربازدید |

### مثال عملی

```text
# نمونه ایمیل Spear Phishing (آموزشی):
فرستنده: it-support@company-secure.com (دامنه جعلی)
موضوع: اقدام فوری: بازنشانی رمز

سلام [نام دقیق کارمند]،
حساب شما به دلیل فعالیت مشکوک قفل می‌شود.
لطفاً ظرف ۲۴ ساعت از لینک زیر رمز خود را بازنشانی کنید:
http://company-secure-login.attacker.com

با تشکر، تیم پشتیبانی فناوری
```

**نشانه‌های هشدار:** دامنه کمی متفاوت، فوریت، درخواست اطلاعات، گرامر ضعیف.

### اشکال شایع

- **مشکل:** فکر می‌کنم فقط ایمیل مهم است → Vishing و Smishing هم رایج‌اند.
- **مشکل:** «کارمندان من آموزش‌دیده‌اند» → حتی متخصصان هم فریب می‌خورند.

### نکات مهم (Tips & Tricks)

- **Spear Phishing** بسیار مؤثرتر از Phishing انبوه است (هدفمند).
- **Tailgating** نیاز به حضور فیزیکی دارد اما بسیار ساده است.
- **Baiting** با USB آلوده در پارکینگ شرکت‌ها کلاسیک است.

### خلاصه فصل

- Phishing انواع مختلفی دارد: انبوه، هدفمند، Whaling.
- کانال‌ها: ایمیل، تلفن، SMS، فیزیکی.
- Spear Phishing مؤثرترین نوع است.

## فصل ۳: Social Engineering Toolkit

### مقدمه

**SET (Social-Engineer Toolkit)** چارچوب اختصاصی برای حملات مهندسی اجتماعی است.

### مفاهیم اساسی

**قابلیت‌های SET:**
- **Spear-Phishing Attack Vectors:** ارسال ایمیل با پیوست مخرب.
- **Website Attack Vectors:** کلون کردن سایت (Credential Harvester).
- **Infectious Media Generator:** ساخت USB آلوده.
- **Mass Mailer:** ارسال انبوه.
- **QRCode Generator:** تولید QR فریبنده.

### مثال عملی

```bash
# === اجرای SET ===
sudo setoolkit

# منو:
# 1) Social-Engineering Attacks
#    2) Website Attack Vectors
#       3) Credential Harvester Attack Method
#          2) Site Cloner
# IP for POST back: 192.168.56.10
# URL to clone: http://example.com/login
# → وقتی قربانی وارد شود، رمز در کنسول نمایش داده می‌شود

# === Spear-Phishing ===
# 1) Social-Engineering Attacks
#    1) Spear-Phishing Attack Vectors
#       1) Perform a Mass Email Attack
#       ... انتخاب Payload و ارسال

# === QRCode Generator ===
# 8) QRCode Generator Attack Vector
```

### اشکال شایع

- **مشکل:** SET خطای Python می‌دهد → به‌روزرسانی کنید: `sudo setoolkit` پس از `apt update`.
- **مشکل:** Site Cloner کار نمی‌کند → بررسی کنید پورت ۸۰ آزاد است.

### نکات مهم (Tips & Tricks)

- **Credential Harvester** + **Site Cloner** ترکیب کلاسیک و مؤثر.
- همیشه از **دامنه/سایت خودتان** برای کلون استفاده کنید.
- SET را در محیط آزمایشگاهی و با مجوز اجرا کنید.

### خلاصه فصل

- SET چارچوب جامع SE.
- Website Attack Vectors پرکاربردترین بخش.
- Site Cloner + Credential Harvester = شکار رمز.

## فصل ۴: فیشینگ با AI و دیپ‌فیک

### مقدمه

هوش مصنوعی مهندسی اجتماعی را **مقیاس‌پذیر، دقیق و باورپذیر** کرده است. این خطرناک‌ترین روند امنیتی امروز است.

### مفاهیم اساسی

**AI در مهندسی اجتماعی:**
1. **تولید ایمیل شخصی‌سازی‌شده:** بر اساس داده‌های OSINT.
2. **غلبه بر موانع زبانی:** ترجمه بی‌نقص به هر زبان.
3. **Voice Cloning:** شبیه‌سازی صدای مدیران (Vishing).
4. **Deepfake ویدئو:** ویدئوی جعلی از مدیر ارشد.
5. **Chatbot تعاملی:** گفتگوی خودکار با قربانی.
6. **Bypass فیلترها:** تولید محتوایی که فیلترهای اسپم را رد کند.

**نمونه واقعی:** در یک شرکت، کارمند با دیدن ویدئوی Deepfake مدیرعامل، ۲۵ میلیون دلار انتقال داد.

### مثال عملی

```text
# نمونه پرامپت (برای درک خطر - آموزشی):
"بر اساس این اطلاعات پروفایل [نقش، سرگرمی‌ها، ارتباطات]،
یک ایمیل کاری کاملاً باورپذیر بنویس که کاربر را
به کلیک روی لینک ترغیب کند."

# این نشان می‌دهد چرا آموزش کاربران حیاتی است.
```

**تکنیک‌های تشخیص دیپ‌فیک:**
- حرکات غیرطبیعی چشم/لب
- ناهماهنگی صدا و تصویر
- نورپردازی غیرعادی
- **تأیید از کانال دوم** (تماس مستقیم)

### اشکال شایع

- **مشکل:** «می‌توانم دیپ‌فیک را تشخیص دهم» → دیپ‌فیک‌های مدرن بسیار واقعی‌اند.
- **مشکل:** فیلترهای اسپم جلوی آن را می‌گیرند → AI محتوایی تولید می‌کند که فیلترها را رد کند.

### نکات مهم (Tips & Tricks)

- **تأیید از کانال دوم (Out-of-band verification)** بهترین دفاع در برابر دیپ‌فیک.
- کلمات رمز سازمانی برای تأیید هویت.
- آموزش مداوم کارکنان در برابر تکنیک‌های جدید AI.
- **بخش دفاعی:** از AI برای تشخیص فیشینگ هم استفاده کنید.

### خلاصه فصل

- AI فیشینگ را مقیاس‌پذیر و باورپذیر کرده.
- Voice Cloning و Deepfake خطرات جدیدند.
- تأیید از کانال دوم بهترین دفاع.

## فصل ۵: آزمایشگاه و اقدامات متقابل

### مقدمه

یک کمپین فیشینگ آموزشی (با مجوز) طراحی و اجرا کنیم.

### مثال عملی — آزمایشگاه

```bash
# === ۱. آماده‌سازی ===
# دامنه شبیه‌سازی‌شده و صفحه ورود کلون‌شده

# === ۲. راه‌اندازی SET ===
sudo setoolkit
# 1) Social-Engineering Attacks
# 2) Website Attack Vectors
# 3) Credential Harvester Attack Method
# 2) Site Cloner
# IP: 192.168.56.10
# URL: http://localhost/dvwa/login.php

# === ۳. ارسال ایمیل آموزشی (به کاربران داوطلب) ===
# با SWAKS یا SMTP محلی

# === ۴. تحلیل نتایج ===
# چه کسی کلیک کرد؟ چه کسی رمز داد؟
# گزارش نرخ آسیب‌پذیری (Click Rate, Submission Rate)
```

### اشکال شایع

- **مشکل:** کمپین بدون مجوز اجرا شد → **همیشه** مجوز کتبی بگیرید.
- **مشکل:** کاربران عصبانی می‌شوند → از قبل اطلاع‌رسانی عمومی و آموزش پس از کمپین.

### نکات مهم (Tips & Tricks)

- کمپین فیشینگ آموزشی ابزار **سنجش آگاهی** است.
- پس از کمپین، جلسه آموزش برگزار کنید (نه تنبیه).
- شاخص‌ها را در طول زمان پیگیری کنید.

### اقدامات متقابل (Countermeasures)

| تهدید | راهکار |
|-------|--------|
| Phishing | فیلتر ایمیل، SPF/DKIM/DMARC، آموزش |
| Vishing | آموزش، تأیید هویت تلفنی |
| Deepfake | تأیید از کانال دوم، کلمه رمز |
| Baiting | سیاست USB، آگاهی |
| Tailgating | کنترل دسترسی فیزیکی، آموزش |
| Pretexting | رویه تأیید هویت |

### خلاصه فصل

- کمپین آموزشی با مجوز = سنجش آگاهی.
- آموزش پس از کمپین ضروری است.
- SPF/DKIM/DMARC + آموزش = دفاع اصلی.
