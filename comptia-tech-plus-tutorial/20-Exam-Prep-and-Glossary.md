## فصل ۸۷: استراتژی مرور و مدیریت زمان آزمون

### مقدمه

دانستن، کافی نیست. باید بتوانی در ۶۰ دقیقه، ۷۰ سؤال را با دقت پاسخ دهی. این فصل، استراتژی را می‌سازد.

### مفاهیم اساسی

**سه مرحلهٔ مرور**

| مرحله | زمان | کار |
|---|---|---|
| مرور اول | ۳ روز | خلاصهٔ هر فایل |
| مرور دوم | ۱ روز | فقط نقاط ضعف |
| مرور سوم | ۲ ساعت | چک‌لیست نهایی |

**مرور فاصله‌دار (Spaced Repetition)**

```
روز ۱: یادگیری
روز ۲: مرور کوتاه
روز ۴: مرور
روز ۸: مرور
روز ۱۵: مرور
```

**چرا؟** فراموشی نمایی است. مرور در فاصلهٔ درست، حافظه را تثبیت می‌کند.

**فلش‌کارت — چه چیزی؟**

| خوب | بد |
|---|---|
| یک مفهوم | یک پاراگراف |
| سؤال/جواب | تعریف طولانی |
| مثال | بدون زمینه |

**نمونه:**

```
سؤال: تفاوت RPO و RTO؟
جواب: RPO = چقدر داده می‌توانم از دست بدهم
       RTO = چقدر می‌توانم قطع باشم
```

**مدیریت زمان آزمون**

```
۶۰ دقیقه ÷ ۷۰ سؤال ≈ ۵۱ ثانیه
```

| مرحله | زمان | کار |
|---|---|---|
| دور ۱ | ۴۰ دقیقه | سؤال‌های سریع |
| دور ۲ | ۱۵ دقیقه | Flagها |
| بررسی | ۵ دقیقه | پاسخ خالی نماند |

**تکنیک‌های تست‌زنی**

| تکنیک | کار |
|---|---|
| **حذف گزینه** | دو گزینهٔ نامعقول را حذف کن |
| **کلمهٔ کلیدی** | NOT، EXCEPT، BEST |
| **گزینهٔ край** | «همیشه»/«هرگز» معمولاً غلط |
| **حدس آگاهانه** | نمرهٔ منفی ندارد |

**مدیریت استرس**

| تکنیک | کار |
|---|---|
| تنفس | ۴-۷-۸ |
| خواب | ۷–۸ ساعت شب قبل |
| آب | همراه داشته باش |
| توقف کوتاه | ۱۰ ثانیه بین سؤال‌های سخت |

### مثال‌های عملی

**سناریوی Lab: برنامهٔ مرور سه‌روزه**

```markdown
## روز ۱
- صبح: فایل ۰۴، ۰۵ (سخت‌افزار)
- عصر: ۳۰ سؤال تمرینی
- شب: مرور خطاها

## روز ۲
- صبح: فایل ۱۶، ۱۷ (امنیت)
- عصر: ۳۰ سؤال
- شب: فلش‌کارت نقاط ضعف

## روز ۳
- صبح: فایل ۱۴، ۱۵ (داده)
- عصر: آزمون کامل ۷۰ سؤالی با تایمر
- شب: مرور چک‌لیست نهایی
```

**سناریوی دوم: دفتر اشتباهات**

```markdown
| # | سؤال | جواب من | جواب درست | چرا اشتباه |
|---|---|---|---|---|
| ۱ | تفاوت Worm و Virus | Virus | Worm | میزبان |
| ۲ | پورت RDP | ۲۲ | ۳۳۸۹ | اشتباه حفظ |
| ۳ | RAID 1 | سرعت | آینه | تعریف |
```

**نکته:** بیشتر خطاها از ۳–۵ مفهوم تکراری می‌آید. همان‌ها را عمیق کن.

### مقایسه و الگوهای مختلف

**سه سبک مرور**

| سبک | مزیت | عیب |
|---|---|---|
| بازخوانی | سریع | کم‌اثر |
| فلش‌کارت | فعال | زمان‌بر |
| تست زدن | واقعی | نیاز به بانک |

**الگوی «۵۰/۵۰»**

نیمی از زمان مطالعه، نیمی تست. تست، یادگیری را تثبیت می‌کند.

### اشکال شایع

**۱) مطالعهٔ شب آخر**
خواب کم، عملکرد پایین.

**۲) فقط خواندن**
تست نزدم.

**۳) بدون تایمر**
در آزمون غافلگیر می‌شوی.

**۴) حفظ بدون فهم**
سؤال سناریویی می‌آید.

**۵) نادیده گرفتن دامنهٔ کم‌وزن**
۹ سؤال = کافی برای رد.

**۶) فلش‌کارت طولانی**
بی‌فایده.

**۷) بدون دفتر اشتباهات**
خطای تکراری.

**۸) استرس بدون تمرین**
تنفس و تمرین.

### نکات مهم (Tips & Tricks)

- **مرور فاصله‌دار.**
- **فلش‌کارت یک‌مفهومی.**
- **۵۰٪ تست.**
- **دفتر اشتباهات.**
- **آزمون با تایمر.**
- **خواب شب قبل.**
- **هرگز خالی نگذار.**

### خلاصه فصل

- سه مرحلهٔ مرور: خلاصه، نقاط ضعف، چک‌لیست.
- مرور فاصله‌دار، تثبیت می‌کند.
- ۵۱ ثانیه برای هر سؤال.
- تکنیک‌های تست‌زنی، نمره را بالا می‌برد.
- دفتر اشتباهات، نقاط ضعف را نشان می‌دهد.
- خواب، بخشی از آماده‌سازی است.

| ۱۴ | ج | ۳۲ | ب | ۵۰ | ج | ۶۸ | ب |
| ۱۵ | د | ۳۳ | ب | ۵۱ | ب | ۶۹ | ج |
| ۱۶ | ج | ۳۴ | ب | ۵۲ | الف | ۷۰ | ب |
| ۱۷ | ب | ۳۵ | ج | ۵۳ | الف | | |
| ۱۸ | ب | ۳۶ | ج | ۵۴ | ب | | |

**نمره‌گذاری:**

```
تعداد صحیح × ۱۰۰ / ۷۰ = درصد
قبولی تقریبی: ۵۳+ صحیح
```

### مقایسه و الگوهای مختلف

**سه سطح نتیجه**

| نتیجه | اقدام |
|---|---|
| ۶۰+ | آماده |
| ۵۰–۵۹ | مرور نقاط ضعف |
| زیر ۵۰ | بازخوانی فایل‌های کلیدی |

### اشکال شایع

**۱) نگاه کردن به پاسخ قبل از اتمام**
نتیجه واقعی نیست.

**۲) بدون تایمر**
آمادگی زمان سنجیده نمی‌شود.

**۳) فقط یک بار**
تکرار، یادگیری را تثبیت می‌کند.

**۴) نادیده گرفتن خطاها**
همان خطا در آزمون اصلی.

**۵) حفظ پاسخ**
سؤال اصلی متفاوت است.

### نکات مهم (Tips & Tricks)

- **تایمر بگذار.**
- **پاسخ را نگاه نکن.**
- **خطاها را ثبت کن.**
- **دو بار بزن.**
- **۶۰+ هدف بگذار.**

### خلاصه فصل

- ۷۰ سؤال با توزیع دامنه‌ها.
- ۵۳+ صحیح تقریباً معادل قبولی.
- تایمر و بدون نگاه به پاسخ.
- خطاها = نقشهٔ مطالعه.
- تکرار آزمون، آمادگی را می‌سنجد.

## فصل ۸۹: مرور فشردهٔ شش دامنه

### مقدمه

پس از ۸۸ فصل، حجم مطالب می‌تواند طاقت‌فرسا شود. این فصل، همهٔ آن‌ها را در شش جدول فشرده جمع می‌کند — برای مرور ۲۴ ساعت آخر. هدف، یادگیری جدید نیست؛ **یادآوری سریع** چیزی است که خوانده‌ای.

### مفاهیم اساسی

#### دامنهٔ ۱ — مفاهیم (۱۳٪)

| مفهوم | نکته |
|---|---|
| بیت/بایت | ۸ بیت = ۱ بایت |
| KB | ۱۰۰۰ (دسیمال) یا ۱۰۲۴ (باینری) |
| Mbps→MB/s | تقسیم بر ۸ |
| باینری | ۱۰۱۱ = ۱۱ |
| هگزا | FF = ۲۵۵ |
| داده/اطلاعات | خام / تفسیرشده |
| عیب‌یابی | شش گام |

#### دامنهٔ ۲ — زیرساخت (۲۴٪)

| CPU | هسته/رشته؛ GHz تنها معیار نیست |
| RAM | فرّار؛ DDR4 ≠ DDR5 |

| Wi-Fi 6E | باند ۶GHz |
| WPA3 | امن‌ترین |
| Type 1 | ESXi |
| IaaS/PaaS/SaaS | زیرساخت / پلتفرم / نرم‌افزار |

#### دامنهٔ ۳ — نرم‌افزار (۱۸٪)

### مثال‌های عملی

**خودآزمایی ۶۰ ثانیه‌ای** — روی هر ردیف، بدون نگاه به جدول جواب بده:

| سؤال | جواب |
|---|---|
| ۸ بیت چند بایت است؟ | ۱ |
| `0xFF` چند است؟ | ۲۵۵ |
| IP با `169.254` یعنی چه؟ | DHCP جواب نداده |
| کدام فایل‌سیستم سقف ۴GB دارد؟ | FAT32 |
| کدام MFA مقاوم به فیشینگ است؟ | FIDO2 |
| تفاوت RPO و RTO؟ | داده / زمان |
| RAID 1 چیست؟ | آینه |
| کدام الگوریتم هش شکسته است؟ | MD5 |
| گام سوم پاسخ به حادثه؟ | مهار |
| کدام باند Wi-Fi کم‌تداخل‌تر است؟ | ۶GHz |

اگر بیش از سه مورد را ندانستی، همان دامنه را دوباره بخوان.

### مقایسه و الگوهای مختلف

**اولویت مرور بر اساس وزن**

| دامنه | وزن | زمان پیشنهادی مرور |
|---|---|---|
| زیرساخت | ۲۴٪ | ۴۰ دقیقه |
| امنیت | ۱۹٪ | ۳۵ دقیقه |
| نرم‌افزار | ۱۸٪ | ۳۰ دقیقه |
| مفاهیم | ۱۳٪ | ۲۰ دقیقه |
| توسعه | ۱۳٪ | ۲۰ دقیقه |
| داده | ۱۳٪ | ۲۰ دقیقه |

**دو سبک مرور**

| سبک | مناسب برای |
|---|---|
| جدول فشرده | ۲۴ ساعت آخر |
| فلش‌کارت | یک هفته آخر |

### اشکال شایع

**۱) مرور جدول بدون تست**
شناخت، نه یادآوری. خودآزمایی بزن.

**۲) خواندن همهٔ دامنه‌ها به یک اندازه**
وزن‌ها متفاوت‌اند.

**۳) نادیده گرفتن اعداد**
۸ بیت، ۴GB، ۲۵۵، ۳۳۸۹ — اعداد نمره دارند.

**۴) مرور شب آزمون**
خواب مهم‌تر است.

**۵) حفظ بدون مثال**
سؤال سناریویی می‌آید.

### نکات مهم (Tips & Tricks)

- **جدول را با خودآزمایی ترکیب کن.**
- **اعداد کلیدی را جدا کن** (۸، ۲۵۵، ۴GB، ۳۳۸۹، ۶۵۰).
- **وزن دامنه‌ها را رعایت کن.**
- **دو بار مرور، با فاصله.**
- **شب قبل، خواب.**

### خلاصه فصل

- شش دامنه، شش جدول فشرده.
- خودآزمایی ۶۰ ثانیه‌ای، شناخت را به یادآوری تبدیل می‌کند.
- وزن دامنه‌ها، اولویت مرور را تعیین می‌کند.
- اعداد کلیدی، نمره‌آورند.
- مرور بدون تست، توهم دانستن می‌سازد.

### مقدمه

این فصل، دو کار می‌کند: یک مرجع سریع از اصطلاحات می‌دهد، و مسیر پس از Tech+ را روشن می‌کند. اگر فقط یک فصل را برای بعداً نگه می‌داری، همین باشد.

### مثال‌های عملی

#### چک‌لیست نهایی آزمون

```markdown
- [ ] هر شش دامنه را مرور کردم
- [ ] آزمون شبیه‌سازی را با تایمر زدم
- [ ] دفتر اشتباهات را مرور کردم
- [ ] فلش‌کارت نقاط ضعف را زدم
- [ ] تاریخ و محل آزمون را تأیید کردم
- [ ] مدارک شناسایی آماده است
- [ ] شب قبل خواب کافی داشتم
```

### مقایسه و الگوهای مختلف

#### نقشهٔ راه پس از Tech+

| گواهی | تمرکز | پس از |
|---|---|---|
| **Tech+** | سواد پایه | — |
| **A+** | سخت‌افزار و پشتیبانی | Tech+ |
| **Network+** | شبکه | A+ |
| **Security+** | امنیت | Network+ |
| **CySA+** | تحلیل امنیت | Security+ |
| **PenTest+** | تست نفوذ | Security+ |
| **CCNA** | شبکهٔ سیسکو | Network+ |

**سه مسیر شغلی**

| اگر… | مسیر |
|---|---|
| باز کردن دستگاه‌ها را دوست داری | A+ → سخت‌افزار |
| «چرا اینترنت قطع شد» را دوست داری | Network+ → شبکه |
| پیدا کردن حفره را دوست داری | Security+ → امنیت |

### اشکال شایع

**۱) گرفتن گواهی و توقف یادگیری**
Tech+ شروع است، نه پایان.

**۲) پریدن به Security+ بدون پایهٔ شبکه**
Network+ پیش‌نیاز واقعی است.

**۳) جمع کردن گواهی بدون تجربه**
کارفرما تجربه هم می‌خواهد.

**۴) نادیده گرفتن نقشهٔ راه**
مسیر تصادفی، وقت تلف می‌کند.

**۵) فراموش کردن واژه‌نامه**
اصطلاحات، زبان مصاحبه‌اند.

### نکات مهم (Tips & Tricks)

- **واژه‌نامه را در دسترس نگه دار.**
- **نردبان گواهی را دنبال کن.**
- **تجربه بساز** (پروژه، home lab).
- **LinkedIn را به‌روز کن** با کد گواهی.
- **یادگیری را متوقف نکن.**

### خلاصه فصل

- واژه‌نامه، مرجع سریع اصطلاحات کلیدی است.
- مسیر پس از Tech+: A+ → Network+ یا Security+.
- سه مسیر شغلی بر اساس علاقه.
- گواهی بدون تجربه، کافی نیست.
- Tech+ نقطهٔ شروع است.
