> مبانی فناوری اطلاعات برای مبتدی کامل — مطابق با **نسخهٔ V6** آزمون

- **مبتدی کامل** — هیچ پیش‌نیاز یا تجربهٔ قبلی لازم نیست.
- **دانش‌آموز** که می‌خواهد ببیند فناوری برایش جذاب است یا نه.
- **کسی که مسیر شغلی عوض می‌کند** (حسابداری، پزشکی، هنر → فناوری).
- **کارمند اداری** که می‌خواهد بفهمد کامپیوترش چطور کار می‌کند.
