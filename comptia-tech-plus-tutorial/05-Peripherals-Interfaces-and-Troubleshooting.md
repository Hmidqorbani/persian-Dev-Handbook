## فصل ۱۹: پورت‌ها و رابط‌ها — USB، HDMI، Thunderbolt و بقیه

### مقدمه

پورت‌ها، «دروازه‌های» کامپیوتر هستند. اگر ندانی کدام کابل به کدام پورت می‌خورد، ممکن است ساعتی را صرف عیب‌یابی چیزی کنی که فقط کابل اشتباه است.

در آزمون Tech+، دامنهٔ زیرساخت صریحاً «Device interfaces: USB, HDMI, Ethernet, Bluetooth, and NFC» را می‌خواهد. این فصل، همه را با شکل و کاربرد می‌دهد.

### مفاهیم اساسی

**دسته‌بندی رابط‌ها**

| دسته | مثال | کار |
|---|---|---|
| **داده** | USB، Thunderbolt | انتقال فایل، اتصال دستگاه |
| **تصویر** | HDMI، DisplayPort، VGA | نمایش تصویر |
| **صدا** | ۳.۵mm، Optical | صدا |
| **شبکه** | Ethernet، Wi-Fi | اتصال شبکه |
| **بی‌سیم کوتاه‌برد** | Bluetooth، NFC | لوازم جانبی، پرداخت |

**USB — همه‌کاره‌ترین**

| نسخه | سرعت | نام تجاری |
|---|---|---|
| USB 2.0 | ۴۸۰ Mbps | Hi-Speed |
| USB 3.0 / 3.1 Gen 1 | ۵ Gbps | SuperSpeed |
| USB 3.1 Gen 2 | ۱۰ Gbps | SuperSpeed+ |
| USB 3.2 Gen 2×2 | ۲۰ Gbps | — |
| USB4 | ۴۰ Gbps | — |

**تلهٔ نام‌گذاری:** نام‌های USB چند بار عوض شده‌اند. `USB 3.0` = `USB 3.1 Gen 1` = `USB 3.2 Gen 1` — همه یک چیز با سرعت ۵ Gbps.

**انواع کانکتور USB**

| نوع | شکل | کاربرد |
|---|---|---|
| **Type-A** | مستطیلی بزرگ | پورت کامپیوتر |
| **Type-B** | مربعی | چاپگر قدیمی |
| **Micro-USB** | باریک | گوشی قدیمی |
| **USB-C** | بیضی کوچک، دوطرفه | استاندارد امروز |

**USB-C — چرا مهم است؟**

- **دوطرفه**: برعکس گذاشتن ندارد.
- **همه‌کاره**: داده، تصویر، برق.
- **Power Delivery**: تا ۲۴۰ وات (USB PD 3.1).

**هشدار:** USB-C فقط **شکل** است. یک کابل USB-C ارزان ممکن است فقط برق بدهد و داده یا تصویر نداشته باشد. کابل را با مشخصات بخواه.

**HDMI**

| نسخه | رزولوشن | نکته |
|---|---|---|
| HDMI 1.4 | 4K@30Hz | قدیمی |
| HDMI 2.0 | 4K@60Hz | رایج |
| HDMI 2.1 | 8K@60Hz، 4K@120Hz | گیم |

**مزیت:** تصویر + صدا در یک کابل. **عیب:** کابل‌های بی‌کیفیت در طول زیاد، تصویر را قطع می‌کنند.

**DisplayPort**

| نسخه | رزولوشن |
|---|---|
| DP 1.2 | 4K@60Hz |
| DP 1.4 | 8K@60Hz، 4K@144Hz |
| DP 2.0 | 16K |

**مزیت:** نرخ تازه‌سازی بالا، پشتیبانی از Daisy Chain (چند مانیتور با یک کابل).

**VGA — قدیمی ولی هنوز هست**

| مشخصه | مقدار |
|---|---|
| سیگنال | آنالوگ |
| رزولوشن | تا ۲۰۴۸×۱۵۳۶ |
| صدا | ندارد |

در پروژکتورهای قدیمی و اتاق کنفرانس هنوز دیده می‌شود.

**Ethernet (RJ-45)**

| سرعت | نام | کابل |
|---|---|---|
| ۱۰۰ Mbps | Fast Ethernet | Cat5 |
| ۱ Gbps | Gigabit | Cat5e/Cat6 |
| ۲.۵/۵ Gbps | Multi-Gig | Cat6 |
| ۱۰ Gbps | 10GbE | Cat6a/Cat7 |

**Bluetooth**

| نسخه | برد | مصرف |
|---|---|---|
| 4.0 (BLE) | ~۱۰m | بسیار کم |
| 5.0 | ~۴۰m | کم |
| 5.3 | ~۴۰m | کم |

**کاربرد:** ماوس، کیبورد، هدفون، ساعت. **محدودیت:** برد کوتاه، تداخل با Wi-Fi 2.4GHz.

**NFC**

**Near Field Communication**: برد چند سانتی‌متر.

| کاربرد | مثال |
|---|---|
| پرداخت | کارت بانکی، Apple Pay |
| بلیت | کارت مترو |
| جفت‌سازی | تگ NFC |

**تفاوت NFC و Bluetooth**

| معیار | NFC | Bluetooth |
|---|---|---|
| برد | < ۱۰ cm | ۱۰–۴۰ m |
| سرعت | کم | متوسط |
| جفت‌سازی | خودکار | دستی |
| کاربرد | پرداخت، بلیت | هدفون، ماوس |

**رابط‌های صوتی**

| رابط | کار |
|---|---|
| ۳.۵mm (TRS/TRRS) | هدفون، میکروفن |
| Optical (TOSLINK) | صدای دیجیتال |
| RCA | صوت آنالوگ |
| XLR | میکروفن حرفه‌ای |

**نکته:** TRRS (چهار حلقه) میکروفن دارد؛ TRS (سه حلقه) ندارد.

### مثال‌های عملی

**سناریوی Lab: انتخاب کابل برای سه سناریو**

**سناریو ۱: اتصال لپ‌تاپ به مانیتور ۴K@60Hz**
- لپ‌تاپ: USB-C با DisplayPort Alt Mode.
- مانیتور: HDMI 2.0 و DP 1.4.
- **انتخاب: کابل USB-C به DisplayPort** (یا HDMI 2.0).

**سناریو ۲: اتصال دو مانیتور به یک لپ‌تاپ**
- گزینهٔ ۱: دو کابل جدا (اگر دو پورت دارد).
- گزینهٔ ۲: **Daisy Chain** با DisplayPort 1.2+.
- گزینهٔ ۳: داک USB-C.

**سناریو ۳: انتقال فایل ۵۰ گیگابایتی**
| رابط | زمان تقریبی |
|---|---|
| USB 2.0 | ~۲۰ دقیقه |
| USB 3.0 | ~۲ دقیقه |
| USB4 | ~۲۰ ثانیه |
| Thunderbolt 4 | ~۲۰ ثانیه |

**سناریوی دوم: تشخیص پورت از روی شکل**

| شکل | پورت |
|---|---|
| مستطیل آبی داخل | USB 3.x Type-A |
| بیضی کوچک دوطرفه | USB-C |
| ذوزنقه با دو گوشهٔ بریده | HDMI |
| مستطیل با یک گوشهٔ بریده | DisplayPort |
| مربع با ۸ پین | RJ-45 (Ethernet) |
| دایرهٔ سبز/صورتی | صدا |

**سناریوی سوم: عیب‌یابی «مانیتور وصل است ولی تصویر نیست»**

| گام | بررسی |
|---|---|
| ۱ | کابل به GPU وصل است یا مادربرد؟ |
| ۲ | ورودی مانیتور روی کدام منبع است؟ (HDMI1/DP) |
| ۳ | کابل سالم است؟ (با کابل دیگر تست) |
| ۴ | رزولوشن پشتیبانی می‌شود؟ |
| ۵ | در سیستم دیگر تست |

### مقایسه و الگوهای مختلف

**HDMI در برابر DisplayPort**

| معیار | HDMI | DisplayPort |
|---|---|---|
| صدا | ✅ | ✅ |
| نرخ تازه‌سازی بالا | در 2.1 | از 1.4 |
| Daisy Chain | ❌ | ✅ |
| کاربرد | TV، پروژکتور | مانیتور گیم |

**سه سطح کابل**

| سطح | قیمت | کیفیت |
|---|---|---|
| ارزان بی‌نام | کم | ریسک قطعی، سرعت کم |
| استاندارد | متوسط | کافی برای اکثر کارها |
| Certified | بالا | تضمین‌شده برای ۴K/۸K |

**الگوی «کابل درست، نه کابل ارزان»**

کابل ارزان برای انتقال ۴K، باعث «تصویر سیاه می‌شود و برمی‌گردد» می‌شود. برای مانیتور گران، کابل certified بخر.

### اشکال شایع

**۱) قاطی کردن USB-C با Thunderbolt**
همهٔ USB-Cها Thunderbolt نیستند. آیکون صاعقه را ببین.

**۲) کابل USB-C فقط برق**
داده منتقل نمی‌شود. مشخصات کابل را بخوان.

**۳) HDMI ارزان برای ۴K**
تصویر قطع می‌شود. کابل با پهنای باند کافی بخر.

**۴) وصل کردن مانیتور به مادربرد با GPU مجزا**
تصویر نمی‌آید.

**۵) استفاده از VGA برای ۴K**
غیرممکن است. VGA آنالوگ و محدود است.

**۶) فرض «بلوتوث و Wi-Fi تداخل ندارند»**
هر دو روی ۲.۴GHz کار می‌کنند. هدفون قطع می‌شود.

**۷) نادیده گرفتن طول کابل**
HDMI بالای ۵ متر بدون تقویت‌کننده، مشکل‌دار است.

**۸) پورت اشتباه روی مانیتور**
ورودی روی HDMI2 است ولی کابل در HDMI1.

### نکات مهم (Tips & Tricks)

- **USB 3.0 = 3.1 Gen 1 = 3.2 Gen 1** (۵ Gbps).
- **USB-C شکل است، نه پروتکل.**
- **HDMI برای TV، DP برای مانیتور گیم.**
- **Ethernet با Cat5e حداقل.**
- **NFC برد کوتاه، Bluetooth برد متوسط.**
- **کابل certified برای ۴K.**
- **ورودی مانیتور را چک کن** — شایع‌ترین خطا.

### خلاصه فصل

- USB چهار نسل سرعت دارد و نام‌گذاری‌اش گیج‌کننده است.
- USB-C شکل است؛ پروتکل می‌تواند USB یا Thunderbolt باشد.
- HDMI و DisplayPort تصویر + صدا می‌دهند.
- VGA آنالوگ و محدود است.
- Ethernet با RJ-45؛ Cat5e حداقل امروز.
- Bluetooth و NFC دو چیز متفاوت‌اند.

## فصل ۲۰: دستگاه‌های ورودی

### مقدمه

ورودی، اولین حلقهٔ زنجیرهٔ محاسبات است: هر چیزی که به کامپیوتر «می‌گوید چه کار کند». از صفحه‌کلید تا اسکنر اثر انگشت.

این فصل، انواع ورودی و نکات عملی هرکدام را می‌دهد.

### مفاهیم اساسی

**دسته‌بندی ورودی**

| دسته | مثال |
|---|---|
| **متن** | صفحه‌کلید |
| **اشاره‌گر** | ماوس، تاچ‌پد، قلم |
| **تصویر** | دوربین، اسکنر |
| **صدا** | میکروفن |
| **زیستی** | اثر انگشت، تشخیص چهره |
| **حرکت** | ژیروسکوپ، شتاب‌سنج |

**صفحه‌کلید**

| نوع | اتصال | نکته |
|---|---|---|
| مکانیکی | USB/Bluetooth | حس بهتر، صدا دارد |
| غشایی | USB | ارزان، بی‌صدا |
| ارگونومیک | USB | کاهش فشار مچ |

**چیدمان‌ها**

| چیدمان | ویژگی |
|---|---|
| QWERTY | استاندارد انگلیسی |
| AZERTY | فرانسوی |
| فارسی استاندارد | — |

**نکتهٔ عملی:** اگر کاراکترها اشتباه تایپ می‌شوند، اول **زبان کیبورد** را در سیستم‌عامل چک کن، بعد سخت‌افزار.

**ماوس**

| نوع | نحوهٔ کار | دقت |
|---|---|---|
| اپتیکال | LED | خوب |
| لیزری | لیزر | بهتر روی سطوح |
| Trackball | توپ ثابت | بدون حرکت دست |

**DPI** (Dot Per Inch): حساسیت. بالاتر = حرکت سریع‌تر با همان جابه‌جایی.

**تاچ‌پد**

| ویژگی | معنی |
|---|---|
| Multi-touch | چند انگشت |
| Palm rejection | نادیده گرفتن کف دست |
| Haptic | بازخورد لمسی |

**اسکنر**

| نوع | کاربرد |
|---|---|
| Flatbed | اسناد، عکس |
| Sheet-fed | حجم بالا |
| Handheld | قابل حمل |
| Drum | کیفیت حرفه‌ای |

**Dpi اسکن**: ۳۰۰ dpi برای متن، ۶۰۰+ برای عکس.

**دوربین وب**

| مشخصه | مقدار مناسب |
|---|---|
| رزولوشن | ۱۰۸۰p حداقل |
| نرخ فریم | ۳۰fps |
| فوکوس | خودکار |
| میکروفن | داخلی |

**میکروفن**

| نوع | الگوی برداشت | کاربرد |
|---|---|---|
| Cardioid | جلو | صحبت تک‌نفره |
| Omnidirectional | همه‌جهت | کنفرانس |
| Condenser | حساس | استودیو |
| Dynamic | مقاوم | اجرای زنده |

**ورودی بیومتریک**

| نوع | دقت | نکته |
|---|---|---|
| اثر انگشت | بالا | ارزان |
| تشخیص چهره | متوسط تا بالا | نور مهم است |
| اسکن عنبیه | بسیار بالا | گران |
| صدا | متوسط | قابل جعل |

**هشدار امنیتی:** بیومتریک، «رمز» نیست؛ «نام کاربری» است. اگر اثر انگشتت لو برود، نمی‌توانی عوضش کنی. همیشه با یک عامل دوم (رمز یا توکن) ترکیب کن.

### مثال‌های عملی

**سناریوی Lab: «کیبورد کار نمی‌کند»**

| گام | بررسی | نتیجه |
|---|---|---|
| ۱ | کابل/باتری | کابل در پورت دیگر تست شد |
| ۲ | چراغ Num Lock | روشن می‌شود؟ |
| ۳ | دستگاه دیگر | روی لپ‌تاپ دیگر کار می‌کند |
| ۴ | Device Manager | «Unknown Device» دیده می‌شود |
| ۵ | درایور | نصب مجدد |

**تشخیص نهایی:** درایور خراب بعد از آپدیت ویندوز.

**سناریوی دوم: «ماوس می‌پرد»**

| علت | راه‌حل |
|---|---|
| سطح نامناسب (شیشه) | زیرپایی ماوس |
| باتری ضعیف (بی‌سیم) | تعویض باتری |
| تداخل Wi-Fi 2.4GHz | تغییر کانال یا استفاده از USB receiver نزدیک |
| DPI بالا | کاهش در تنظیمات |
| گرد و غبار روی سنسور | تمیز کردن |

**سناریوی سوم: انتخاب ورودی برای سه کاربر**

| کاربر | نیاز | انتخاب |
|---|---|---|
| تایپیست | تایپ طولانی | کیبورد مکانیکی ارگونومیک |
| طراح گرافیک | دقت | ماوس با DPI بالا + قلم |
| حسابدار | اعداد | کیبورد با Numpad |

### مقایسه و الگوهای مختلف

**سه نوع اتصال**

| اتصال | مزیت | عیب |
|---|---|---|
| USB سیمی | پایدار، بدون باتری | کابل |
| Bluetooth | بدون دانگل | جفت‌سازی، باتری |
| دانگل 2.4GHz | تأخیر کم | اشغال پورت |

**الگوی «ورودی با کیفیت، عمر طولانی»**

ماوس و کیبورد، پرلمس‌ترین قطعات‌اند. خرید ارزان، تعویض مکرر می‌آورد. یک ماوس خوب، ۵ سال دوام می‌آورد.

### اشکال شایع

**۱) قاطی کردن زبان کیبورد با خرابی سخت‌افزار**
اول چیدمان را چک کن.

**۲) باتری ضعیف در دستگاه بی‌سیم**
«قطع و وصل می‌شود» = باتری.

**۳) سطح نامناسب برای ماوس اپتیکال**
شیشه و پارچهٔ براق، سنسور را گیج می‌کنند.

**۴) تداخل USB 3.0 با دانگل 2.4GHz**
دانگل را به پورت دور از USB 3.0 بزن.

**۵) نصب نکردن درایور اسکنر**
دستگاه شناخته می‌شود ولی کار نمی‌کند.

**۶) اسکن با dpi کم**
متن ناخوانا. ۳۰۰ dpi حداقل.

**۷) اعتماد به بیومتریک تنها**
اثر انگشت لو رفته = دسترسی دائمی.

**۸) نادیده گرفتن ارگونومی**
درد مچ و گردن، هزینهٔ بلندمدت.

### نکات مهم (Tips & Tricks)

- **ورودی = اولین حلقه.**
- **زبان کیبورد را اول چک کن.**
- **DPI = حساسیت ماوس.**
- **۳۰۰ dpi برای اسکن متن.**
- **بیومتریک + عامل دوم.**
- **دانگل را دور از USB 3.0 بگذار.**
- **ارگونومی، بخشی از انتخاب است.**

### خلاصه فصل

- شش دستهٔ ورودی: متن، اشاره‌گر، تصویر، صدا، زیستی، حرکت.
- کیبورد مکانیکی/غشایی؛ چیدمان مهم است.
- DPI حساسیت ماوس را تعیین می‌کند.
- اسکنر flatbed برای اسناد، sheet-fed برای حجم.
- بیومتریک جای رمز را نمی‌گیرد.
- تداخل ۲.۴GHz شایع‌ترین مشکل بی‌سیم است.

<a name="ch-21"></a>
## فصل ۲۱: دستگاه‌های خروجی — مانیتور، پروژکتور، بلندگو

### مقدمه

خروجی، جایی است که کامپیوتر «حرفش را می‌زند». مانیتور، پروژکتور، بلندگو و چاپگر. انتخاب اشتباه، می‌تواند باعث خستگی چشم، صدای بد، یا تصویر بی‌کیفیت شود.

### مفاهیم اساسی

**مانیتور — پنل‌ها**

| پنل | مزیت | عیب | مناسب برای |
|---|---|---|---|
| **IPS** | رنگ دقیق، زاویهٔ دید | گران‌تر | طراحی، کار عمومی |
| **VA** | کنتراست بالا | پاسخ‌دهی کندتر | فیلم |
| **TN** | ارزان، سریع | رنگ ضعیف | گیم ارزان |

**مشخصات کلیدی**

| مشخصه | معنی | مقدار مناسب |
|---|---|---|
| **اندازه** | قطر صفحه | ۲۴" کار، ۲۷" راحت |
| **رزولوشن** | تعداد پیکسل | ۱۹۲۰×۱۰۸۰ حداقل |
| **نرخ تازه‌سازی** | Hz | ۶۰Hz کار، ۱۴۴Hz گیم |
| **زمان پاسخ** | ms | < ۵ms |
| **کنتراست** | نسبت روشنایی | ۱۰۰۰:۱ حداقل |
| **روشنایی** | nits | ۲۵۰ کار، ۴۰۰+ HDR |

**رزولوشن‌های رایج**

| نام | پیکسل | نسبت |

| HD | 1280×720 | 16:9 |
| Full HD | 1920×1080 | 16:9 |
| QHD | 2560×1440 | 16:9 |
| 4K UHD | 3840×2160 | 16:9 |
| Ultrawide | 3440×1440 | 21:9 |

**پروژکتور**

| مشخصه | معنی |
|---|---|
| **لومن (Lumens)** | روشنایی |
| **کنتراست** | تفاوت روشن/تیره |
| **رزولوشن بومی** | واقعی، نه پشتیبانی‌شده |
| **فاصلهٔ پرتاب** | فاصله تا پرده |

| محیط | لومن لازم |
|---|---|
| اتاق تاریک | ۱٬۵۰۰–۲٬۵۰۰ |

| اتاق روشن | ۵٬۰۰۰+ |

**تله:** «پشتیبانی از 4K» با «رزولوشن بومی 4K» فرق دارد. پروژکتور ارزان ممکن است 4K را بپذیرد ولی 720p نمایش دهد.

**بلندگو**

|---|---|

**هدفون**

|---|---|---|

**چاپگر — در فصل بعد کامل**

انواع: جوهرافشان، لیزری، حرارتی، ماتریس نقطه‌ای، ۳بعدی.

### مثال‌های عملی

**سناریوی Lab: انتخاب مانیتور**

**کاربر A: کار اداری ۸ ساعت**
- نیاز: خوانایی، کاهش خستگی چشم.
- **انتخاب: ۲۴" IPS، ۱۹۲۰×۱۰۸۰، ۶۰Hz، پایهٔ ارتفاع‌تنظیم.**

**کاربر B: گیمر رقابتی**
- نیاز: نرخ تازه‌سازی بالا، پاسخ سریع.
- **انتخاب: ۲۷" TN/IPS، ۱۴۴Hz، ۱ms.**

**کاربر C: طراح گرافیک**
- نیاز: دقت رنگ.
- **انتخاب: ۲۷" IPS 4K، پوشش ۱۰۰٪ sRGB، کالیبراسیون.**

**جدول تصمیم**

| اگر… | اولویت |
|---|---|
| متن زیاد | IPS + اندازهٔ بزرگ |
| گیم | نرخ تازه‌سازی + پاسخ |
| طراحی | دقت رنگ + رزولوشن |
| فیلم | کنتراست + اندازه |

**سناریوی دوم: محاسبهٔ لومن پروژکتور**

اتاق جلسه ۵×۴ متر، پرده ۲ متر عرض، نور متوسط.

```
لومن ≈ ۳٬۰۰۰ (برای اتاق نیمه‌روشن)
اگر پرده بزرگ‌تر: لومن بیشتر
اگر پنجره زیاد: ۴٬۰۰۰+
```

**سناریوی سوم: «متن روی مانیتور تار است»**

| علت | راه‌حل |
|---|---|
| رزولوشن غیربومی | تنظیم روی رزولوشن native |
| مقیاس‌بندی اشتباه | ۱۰۰٪ یا ۱۲۵٪ |
| کابل آنالوگ (VGA) | کابل دیجیتال |
| ClearType خاموش | فعال‌سازی در ویندوز |

### مقایسه و الگوهای مختلف

**سه سطح مانیتور**

| سطح | مشخصات | قیمت |
|---|---|---|
| اقتصادی | ۲۲" TN، 1080p | کم |
| متوسط | ۲۴–۲۷" IPS، 1080p/1440p | متوسط |
| حرفه‌ای | ۲۷" IPS 4K، کالیبره | بالا |

**الگوی «دو مانیتور، بهره‌وری بیشتر»**

مطالعات نشان می‌دهند دو مانیتور می‌تواند بهره‌وری را ۲۰–۳۰٪ افزایش دهد. برای کار با متن و مرجع همزمان، ارزشمند است.

### اشکال شایع

**۱) رزولوشن غیربومی**
تصویر تار. همیشه native.

**۲) مانیتور بزرگ با رزولوشن کم**
پیکسل‌ها دیده می‌شوند.

**۳) پروژکتور با لومن کم در اتاق روشن**
تصویر شسته. لومن کافی.

**۴) «پشتیبانی 4K» به‌جای «بومی 4K»**
تصویر 720p. مشخصات را دقیق بخوان.

**۵) نادیده گرفتن پایهٔ ارگونومیک**
گردن‌درد. پایهٔ ارتفاع‌تنظیم یا بازوی مانیتور.

**۶) روشنایی زیاد در اتاق تاریک**
خستگی چشم. نور محیط را تنظیم کن.

**۷) کابل VGA برای ۱۰۸۰p**
کیفیت کم. دیجیتال استفاده کن.

**۸) بلندگوی ارزان برای میکس**
صدای اشتباه. مانیتور استودیویی.

### نکات مهم (Tips & Tricks)

- **IPS برای رنگ، TN برای سرعت، VA برای کنتراست.**
- **رزولوشن native** همیشه.
- **۱۴۴Hz برای گیم، ۶۰Hz برای کار.**
- **لومن پروژکتور را با نور اتاق هماهنگ کن.**
- **«بومی» را از «پشتیبانی» جدا کن.**
- **پایهٔ ارگونومیک، سرمایه‌گذاری سلامت است.**
- **کابل دیجیتال برای تصویر شفاف.**

### خلاصه فصل

- سه پنل: IPS (رنگ)، VA (کنتراست)، TN (سرعت).
- رزولوشن native، مهم‌ترین عامل شفافیت.
- نرخ تازه‌سازی برای گیم مهم است.
- لومن پروژکتور باید با نور محیط بخواند.
- «پشتیبانی» با «بومی» فرق دارد.
- ارگونومی، بخشی از انتخاب مانیتور است.

## فصل ۲۲: چاپگرها و اسکنرها

### مقدمه

چاپگر، یکی از پر دردسرترین دستگاه‌های جانبی است. در آزمون Tech+، انواع چاپگر و روش نصب درایور جزو دامنهٔ زیرساخت است. در عمل هم، «چاپ نمی‌کند» یکی از پرتکرارترین تیکت‌های پشتیبانی است.

### مفاهیم اساسی

**انواع چاپگر**

| نوع | نحوهٔ کار | هزینهٔ صفحه | کیفیت |
|---|---|---|---|
| **جوهرافشان (Inkjet)** | پاشش جوهر | بالا | عکس عالی |
| **لیزری (Laser)** | تونر + حرارت | کم | متن عالی |
| **حرارتی (Thermal)** | حرارت روی کاغذ | کم | رسید |
| **ماتریس نقطه‌ای** | ضربهٔ سوزن | کم | چندنسخه‌ای |
| **۳بعدی (3D)** | لایه‌گذاری فیلامنت | بالا | قطعه |

**جوهرافشان**

```
کارتریج جوهر → هد چاپ → پاشش قطرات → کاغذ
```

| مزیت | عیب |
|---|---|
| کیفیت عکس بالا | خشک شدن جوهر |
| قیمت اولیهٔ کم | هزینهٔ جوهر بالا |
| چاپ رنگی ارزان | سرعت کم |

**لیزری**

```
تونر → درام → لیزر → حرارت → کاغذ
```

| مزیت | عیب |
|---|---|
| سرعت بالا | قیمت اولیهٔ بالا |
| هزینهٔ صفحهٔ کم | چاپ عکس ضعیف‌تر |
| متن شارپ | تونر گران |

**حرارتی**

| نوع | کاربرد |
|---|---|
| Direct Thermal | رسید فروشگاه |
| Thermal Transfer | برچسب با دوام |

**مزیت:** بدون جوهر. **عیب:** کاغذ مخصوص، محو شدن با گرما.

**ماتریس نقطه‌ای**

هنوز در بعضی جاها (فاکتور چندنسخه‌ای، بانک) استفاده می‌شود. سر و صدا دارد، کیفیت کم، ولی ارزان و مقاوم.

**مشخصات کلیدی چاپگر**

| مشخصه | معنی |
|---|---|
| **ppm** | صفحه در دقیقه |
| **dpi** | چگالی چاپ |
| **Duplex** | چاپ دوطرفه |
| **Network** | اتصال شبکه |
| **Wi-Fi Direct** | چاپ بدون روتر |

**اتصال چاپگر**

| اتصال | مزیت | عیب |
|---|---|---|
| USB | ساده، پایدار | فقط یک دستگاه |
| Ethernet | اشتراک | نیاز به کابل |
| Wi-Fi | بی‌سیم | پیکربندی |
| Bluetooth | قابل حمل | برد کم |

**درایور — چرا مهم است؟**

درایور، مترجم بین سیستم‌عامل و چاپگر است. سه گزینه:

| نوع درایور | مزیت | عیب |
|---|---|---|
| **سازنده** | همهٔ قابلیت‌ها | حجم زیاد |
| **عمومی (Generic)** | نصب آسان | قابلیت کم |
| **Universal (مثل PCL/PostScript)** | یک درایور، چند چاپگر | ممکن است بعضی ویژگی‌ها نباشد |

**نصب چاپگر — سه روش**

1. **Plug and Play**: ویندوز خودش تشخیص می‌دهد.
2. **نصب دستی**: از سایت سازنده، درایور را دانلود کن.
3. **چاپگر شبکه‌ای**: با IP اضافه کن.

**صف چاپ (Print Queue)**

وقتی چاپ می‌فرستی، سند در صف می‌رود. اگر گیر کند:

| علت | راه‌حل |
|---|---|
| سند بزرگ | صبر یا حذف |
| چاپگر آفلاین | بررسی اتصال |
| درایور خراب | نصب مجدد |
| Spooler متوقف | ری‌استارت سرویس |

### مثال‌های عملی

**سناریوی Lab: «چاپگر چاپ نمی‌کند» — درخت تصمیم**

```
۱) چاپگر روشن است؟ چراغ خطا؟
   ├── نه → برق/کابل
   └── بله ↓

۲) در صف چاپ سند هست؟
   ├── نه → سند ارسال نشده (برنامه/درایور)
   └── بله ↓

۳) صف گیر کرده؟
   ├── بله → حذف صف، ری‌استارت Spooler
   └── نه ↓

۴) چاپگر «آفلاین» است؟
   ├── بله → اتصال (USB/شبکه) را چک کن
   └── نه ↓

۵) تست صفحه (Test Page) کار می‌کند؟
   ├── بله → مشکل در برنامهٔ خاص
   └── نه → درایور/سخت‌افزار
```

**ری‌استارت Spooler در ویندوز:**

```powershell
Restart-Service -Name Spooler -Force
```

**سناریوی دوم: انتخاب چاپگر**

| کاربر | نیاز | انتخاب |
|---|---|---|
| دفتر کوچک | متن، کم‌رنگ | لیزری سیاه‌وسفید |
| عکاسی | عکس رنگی | جوهرافشان عکس |
| فروشگاه | رسید | حرارتی |
| خانه | گاه‌به‌گاه | جوهرافشان ارزان یا لیزری کوچک |

**سناریوی سوم: هزینهٔ واقعی چاپ**

| نوع | قیمت دستگاه | هزینهٔ صفحه | ۱۰۰۰ صفحه |
|---|---|---|---|
| جوهرافشان ارزان | کم | بالا | گران |
| لیزری متوسط | متوسط | کم | ارزان |

**درس:** برای چاپ زیاد، لیزری ارزان‌تر تمام می‌شود.

**سناریوی چهارم: چاپگر شبکه‌ای**

```markdown
۱. چاپگر را با کابل به روتر وصل کن
۲. IP چاپگر را از پنل آن بردار (مثلاً 192.168.1.50)
۳. در ویندوز: Settings → Printers → Add → IP
۴. درایور را نصب کن
۵. Test Page بزن
```

**نکته:** IP ثابت بده (Static یا DHCP Reservation)، وگرنه بعد از ری‌استارت روتر عوض می‌شود.

### مقایسه و الگوهای مختلف

**جوهرافشان در برابر لیزری**

| معیار | جوهرافشان | لیزری |
|---|---|---|
| قیمت اولیه | کم | بالا |
| هزینهٔ صفحه | بالا | کم |
| سرعت | کم | بالا |
| کیفیت عکس | عالی | متوسط |
| متن | خوب | عالی |
| خشک شدن | دارد | ندارد |

**الگوی «چاپگر مناسب، نه چاپگر ارزان»**

چاپگر ارزان با کارتریج گران، در بلندمدت گران‌تر است. هزینهٔ صفحه را حساب کن.

### اشکال شایع

**۱) جوهر خشک‌شده**
چاپگر هفته‌ها استفاده نشده. هد را تمیز کن یا کارتریج را عوض کن.

**۲) کاغذ گیرکرده**
کاغذ نامناسب یا رطوبت. کاغذ را درست بگذار.

**۳) چاپ راه‌راه**
نازل‌های هد گرفته. Head Cleaning.

**۴) درایور اشتباه**
چاپگر شناخته می‌شود ولی چاپ نمی‌کند.

**۵) صف چاپ گیرکرده**
Spooler را ری‌استارت کن.

**۶) IP چاپگر عوض شده**
با DHCP رزرو ثابت کن.

**۷) تونر تقلبی**
کیفیت پایین و خرابی درام.

**۸) چاپ دوطرفه اشتباه**
کاغذ برعکس. تنظیمات Duplex را چک کن.

### نکات مهم (Tips & Tricks)

- **لیزری برای متن، جوهرافشان برای عکس.**
- **هزینهٔ صفحه را حساب کن، نه قیمت دستگاه.**
- **Test Page** اولین تست است.
- **Spooler** را ری‌استارت کن.
- **IP ثابت** برای چاپگر شبکه‌ای.
- **درایور سازنده** برای قابلیت کامل.
- **کاغذ مناسب** برای هر چاپگر.

### خلاصه فصل

- پنج نوع چاپگر: جوهرافشان، لیزری، حرارتی، ماتریس، ۳بعدی.
- لیزری هزینهٔ صفحهٔ کم، جوهرافشان کیفیت عکس.
- درایور، مترجم بین سیستم و چاپگر است.
- صف چاپ، منبع بیشتر مشکلات است.
- IP ثابت برای چاپگر شبکه‌ای ضروری است.
- Test Page، اولین گام عیب‌یابی است.

## فصل ۲۳: نصب و پیکربندی دستگاه جانبی — Lab کامل

### مقدمه

این فصل، همهٔ فایل را در یک سناریوی عملی جمع می‌کند: راه‌اندازی یک میز کار کامل با مانیتور، چاپگر، اسکنر و وبکم.

### مفاهیم اساسی

**ترتیب درست نصب**

```
۱) آماده‌سازی (برق قطع، ابزار)
۲) اتصال فیزیکی
۳) روشن کردن
۴) شناسایی توسط سیستم
۵) نصب درایور
۶) تست
۷) مستندسازی
```

**قاعدهٔ طلایی درایور**

| ترتیب | چرا |
|---|---|
| اول درایور، بعد اتصال | برای دستگاه‌های قدیمی |
| اول اتصال، بعد درایور | برای Plug and Play |

اگر مطمئن نیستی، **دستورالعمل سازنده** را بخوان.

**Plug and Play (PnP)**

سیستم‌عامل دستگاه را شناسایی و درایور را خودکار نصب می‌کند.

| مزیت | عیب |
|---|---|
| ساده | درایور عمومی، نه کامل |

**Device Manager**

ابزار اصلی ویندوز برای مدیریت دستگاه‌ها.

| علامت | معنی |
|---|---|
| ⚠️ مثلث زرد | درایور مشکل دارد |
| ❌ ضربدر | غیرفعال |
| ❓ علامت سؤال | ناشناخته |

### مثال‌های عملی

**سناریوی Lab: راه‌اندازی میز کار**

**تجهیزات:**
- لپ‌تاپ با USB-C
- مانیتور ۲۷" با HDMI و DP
- چاپگر لیزری با USB و Ethernet
- اسکنر flatbed با USB
- وبکم USB
- هاب USB-C

**گام ۱ — نقشهٔ اتصال**

```
لپ‌تاپ (USB-C)
   └── هاب USB-C
         ├── HDMI → مانیتور
         ├── USB → چاپگر
         ├── USB → اسکنر
         └── USB → وبکم
```

**گام ۲ — اتصال فیزیکی**

| دستگاه | پورت | نکته |
|---|---|---|
| مانیتور | HDMI | ورودی درست |
| چاپگر | USB (یا Ethernet) | کابل کوتاه |
| اسکنر | USB | پورت مستقیم |
| وبکم | USB | نه روی هاب اشتراکی |

**نکته:** وبکم را مستقیم به لپ‌تاپ بزن، نه هاب — پهنای باند.

**گام ۳ — شناسایی**

```
Settings → Bluetooth & devices → Devices
```

باید همه را ببینی. اگر «Unknown» بود، درایور.

**گام ۴ — نصب درایور**

| دستگاه | منبع درایور |
|---|---|
| مانیتور | معمولاً لازم نیست |
| چاپگر | سایت سازنده |
| اسکنر | سایت سازنده (TWAIN) |
| وبکم | معمولاً PnP |

**گام ۵ — تست**

```markdown
- [ ] مانیتور: رزولوشن native، ۶۰Hz
- [ ] چاپگر: Test Page
- [ ] اسکنر: اسکن ۳۰۰dpi
- [ ] وبکم: تست در برنامهٔ کنفرانس
```

**گام ۶ — مستندسازی**


### مقایسه و الگوهای مختلف

**سه سبک اتصال**

| سبک | مزیت | عیب |
|---|---|---|
| مستقیم | پایدار، سریع | پورت کم |
| هاب | چند دستگاه | اشتراک پهنای باند |
| داک | یک کابل، همه‌چیز | گران |

**الگوی «داک برای لپ‌تاپ»**

داک USB-C، برق + تصویر + شبکه + USB می‌دهد. یک کابل وصل، همه‌چیز آماده. برای کارمندانی که روزانه جابه‌جا می‌شوند، عالی است.

### اشکال شایع

**۱) نصب درایور قبل از اتصال (یا برعکس)**
بسته به دستگاه. دستورالعمل را بخوان.

**۲) هاب بدون برق**
دستگاه‌های پرمصرف کار نمی‌کنند.

**۳) وبکم روی هاب اشتراکی**
تصویر می‌پرد.

**۴) کابل HDMI طولانی و ارزان**
تصویر قطع می‌شود.

**۵) فراموش کردن رزولوشن native**
تصویر تار.

**۶) نصب نکردن TWAIN**
اسکنر شناخته می‌شود ولی برنامه نمی‌بیند.

**۷) مستند نکردن**
دفعهٔ بعد از صفر شروع می‌کنی.

**۸) رها کردن کابل‌ها**
خرابی و سردرگمی.

### نکات مهم (Tips & Tricks)

- **ترتیب نصب را رعایت کن.**
- **Device Manager** اولین ابزار.
- **وبکم مستقیم، نه هاب.**
- **Test Page** برای چاپگر.
- **۳۰۰dpi** برای اسکن.
- **مستندسازی با جدول.**
- **کابل‌ها را برچسب بزن.**

### خلاصه فصل

- ترتیب: آماده‌سازی، اتصال، شناسایی، درایور، تست، مستندسازی.
- PnP ساده است ولی درایور کامل نمی‌دهد.
- Device Manager سه علامت دارد: هشدار، غیرفعال، ناشناخته.
- هاب بدون برق، دستگاه پرمصرف را پشتیبانی نمی‌کند.
- تست و مستندسازی، بخشی از نصب است.
