<a name="ch-14"></a>
## فصل ۱۴: مادربرد — صفحه‌ای که همه‌چیز را به هم وصل می‌کند

### مقدمه

اگر کامپیوتر را یک شهر بدانیم، مادربرد **شبکهٔ خیابان‌ها** است. CPU، RAM، دیسک، کارت گرافیک و پورت‌ها همه به آن وصل می‌شوند. اگر مادربرد خراب باشد، هیچ قطعه‌ای کار نمی‌کند — حتی اگر همه سالم باشند.

در آزمون Tech+، مادربرد به‌عنوان «قطعهٔ اصلی اتصال» معرفی می‌شود. این فصل، اجزای آن را با کارکرد واقعی نشان می‌دهد.

### مفاهیم اساسی

**اجزای اصلی مادربرد**

| جزء | کار | نکته |
|---|---|---|
| **سوکت CPU** | اتصال پردازنده | Intel و AMD سازگار نیستند |
| **اسلات‌های RAM** | اتصال حافظه | معمولاً ۲ یا ۴ عدد |
| **تراشهٔ چیپست (Chipset)** | مدیریت ارتباطات | پل شمالی/جنوبی در معماری قدیم |
| **اسلات PCIe** | کارت‌های توسعه | گرافیک، NIC، صدا |
| **کانکتور SATA** | دیسک‌های قدیمی‌تر | HDD، SSD 2.5" |
| **کانکتور M.2** | SSD مدرن | NVMe |
| **باتری CMOS** | نگه‌داشتن تنظیمات BIOS | سکه‌ای، ۵–۱۰ سال |
| **BIOS/UEFI** | راه‌اندازی اولیه | نرم‌افزار روی تراشه |
| **هدرهای پنل جلو** | پاور، ریست، LED | سیم‌های ریز |

**فرم‌فاکتور (Form Factor)**

| فرم‌فاکتور | اندازه | مناسب برای |
|---|---|---|
| **ATX** | ۳۰۵×۲۴۴ mm | دسکتاپ کامل |
| **Micro-ATX** | ۲۴۴×۲۴۴ mm | دسکتاپ متوسط |
| **Mini-ITX** | ۱۷۰×۱۷۰ mm | سیستم کوچک |
| **E-ATX** | بزرگ‌تر از ATX | ورک‌استیشن |

**قاعده:** فرم‌فاکتور مادربرد باید با کیس و پاور سازگار باشد.

**چیپست (Chipset) چیست؟**

چیپست، «پلیس راه» مادربرد است: تعیین می‌کند کدام قطعات با چه سرعتی حرف بزنند و چه قابلیت‌هایی وجود داشته باشد.

| چیپست | ویژگی |
|---|---|
| ردهٔ پایین (H/B) | قابلیت‌های محدود، ارزان |
| ردهٔ بالا (Z/X) | اورکلاک، PCIe بیشتر، گران |

**نکته:** چیپست باید با نسل CPU سازگار باشد. CPU نسل جدید روی مادربرد قدیمی کار نمی‌کند (سوکت متفاوت).

**BIOS در برابر UEFI**

| معیار | BIOS | UEFI |
|---|---|---|
| رابط | متنی، محدود | گرافیکی، ماوس |
| دیسک | MBR (حداکثر ۲TB) | GPT (بسیار بزرگ‌تر) |
| بوت | کند | سریع (Fast Boot) |
| امنیت | ندارد | Secure Boot |

**امروز تقریباً همه UEFI دارند**، ولی مردم هنوز می‌گویند «برو BIOS».

**Secure Boot چیست؟**

UEFI فقط کد امضاشده را اجرا می‌کند. مانع از بوت بدافزار (Bootkit) می‌شود. در نصب بعضی سیستم‌عامل‌ها (مثل لینوکس‌های قدیمی) باید خاموش شود — که یک ریسک است.

**چرا باتری CMOS مهم است؟**

باتری سکه‌ای، تنظیمات BIOS (زمان، ترتیب بوت، تنظیمات سخت‌افزار) را نگه می‌دارد. اگر تمام شود:

- ساعت سیستم عقب می‌رود.
- تنظیمات به حالت پیش‌فرض برمی‌گردد.
- ممکن است پیام «CMOS checksum error» ببینی.

**راه‌حل:** تعویض باتری CR2032 (ارزان).

### مثال‌های عملی

**سناریوی Lab: خواندن یک مادربرد**

روی مادربرد نوشته: `B650M-PLUS`

| بخش | معنی |
|---|---|
| `B650` | چیپست AMD، ردهٔ متوسط |
| `M` | Micro-ATX |
| `PLUS` | نسخهٔ بهبودیافته |

حالا می‌دانی:

- سوکت: AM5 (سازگار با Ryzen نسل جدید).
- فرم: Micro-ATX (کیس متوسط).
- RAM: DDR5.

**سناریوی دوم: عیب‌یابی «کامپیوتر روشن می‌شود ولی تصویر نمی‌آید»**

| گام | بررسی |
|---|---|
| ۱ | کابل مانیتور وصل است؟ به کدام پورت؟ |
| ۲ | کارت گرافیک درست نشسته؟ |
| ۳ | RAM درست در اسلات؟ (تا کلیک نشنیده، جا نرفته) |
| ۴ | چراغ‌های عیب‌یابی مادربرد (Debug LED) چه می‌گویند؟ |
| ۵ | بوق‌های BIOS (Beep Code) |

**نکتهٔ حرفه‌ای:** اکثر مادربردهای مدرن یک LED کوچک دارند که نشان می‌دهد کدام قطعه مشکل دارد: CPU، DRAM، VGA، BOOT.

**سناریوی سوم: ارتقای RAM**

مادربرد ۴ اسلات دارد، دو تا پر است (۲×۸GB). می‌خواهی ۳۲GB کنی:

| گزینه | نتیجه | نکته |
|---|---|---|
| ۲×۱۶GB جدید | ۳۲GB، دو اسلات آزاد | بهترین |
| ۲×۸GB اضافه | ۳۲GB، چهار اسلات پر | ارزان‌تر، ولی سرعت ممکن است کم شود |
| ۱×۱۶GB اضافه | ۲۴GB | نامتقارن، عملکرد کمتر |

**قاعده:** جفت‌های هم‌اندازه در اسلات‌های هم‌رنگ (Dual Channel).

### مقایسه و الگوهای مختلف

**سه سطح مادربرد**

| سطح | مناسب برای | قیمت نسبی |
|---|---|---|
| اقتصادی (H610/A620) | کار اداری | کم |
| متوسط (B650/B760) | اکثر کاربران | متوسط |
| بالا (X670/Z790) | اورکلاک، گیم | بالا |

**الگوی «سازگاری سه‌گانه»**

قبل از خرید، سه چیز باید هماهنگ باشند:

```
سوکت CPU = چیپست مادربرد = نسل RAM
```

اگر یکی نخواند، قطعه کار نمی‌کند.

### اشکال شایع

**۱) خرید CPU بدون چک کردن سوکت**
`LGA1700` با `AM5` کار نمی‌کند. سازگاری را چک کن.

**۲) نادیده گرفتن فرم‌فاکتور**
مادربرد ATX در کیس Mini-ITX جا نمی‌شود.

**۳) فراموش کردن باتری CMOS**
«ساعت عقب می‌رود» یک علامت کلاسیک است.

**۴) دست زدن به قطعات بدون تخلیهٔ الکتریسیتهٔ ساکن**
ESD می‌تواند قطعه را بی‌صدا خراب کند. قبل از کار، بدنهٔ فلزی را لمس کن.

**۵) فشار دادن RAM بدون شنیدن کلیک**
RAM جا نرفته، سیستم بوت نمی‌شود.

**۶) اشتباه در ترتیب بوت**
سیستم از USB بوت می‌شود در حالی که باید از دیسک.

**۷) خاموش کردن Secure Boot بدون دلیل**
ریسک Bootkit.

**۸) نادیده گرفتن به‌روزرسانی BIOS**
نسخهٔ قدیمی ممکن است با CPU جدید سازگار نباشد.

### نکات مهم (Tips & Tricks)

- **اجزای مادربرد** را با کارشان حفظ کن.
- **سازگاری سه‌گانه**: سوکت، چیپست، RAM.
- **فرم‌فاکتور** را با کیس چک کن.
- **Debug LED** بهترین دوست عیب‌یابی است.
- **باتری CR2032** را در کیف ابزار داشته باش.
- **قبل از کار، ESD را تخلیه کن.**
- **UEFI + GPT** استاندارد امروز است.

### خلاصه فصل

- مادربرد، همهٔ قطعات را به هم وصل می‌کند.
- فرم‌فاکتورها: ATX، Micro-ATX، Mini-ITX.
- چیپست، قابلیت‌ها و سازگاری را تعیین می‌کند.
- UEFI جای BIOS را گرفته؛ Secure Boot امنیت بوت می‌دهد.
- باتری CMOS تنظیمات را نگه می‌دارد.
- سازگاری سوکت، چیپست و RAM را قبل از خرید چک کن.

## فصل ۱۵: CPU — مغز کامپیوتر

### مقدمه

CPU (Central Processing Unit) هر دستوری را اجرا می‌کند: از باز کردن یک فایل تا محاسبهٔ فیزیک یک بازی. اما «سرعت CPU» فقط GHz نیست — و این یکی از پرتکرارترین اشتباهات مبتدی‌هاست.

### مفاهیم اساسی

**چرخهٔ اجرا**

```
Fetch (واکشی) → Decode (رمزگشایی) → Execute (اجرا) → Store (ذخیره)
       ↑                                                    │
       └────────────────────────────────────────────────────┘
```

این چرخه، میلیاردها بار در ثانیه تکرار می‌شود.

**اجزای CPU**

| جزء | کار |
|---|---|
| **هسته (Core)** | واحد اجرای دستور |
| **رشته (Thread)** | جریان اجرا در یک هسته |
| **کش (Cache)** | حافظهٔ فوق‌سریع نزدیک هسته |
| **کنترلر حافظه** | ارتباط با RAM |
| **GPU یکپارچه** | گرافیک پایه (در بعضی CPUها) |

**هسته و رشته**

| مفهوم | معنی | مثال |
|---|---|---|
| **هستهٔ فیزیکی** | واحد واقعی روی تراشه | ۸ هسته |
| **رشتهٔ منطقی** | جریان اجرا | ۱۶ رشته با Hyper-Threading |

**Hyper-Threading (Intel) / SMT (AMD)**: هر هسته، دو رشته را همزمان مدیریت می‌کند. عملکرد ۲۰–۳۰٪ بهتر، نه دو برابر.

**کش (Cache)**

| سطح | اندازه | سرعت | محل |
|---|---|---|---|
| **L1** | ۳۲–۱۲۸ KB | فوق‌سریع | داخل هسته |
| **L2** | ۲۵۶ KB–۲ MB | سریع | داخل هسته |
| **L3** | ۸–۶۴ MB | متوسط | مشترک |

**چرا کش مهم است؟** دسترسی به RAM حدود ۱۰۰ نانوثانیه طول می‌کشد؛ به L1 حدود ۱ نانوثانیه. کش بزرگ‌تر = انتظار کمتر.

**فرکانس (Clock Speed)**

| واحد | معنی |
|---|---|
| GHz | میلیارد چرخه در ثانیه |

**تلهٔ بزرگ:** `۳.۵ GHz` همیشه سریع‌تر از `۳.۰ GHz` نیست.

| عامل | اثر |
|---|---|
| معماری (IPC) | دستور بیشتر در هر چرخه |
| تعداد هسته | کار موازی |
| کش | انتظار کمتر |
| فرکانس | چرخهٔ بیشتر |

**مثال:** یک CPU جدید ۳.۰ GHz می‌تواند از یک CPU قدیمی ۴.۰ GHz سریع‌تر باشد، چون در هر چرخه کار بیشتری انجام می‌دهد.

**معماری‌ها**

| معماری | سازنده | ویژگی |
|---|---|---|
| **x86-64** | Intel/AMD | دسکتاپ و سرور |
| **ARM** | ARM Ltd. | موبایل، تبلت، مک جدید |
| **RISC-V** | بنیاد باز | نوظهور |

**نکته:** اپلیکیشن‌های x86 روی ARM اجرا نمی‌شوند، مگر با شبیه‌ساز (که کندتر است).

**نسل و سوکت**

| سازنده | سوکت‌های رایج | نکته |
|---|---|---|
| Intel | LGA1700، LGA1851 | هر دو نسل، سوکت عوض می‌شود |
| AMD | AM4، AM5 | AM4 طولانی‌ترین عمر را داشت |

**TDP — توان حرارتی**

**Thermal Design Power**: مقدار گرمایی که خنک‌کننده باید دفع کند.

| TDP | خنک‌کننده |
|---|---|
| ۳۵–۶۵W | خنک‌کنندهٔ همراه |
| ۶۵–۱۰۵W | خنک‌کنندهٔ برجی متوسط |
| ۱۰۵–۲۵۰W | خنک‌کنندهٔ بزرگ یا مایع |

### مثال‌های عملی

**سناریوی Lab: مقایسهٔ دو CPU**

| مشخصه | CPU A | CPU B |
|---|---|---|
| هسته/رشته | ۶/۱۲ | ۸/۸ |
| فرکانس پایه | ۳.۸ GHz | ۳.۲ GHz |
| کش L3 | ۳۲ MB | ۱۶ MB |
| TDP | ۶۵W | ۹۵W |
| نسل | جدید | قدیمی |

**تحلیل:**

- تک‌کاره: A سریع‌تر (فرکانس + معماری جدید).
- چندکاره: B ممکن است بهتر باشد (۸ هستهٔ فیزیکی).
- مصرف: A بهتر.

**نتیجه:** «کدام بهتر است؟» جواب واحد ندارد؛ به کاربرد بستگی دارد.

**سناریوی دوم: انتخاب CPU برای سه کاربر**

| کاربر | نیاز | انتخاب |
|---|---|---|
| کار اداری | ۴ هسته، GPU یکپارچه | ردهٔ اقتصادی |
| گیمر | ۶–۸ هسته، فرکانس بالا | ردهٔ متوسط/بالا |
| رندر ویدئو | ۱۲+ هسته | ردهٔ بالا (Ryzen 9 / i9) |

**سناریوی سوم: خنک‌کننده**

اگر CPU با TDP ۱۲۵W داری و خنک‌کنندهٔ ۶۵W بگذاری:

- دما بالا می‌رود.
- CPU **Throttling** می‌کند (فرکانس را کم می‌کند).
- عملکرد افت می‌کند و عمر کم می‌شود.

**قاعده:** ظرفیت خنک‌کننده ≥ TDP پردازنده.

### مقایسه و الگوهای مختلف

**Intel در برابر AMD**

| معیار | Intel | AMD |
|---|---|---|
| فرکانس تک‌هسته | معمولاً بالا | رقابتی |
| چند هسته | رقابتی | معمولاً بهتر در قیمت |
| عمر سوکت | کوتاه‌تر | طولانی‌تر (AM4) |
| GPU یکپارچه | رایج | در مدل‌های G |

**سه سطح CPU**

| سطح | مثال | کاربرد |
|---|---|---|
| اقتصادی | Core i3 / Ryzen 3 | اداری، وب |
| متوسط | Core i5 / Ryzen 5 | اکثر کاربران |
| بالا | Core i7/i9 / Ryzen 7/9 | گیم، رندر |

**الگوی «گلوگاه» (Bottleneck)**

اگر CPU ضعیف و GPU قوی باشد، GPU بیکار می‌ماند. برعکس هم صادق است. تعادل مهم‌تر از قدرت یکی است.

### اشکال شایع

**۱) مقایسهٔ فقط GHz**
معماری و هسته مهم‌ترند.

**۲) فرض «هستهٔ بیشتر همیشه بهتر»**
برای کار تک‌رشته‌ای (بعضی بازی‌ها)، فرکانس مهم‌تر است.

**۳) نادیده گرفتن TDP**
خنک‌کنندهٔ ناکافی = Throttling.

**۴) خرید CPU بدون چک کردن سوکت**
مادربرد ناسازگار.

**۵) فراموش کردن خمیر حرارتی**
بین CPU و خنک‌کننده، خمیر لازم است. بدون آن، دما بالا می‌رود.

**۶) فشار دادن زیاد هنگام نصب**
پین‌های سوکت خم می‌شوند.

**۷) نادیده گرفتن نسل**
CPU نسل قدیم روی مادربرد جدید کار نمی‌کند.

**۸) فرض «ARM جایگزین x86 شده»**
در دسکتاپ، x86 هنوز غالب است.

### نکات مهم (Tips & Tricks)

- **چرخهٔ Fetch-Decode-Execute** را حفظ کن.
- **هسته ≠ رشته.**
- **کش L1/L2/L3** را بشناس.
- **GHz تنها معیار نیست.**
- **TDP را با خنک‌کننده هماهنگ کن.**
- **خمیر حرارتی را فراموش نکن.**
- **تعادل CPU و GPU** مهم‌تر از قدرت یکی.

### خلاصه فصل

- CPU چهار مرحله را تکرار می‌کند: واکشی، رمزگشایی، اجرا، ذخیره.
- هسته واحد فیزیکی، رشته جریان اجرا.
- کش L1/L2/L3 سرعت دسترسی را تعیین می‌کند.
- فرکانس تنها معیار نیست؛ معماری و هسته مهم‌اند.
- TDP تعیین می‌کند چه خنک‌کننده‌ای لازم است.
- تعادل قطعات، از قدرت تک‌قطعه مهم‌تر است.

<a name="ch-16"></a>
## فصل ۱۶: RAM — حافظهٔ موقت

### مقدمه

RAM (Random Access Memory) حافظهٔ **موقت** کامپیوتر است. هر برنامه‌ای که باز می‌کنی، در RAM بار می‌شود. وقتی کامپیوتر خاموش می‌شود، RAM خالی می‌شود.

تشبیه کلاسیک: **RAM = میز کار، دیسک = کمد**. هر چه میز بزرگ‌تر، کار همزمان بیشتر — ولی با خاموش شدن چراغ، میز خالی می‌شود.

### مفاهیم اساسی

**RAM در برابر ذخیره‌سازی**

| معیار | RAM | دیسک |
|---|---|---|
| فرّار (Volatile) | ✅ با خاموشی پاک می‌شود | ❌ پایدار |
| سرعت | بسیار بالا (نانوثانیه) | کندتر (میکروثانیه) |
| ظرفیت | ۸–۱۲۸ GB | ۲۵۶ GB–۱۰ TB |
| قیمت به GB | بالا | کم |
| کار | نگه‌داشتن برنامهٔ در حال اجرا | نگه‌داشتن دائمی |

**چرا RAM لازم است؟**

CPU فقط می‌تواند از RAM بخواند (و کش). اگر داده روی دیسک باشد، اول باید به RAM منتقل شود. RAM کم = انتقال مکرر از دیسک = کندی.

**نسل‌های RAM**

| نسل | سال | سرعت | سازگاری |
|---|---|---|---|
| DDR3 | ۲۰۰۷ | ۸۰۰–۲۱۳۳ MT/s | قدیمی |
| DDR4 | ۲۰۱۴ | ۲۱۳۳–۳۲۰۰ | رایج |
| DDR5 | ۲۰۲۱ | ۴۸۰۰–۸۰۰۰+ | جدید |

**نکتهٔ حیاتی:** DDR4 و DDR5 با هم کار نمی‌کنند و اسلات‌هایشان متفاوت است. مادربرد فقط یک نسل را پشتیبانی می‌کند.

**فرم‌فاکتور**

| نوع | کاربرد |
|---|---|
| **DIMM** | دسکتاپ |
| **SO-DIMM** | لپ‌تاپ، Mini-PC |

**کانال (Channel)**

| حالت | توضیح | عملکرد |
|---|---|---|
| **Single Channel** | یک ماژول | پایه |
| **Dual Channel** | دو ماژول هم‌اندازه | ۱۰–۲۰٪ بهتر |
| **Quad Channel** | چهار ماژول | سرور |

**قاعده:** برای Dual Channel، ماژول‌ها را در اسلات‌های هم‌رنگ بگذار (معمولاً ۲ و ۴).

**پارامترهای RAM**

| پارامتر | معنی |
|---|---|
| **ظرفیت** | ۸، ۱۶، ۳۲ GB |
| **سرعت** | ۳۲۰۰، ۴۸۰۰ MT/s |
| **CAS Latency (CL)** | تأخیر (کمتر = بهتر) |
| **ولتاژ** | ۱.۲V (DDR4)، ۱.۱V (DDR5) |

**سرعت در برابر تأخیر**

```
DDR4-3200 CL16  →  تأخیر مؤثر ≈ ۱۰ نانوثانیه
DDR4-3600 CL18  →  تأخیر مؤثر ≈ ۱۰ نانوثانیه
```

سرعت بالاتر با CL بالاتر، ممکن است همان عملکرد را بدهد. برای اکثر کاربران، تفاوت محسوس نیست.

**ECC — حافظهٔ سرور**

| نوع | ویژگی |
|---|---|
| Non-ECC | استاندارد دسکتاپ |
| **ECC** | تصحیح خطای تک‌بیتی |

ECC در سرورها استاندارد است، چون یک خطای حافظه می‌تواند داده را خراب کند. در دسکتاپ معمولاً پشتیبانی نمی‌شود.

**RAM کافی چقدر است؟**

| کاربرد | حداقل | راحت |
|---|---|---|
| وب و اداری | ۴ GB | ۸ GB |
| چندکاره | ۸ GB | ۱۶ GB |
| گیم | ۱۶ GB | ۳۲ GB |
| رندر/ماشین مجازی | ۳۲ GB | ۶۴ GB+ |
| سرور | ۳۲ GB | ۱۲۸ GB+ |

**نشانه‌های کمبود RAM**

- کندی هنگام چند برنامهٔ باز.
- چراغ دیسک مدام روشن (Page File).
- پیام «Out of memory».
- برنامه‌ها ناگهان بسته می‌شوند.

**Page File / Swap**

وقتی RAM پر است، سیستم بخشی از داده را روی دیسک می‌نویسد. این کار **بسیار کندتر** از RAM است.

```
RAM:      ~۱۰۰ نانوثانیه
SSD:      ~۱۰۰ میکروثانیه  (۱۰۰۰ برابر کندتر)
HDD:      ~۱۰ میلی‌ثانیه    (۱۰۰٬۰۰۰ برابر کندتر)
```

### مثال‌های عملی

**سناریوی Lab: تشخیص کمبود RAM**

**موقعیت:** کاربر می‌گوید «وقتی ۱۰ تب مرورگر باز می‌کنم، کامپیوتر کند می‌شود.»

**گام ۱ — اندازه‌گیری**

Task Manager → Performance → Memory:

| شاخص | مقدار | تفسیر |
|---|---|---|
| In use | ۷.۲ GB از ۸ GB | ۹۰٪ |
| Available | ۰.۸ GB | کم |
| Committed | ۹.۵ GB | بیش از RAM → Page File |

**گام ۲ — نتیجه**

RAM کافی نیست. سیستم مجبور است از دیسک استفاده کند.

**گام ۳ — راه‌حل**

| راه‌حل | هزینه | اثر |
|---|---|---|
| بستن تب‌های اضافه | ۰ | موقت |
| ارتقا به ۱۶ GB | متوسط | پایدار |
| افزودن SSD (اگر HDD داری) | متوسط | Page File سریع‌تر |

**سناریوی دوم: ارتقای RAM — چک‌لیست**

```markdown
- [ ] مدل مادربرد را می‌دانم
- [ ] نسل RAM (DDR4/DDR5) را چک کردم
- [ ] تعداد اسلات‌های آزاد را دیدم
- [ ] حداکثر ظرفیت پشتیبانی‌شده را دیدم
- [ ] ماژول‌ها را جفت (۲ یا ۴) خریدم
- [ ] قبل از نصب، برق را قطع کردم
- [ ] ESD را تخلیه کردم
- [ ] بعد از نصب، در BIOS ظرفیت را دیدم
```

**سناریوی سوم: RAM در برابر سرعت**

دو سیستم:

| سیستم | RAM | CPU | نتیجه |
|---|---|---|---|
| A | ۸ GB DDR4 | i5 | کند در چندکاره |
| B | ۱۶ GB DDR4 | i3 | روان‌تر در چندکاره |

**درس:** برای کارهای روزمره، RAM بیشتر از CPU قوی‌تر کمک می‌کند.

### مقایسه و الگوهای مختلف

**سه نوع حافظه**

| نوع | فرّار | سرعت | کاربرد |
|---|---|---|---|
| **RAM** | ✅ | بسیار بالا | برنامهٔ در حال اجرا |
| **ROM** | ❌ | پایین | فریمور (BIOS) |
| **Flash** | ❌ | متوسط | SSD، USB، حافظهٔ گوشی |

**الگوی «RAM کافی، نه بیشتر»**

خرید ۶۴ GB برای کار اداری، هدر دادن پول است. نیاز را اندازه بگیر، بعد ارتقا بده.

### اشکال شایع

**۱) خرید DDR4 برای مادربرد DDR5**
جا نمی‌شود و کار نمی‌کند.

**۲) نصب در اسلات نامناسب**
Dual Channel فعال نمی‌شود. اسلات‌های هم‌رنگ را ببین.

**۳) ماژول‌های ناهم‌اندازه**
۸+۱۶ = ۲۴ GB، ولی بخشی در Single Channel کار می‌کند.

**۴) فرض «RAM بیشتر = سریع‌تر»**
اگر CPU گلوگاه باشد، RAM بیشتر کمکی نمی‌کند.

**۵) دست زدن به پین‌ها**
پین طلایی را با انگشت لمس نکن.

**۶) نادیده گرفتن حداکثر ظرفیت**
مادربرد قدیمی ممکن است بیش از ۱۶ GB پشتیبانی نکند.

**۷) قاطی کردن RAM و ذخیره‌سازی**
«۱۶ گیگابایت» در هر دو هست، ولی دو چیز متفاوت.

**۸) فراموش کردن BIOS**
بعد از نصب، باید ظرفیت جدید را در BIOS ببینی؛ اگر نه، درست جا نرفته.

### نکات مهم (Tips & Tricks)

- **RAM = میز کار، دیسک = کمد.**
- **DDR4 و DDR5 سازگار نیستند.**
- **Dual Channel = دو ماژول هم‌اندازه.**
- **ECC برای سرور.**
- **۸ GB حداقل امروز، ۱۶ GB راحت.**
- **Page File را از Task Manager ببین.**
- **پین طلایی را لمس نکن.**

### خلاصه فصل

- RAM حافظهٔ موقت و فرّار است؛ دیسک پایدار.
- DDR3/DDR4/DDR5 ناسازگارند.
- Dual Channel با دو ماژول هم‌اندازه فعال می‌شود.
- ECC برای سرور، Non-ECC برای دسکتاپ.
- کمبود RAM باعث Page File و کندی شدید می‌شود.
- ۱۶ GB برای اکثر کاربران امروز کافی است.

<a name="ch-17"></a>
## فصل ۱۷: ذخیره‌سازی — HDD، SSD، NVMe

### مقدمه

ذخیره‌سازی، جایی است که داده **می‌ماند**. سه فناوری اصلی داریم و تفاوتشان فقط سرعت نیست: دوام، صدا، مصرف برق و قیمت هم متفاوت است.

این فصل، انتخاب درست را ممکن می‌کند.

### مفاهیم اساسی

**فرّار در برابر غیرفرّار**

| نوع | با خاموشی | مثال |
|---|---|---|
| **فرّار (Volatile)** | پاک می‌شود | RAM |
| **غیرفرّار (Non-volatile)** | می‌ماند | HDD، SSD، فلش |

**HDD — هارد دیسک**

```
┌─────────────────────────┐
│  صفحهٔ مغناطیسی گردان   │ ← ۵۴۰۰ یا ۷۲۰۰ RPM
│  بازوی خواندن/نوشتن     │ ← حرکت مکانیکی
└─────────────────────────┘
```

| مشخصه | مقدار |
|---|---|
| سرعت | ۸۰–۱۶۰ MB/s |
| زمان دسترسی | ۵–۱۵ ms |
| ظرفیت | تا ۲۰+ TB |
| قیمت به TB | کمترین |
| صدا | دارد |
| مقاومت به ضربه | کم |

**SSD — درایو حالت جامد**

حافظهٔ فلش (NAND)، بدون قطعهٔ متحرک.

| مشخصه | مقدار |
|---|---|
| سرعت | ۵۰۰–۷٬۰۰۰ MB/s |
| زمان دسترسی | ۰.۱ ms |
| ظرفیت | تا ۸ TB |
| قیمت به TB | بیشتر |
| صدا | ندارد |
| مقاومت به ضربه | بالا |

**انواع SSD**

| نوع | اتصال | سرعت | کاربرد |
|---|---|---|---|
| **SATA 2.5"** | SATA | ~۵۵۰ MB/s | ارتقای لپ‌تاپ قدیمی |
| **M.2 SATA** | M.2 | ~۵۵۰ MB/s | — |
| **M.2 NVMe** | PCIe | ۲٬۰۰۰–۷٬۰۰۰+ MB/s | استاندارد امروز |

**نکتهٔ مهم:** M.2 فقط شکل است، نه پروتکل. M.2 می‌تواند SATA یا NVMe باشد. قبل از خرید، ببین مادربرد کدام را پشتیبانی می‌کند.

**نسل‌های PCIe و NVMe**

| نسل | سرعت هر خط | NVMe واقعی |
|---|---|---|
| PCIe 3.0 | ~۱ GB/s | ~۳٬۵۰۰ MB/s |
| PCIe 4.0 | ~۲ GB/s | ~۷٬۰۰۰ MB/s |
| PCIe 5.0 | ~۴ GB/s | ~۱۴٬۰۰۰ MB/s |

**توجه:** سرعت اسمی، در کار واقعی همیشه دیده نمی‌شود. برای فایل‌های کوچک، تفاوت کم است.

**RAID — ترکیب دیسک‌ها**

| سطح | توضیح | تحمل خرابی | ظرفیت قابل استفاده |
|---|---|---|---|
| **RAID 0** | Stripe (پخش) | ❌ | ۱۰۰٪ |
| **RAID 1** | Mirror (آینه) | ✅ یک دیسک | ۵۰٪ |
| **RAID 5** | Stripe + Parity | ✅ یک دیسک | (n−1)/n |
| **RAID 6** | دو Parity | ✅ دو دیسک | (n−2)/n |
| **RAID 10** | Mirror + Stripe | ✅ | ۵۰٪ |

**RAID پشتیبان نیست.** اگر فایل را پاک کنی، روی همهٔ دیسک‌ها پاک می‌شود. RAID فقط از **خرابی دیسک** محافظت می‌کند.

**ذخیره‌سازی شبکه‌ای**

| نوع | توضیح |
|---|---|
| **NAS** | فایل‌سرور متصل به شبکه |
| **SAN** | شبکهٔ اختصاصی ذخیره‌سازی (بلوکی) |
| **DAS** | دیسک مستقیم به سرور |

**ابر در برابر محلی**

| معیار | محلی | ابری |
|---|---|---|
| سرعت دسترسی | بالا | وابسته به اینترنت |
| هزینهٔ اولیه | بالا | کم |
| پشتیبان‌گیری | خودت | ارائه‌دهنده |
| کنترل | کامل | محدود |
| اشتراک | سخت | آسان |

### مثال‌های عملی

**سناریوی Lab: ارتقای لپ‌تاپ قدیمی**

**وضعیت:** لپ‌تاپ ۲۰۱۷ با HDD ۱TB، بوت ۹۰ ثانیه.

**گام ۱ — تشخیص**
Task Manager → Disk → ۱۰۰٪ Active Time در بوت. یعنی گلوگاه دیسک است.

**گام ۲ — انتخاب**
| گزینه | هزینه | نتیجه |
|---|---|---|
| SSD SATA 500GB | کم | بوت ۱۵ ثانیه |
| SSD NVMe (اگر پشتیبانی) | متوسط | بوت ۱۰ ثانیه |
| HDD جدید | کم | همان کندی |

**گام ۳ — مهاجرت**
- کلون کردن دیسک (با نرم‌افزار) یا نصب تازه.
- بعد از تعویض، HDD قدیمی را به‌عنوان دیسک دوم (با کدی) استفاده کن.

**گام ۴ — نتیجه**

| معیار | قبل | بعد |
|---|---|---|
| بوت | ۹۰s | ۱۵s |
| باز کردن مرورگر | ۱۲s | ۳s |
| صدا | دارد | ندارد |

**سناریوی دوم: انتخاب RAID**

| نیاز | RAID |
|---|---|
| سرعت، بدون اهمیت داده | 0 |
| دو دیسک، تحمل خرابی | 1 |
| چهار دیسک، تعادل | 5 یا 10 |
| حداکثر تحمل خرابی | 6 |

**هشدار:** RAID 0 با دو دیسک، احتمال خرابی را **دو برابر** می‌کند.

**سناریوی سوم: TBW و عمر SSD**

SSDها عمر نوشتن محدود دارند.

| مشخصه | معنی |
|---|---|
| **TBW** | Total Bytes Written — کل دادهٔ قابل نوشتن |
| **DWPD** | Drive Writes Per Day |

مثال: SSD با TBW ۶۰۰، اگر روزی ۵۰ GB بنویسی:

```
۶۰۰٬۰۰۰ GB ÷ ۵۰ GB = ۱۲٬۰۰۰ روز ≈ ۳۳ سال
```

برای کاربر معمولی، عمر SSD مسئله نیست. برای سرور با نوشتن سنگین، مهم است.

### مقایسه و الگوهای مختلف

**HDD در برابر SSD**

| معیار | HDD | SSD |
|---|---|---|
| سرعت | کم | بالا |
| قیمت به TB | کم | بالا |
| صدا | دارد | ندارد |
| ضربه | حساس | مقاوم |
| عمر | مکانیکی | محدود به نوشتن |
| مناسب برای | آرشیو، پشتیبان | سیستم‌عامل، برنامه |

**الگوی «SSD برای سیستم، HDD برای داده»**

```
SSD 500GB  → ویندوز + برنامه‌ها
HDD 2TB    → فیلم، آرشیو، پشتیبان محلی
```

این ترکیب، بهترین تعادل قیمت/عملکرد است.

**سه سطح ذخیره‌سازی**

| سطح | سرعت | ظرفیت | هزینه |
|---|---|---|---|
| کش (RAM) | فوق‌سریع | کم | بالا |
| SSD/NVMe | سریع | متوسط | متوسط |
| HDD/آرشیو | کند | بالا | کم |

### اشکال شایع

**۱) خرید M.2 SATA به‌جای NVMe**
جا می‌شود، ولی سرعت NVMe را نمی‌دهد.

**۲) فرض «RAID = پشتیبان»**
فایل حذف‌شده روی همهٔ دیسک‌ها حذف می‌شود.

**۳) پر کردن SSD تا ۱۰۰٪**
SSD به فضای آزاد برای مدیریت نیاز دارد. زیر ۱۰–۱۵٪ خالی نگه دار.

**۴) Defrag روی SSD**
بی‌فایده و مضر است. ویندوز خودش TRIM می‌زند.

**۵) نادیده گرفتن TBW**
برای سرور، SSD ارزان با TBW کم، زود می‌میرد.

**۶) RAID 0 برای دادهٔ مهم**
یک دیسک خراب = همه‌چیز رفته.

**۷) نادیده گرفتن پشتیبان**
RAID، پشتیبان نیست. فصل ۱۵ را ببین.

**۸) خرید HDD برای سیستم‌عامل امروز**
تجربهٔ کاربری بسیار بد.

### نکات مهم (Tips & Tricks)

- **SSD برای سیستم، HDD برای آرشیو.**
- **M.2 ≠ NVMe** — پروتکل را چک کن.
- **RAID پشتیبان نیست.**
- **SSD را پر نکن.**
- **Defrag روی SSD نزن.**
- **TBW را برای سرور ببین.**
- **RAID 0 ریسک را دو برابر می‌کند.**

### خلاصه فصل

- HDD مکانیکی و ارزان؛ SSD فلش و سریع.
- M.2 شکل است؛ SATA یا NVMe پروتکل.
- RAID از خرابی دیسک محافظت می‌کند، نه از حذف فایل.
- RAID 0 سرعت بدون تحمل خرابی؛ RAID 1 آینه.
- TBW عمر SSD را تعیین می‌کند.
- ترکیب SSD + HDD بهترین تعادل است.

<a name="ch-18"></a>
## فصل ۱۸: GPU، NIC و منبع تغذیه

### مقدمه

سه قطعهٔ باقی‌مانده، هر کدام یک مسئولیت مشخص دارند: GPU تصویر می‌سازد، NIC شبکه را وصل می‌کند، و PSU برق را تأمین می‌کند. نادیده گرفتن هر کدام، می‌تواند کل سیستم را از کار بیندازد.

### مفاهیم اساسی

**GPU — واحد پردازش گرافیک**

| نوع | محل | کاربرد |
|---|---|---|
| **یکپارچه (Integrated)** | داخل CPU | کار روزمره، ویدئو |
| **مجزا (Discrete)** | کارت PCIe | گیم، رندر، AI |

**چرا GPU برای گرافیک بهتر است؟**

CPU چند هستهٔ پیچیده دارد؛ GPU هزاران هستهٔ ساده. برای عملیات موازی (پیکسل‌ها)، GPU بسیار کارآمدتر است.

| معیار | CPU | GPU |
|---|---|---|
| هسته | ۴–۳۲ | ۱٬۰۰۰–۲۰٬۰۰۰ |
| کار | ترتیبی | موازی |
| حافظه | RAM | VRAM |
| مصرف | ۶۵–۲۵۰W | ۷۵–۴۵۰W |

**VRAM**

حافظهٔ اختصاصی کارت گرافیک.

| مقدار | مناسب برای |
|---|---|
| ۴ GB | کار روزمره، بازی سبک |
| ۸ GB | بازی ۱۰۸۰p |
| ۱۲–۱۶ GB | بازی ۱۴۴۰p/۴K، رندر |
| ۲۴ GB+ | AI، رندر حرفه‌ای |

**اتصال**

| اتصال | نکته |
|---|---|
| PCIe x16 | استاندارد کارت گرافیک |
| HDMI | تصویر + صدا |
| DisplayPort | تصویر با نرخ بالا |
| USB-C | تصویر + داده + برق |

**NIC — کارت شبکه**

**Network Interface Card**: اتصال به شبکه.

| نوع | سرعت | کاربرد |
|---|---|---|
| Ethernet 1GbE | ۱ Gbps | خانگی |
| Ethernet 2.5GbE | ۲.۵ Gbps | NAS، گیم |
| Ethernet 10GbE | ۱۰ Gbps | سرور |
| Wi-Fi | متغیر | بی‌سیم |

**MAC Address**

آدرس فیزیکی ۴۸ بیتی، مثل `00:1A:2B:3C:4D:5E`.

- ۲۴ بیت اول: سازنده (OUI)
- ۲۴ بیت دوم: شمارهٔ دستگاه

MAC **تغییرناپذیر** است (در حالت عادی)، ولی می‌تواند جعل شود (MAC spoofing).

**PSU — منبع تغذیه**

| مشخصه | معنی |
|---|---|
| **وات (W)** | توان کل |
| **کارایی 80 PLUS** | بازده تبدیل |
| **ماژولار** | کابل‌های جداشدنی |
| **اتصال‌ها** | ۲۴ پین، ۸ پین CPU، PCIe |

**سطح 80 PLUS**

| سطح | بازده |
|---|---|
| White | ۸۰٪ |
| Bronze | ۸۲٪ |
| Silver | ۸۵٪ |
| Gold | ۸۷٪ |
| Platinum | ۹۰٪ |
| Titanium | ۹۲٪ |

**محاسبهٔ توان**

```
CPU: ۱۲۵W
GPU: ۲۵۰W
مادربرد: ۵۰W
دیسک‌ها: ۲۰W
RAM: ۱۰W
فن‌ها: ۱۰W
────────────────
جمع: ~۴۶۵W
+ ۳۰٪ حاشیه = ~۶۰۰W
```

**قاعده:** PSU را ۲۰–۳۰٪ بیشتر از مصرف تخمینی بگیر.

### مثال‌های عملی

**سناریوی Lab: ساخت یک سیستم گیم**

| قطعه | انتخاب | دلیل |
|---|---|---|
| CPU | ۶ هسته، ۳.۸ GHz | تعادل |
| GPU | ۸ GB VRAM | ۱۰۸۰p |
| RAM | ۱۶ GB DDR4 | کافی |
| SSD | ۱TB NVMe | سرعت |
| PSU | ۶۵۰W Gold | حاشیهٔ ۳۰٪ |
| خنک‌کننده | برجی ۱۵۰W | > TDP |

**بررسی تعادل:**

- CPU و GPU هم‌سطح‌اند (بدون گلوگاه).
- PSU حاشیه دارد.
- خنک‌کننده کافی است.

**سناریوی دوم: عیب‌یابی «تصویر نمی‌آید»**

| گام | بررسی |
|---|---|
| ۱ | کابل به GPU وصل است یا مادربرد؟ |
| ۲ | GPU درست در اسلات نشسته؟ |
| ۳ | کابل برق PCIe وصل است؟ |
| ۴ | مانیتور روی ورودی درست است؟ |
| ۵ | در سیستم دیگر تست کن |

**نکتهٔ کلاسیک:** کابل مانیتور به مادربرد وصل است، ولی GPU مجزا نصب شده. مادربرد تصویر نمی‌دهد (چون GPU فعال است).

**سناریوی سوم: محاسبهٔ PSU**

```
i7-13700K: 125W (پیک 250W)
RTX 4070: 200W (پیک 250W)
بقیه: 80W
────────────────
پیک: ~580W
PSU پیشنهادی: 750W Gold
```

**هشدار:** PSU ارزان و بی‌کیفیت، می‌تواند کل سیستم را بسوزاند. این قطعه را ارزان نخر.

### مقایسه و الگوهای مختلف

**GPU یکپارچه در برابر مجزا**

| معیار | یکپارچه | مجزا |
|---|---|---|
| قیمت | در CPU | جدا |
| مصرف | کم | بالا |
| عملکرد | پایه | بالا |
| مناسب | اداری، ویدئو | گیم، رندر |

**سه سطح PSU**

| سطح | مناسب برای |
|---|---|
| ۴۵۰–۵۵۰W | سیستم اداری |
| ۶۵۰–۷۵۰W | گیم متوسط |
| ۸۵۰W+ | گیم بالا، رندر |

**الگوی «PSU با کیفیت، نه وات بالا»**

PSU ۵۵۰W Gold از PSU ۸۰۰W بی‌نام بهتر است. کیفیت اجزا، حفاظت‌ها (OVP/OCP) و گارانتی مهم‌اند.

### اشکال شایع

**۱) PSU کم‌توان**
خاموشی ناگهانی زیر بار، ری‌استارت، خرابی قطعات.

**۲) PSU بی‌کیفیت**
ولتاژ ناپایدار، ریسک آتش. فقط برند معتبر.

**۳) اتصال مانیتور به مادربرد با GPU مجزا**
تصویر نمی‌آید. به GPU وصل کن.

**۴) فراموش کردن کابل برق GPU**
کارت روشن می‌شود ولی تصویر نمی‌دهد یا کرش می‌کند.

**۵) نادیده گرفتن طول کارت گرافیک**
در کیس جا نمی‌شود.

**۶) فرض «VRAM بیشتر = سریع‌تر»**
معماری GPU مهم‌تر است.

**۷) استفاده از کابل HDMI ارزان برای ۴K**
ممکن است از ۳۰Hz بیشتر ندهد.

**۸) نادیده گرفتن جریان هوای کیس**
گرما، عملکرد را کم می‌کند.

### نکات مهم (Tips & Tricks)

- **GPU برای موازی، CPU برای ترتیبی.**
- **VRAM را با رزولوشن هماهنگ کن.**
- **MAC = آدرس فیزیکی، IP = منطقی.**
- **PSU با ۳۰٪ حاشیه.**
- **80 PLUS Gold** حداقل برای سیستم جدی.
- **کابل مانیتور به GPU.**
- **طول GPU را با کیس چک کن.**

### خلاصه فصل

- GPU هزاران هستهٔ ساده برای پردازش موازی دارد.
- VRAM برای گرافیک حیاتی است؛ ۸ GB حداقل امروز.
- NIC اتصال شبکه را فراهم می‌کند؛ MAC آدرس فیزیکی است.
- PSU باید ۲۰–۳۰٪ بیشتر از مصرف تخمینی باشد.
- کیفیت PSU از وات آن مهم‌تر است.
- تعادل قطعات، از قدرت تک‌قطعه مهم‌تر است.
