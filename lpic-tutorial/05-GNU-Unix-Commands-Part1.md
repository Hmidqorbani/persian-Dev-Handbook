## فصل ۲۰: کار در خط فرمان

### مقدمه

**خط فرمان (command line)** قدرتمندترین ابزار یک مدیر سیستم است. با آن می‌توانید هر کاری انجام دهید — سریع‌تر و دقیق‌تر از رابط گرافیکی. تصور کنید می‌خواهید ۱۰۰۰ فایل را تغییر نام دهید؛ با گرافیک ساعت‌ها طول می‌کشد، با خط فرمان در چند ثانیه.

در این فصل با اصول کار در ترمینال آشنا می‌شوید: ساختار دستورها، ناوبری، دریافت راهنما و میانبرهای مفید.

### مفاهیم اساسی

**ساختار یک دستور:**

```
command [options] [arguments]
```

مثال: `ls -l /home` → دستور `ls`، گزینهٔ `-l`، آرگومان `/home`.

**انواع گزینه‌ها:**

| نوع | مثال | توضیح |
|---|---|---|
| کوتاه | `-l` | یک حرف |
| بلند | `--long` | کلمهٔ کامل |
| ترکیبی | `-la` | چند کوتاه |
| با مقدار | `--color=auto` | با مساوی |

**مفاهیم کلیدی:**

- **Shell:** مفسری که دستورهای شما را اجرا می‌کند (معمولاً bash).
- **Prompt:** نشانهٔ آماده‌بودن (`$` برای کاربر عادی، `#` برای ریشه).
- **PATH:** متغیری که مسیرهای جستجوی دستورها را نگه می‌دارد.
- **Terminal:** برنامه‌ای که Shell را اجرا می‌کند.

**ساختار Prompt پیش‌فرض:**

```
user@hostname:~$
│    │        ││
│    │        │└── $ (کاربر عادی) یا # (ریشه)
│    │        └── پوشهٔ فعلی (~ = خانه)
│    └── نام میزبان
└── نام کاربر
```

**دستورهای ناوبری پایه:**

| دستور | کار |
|---|---|
| `pwd` | نمایش پوشهٔ فعلی |
| `cd` | تغییر پوشه |
| `ls` | فهرست محتوا |
| `man` | راهنمای دستور |

### مثال‌های عملی

**ناوبری:**

```bash
pwd                    # /home/user
cd /var/log            # رفتن به پوشه
cd ..                  # یک سطح بالا
cd ~                   # پوشهٔ خانه
cd -                   # پوشهٔ قبلی
cd                     # پوشهٔ خانه (بدون آرگومان)
cd /                   # ریشه
```

**فهرست کردن:**

```bash
ls                     # ساده
ls -l                  # جزئیات (long)
ls -a                  # شامل فایل‌های مخفی
ls -la                 # ترکیبی
ls -lh                 # حجم خوانا (human-readable)
ls -lt                 # مرتب‌سازی بر اساس زمان
ls -ltr                # زمان معکوس (قدیمی اول)
ls -R                  # بازگشتی
ls -d */               # فقط پوشه‌ها
ls -1                  # یک ستون
ls --color=auto        # رنگی
```

**راهنما:**

```bash
man ls                 # راهنمای کامل
ls --help              # راهنمای خلاصه
apropos copy           # جستجو در توضیحات دستورها
whatis ls              # توضیح یک‌خطی
info ls                # راهنمای info (جامع‌تر)
type ls                # نوع (alias/builtin/file)
which ls               # مسیر فایل اجرایی
whereis ls             # مسیر + man
```

**کار با تاریخچه:**

```bash
history                # تاریخچه
history 20             # ۲۰ دستور آخر
!!                     # آخرین دستور
!100                   # دستور شمارهٔ ۱۰۰
!ls                    # آخرین دستور شروع‌شده با ls
Ctrl+R                 # جستجوی تعاملی
```

### مقایسه و الگوهای مختلف

**راه‌های دریافت کمک:**

| ابزار | کاربرد | عمق |
|---|---|---|
| `man` | راهنمای رسمی | کامل |
| `--help` | خلاصهٔ سریع | کم |
| `apropos` | جستجو در توضیحات | — |
| `info` | راهنمای جامع (GNU) | کامل |
| `/usr/share/doc/` | مستندات پکیج | متغیر |
| `tldr` | مثال‌های عملی | مثال |

**مفاهیم man:** راهنماها در «فصل»های مختلف‌اند:

| فصل | محتوا | مثال |
|---|---|---|
| 1 | دستورهای کاربر | `man 1 passwd` |
| 2 | فراخوانی‌های سیستم | `man 2 open` |
| 3 | کتابخانه‌ها | `man 3 printf` |
| 5 | فرمت فایل‌ها | `man 5 passwd` |
| 7 | مفاهیم | `man 7 signal` |
| 8 | دستورهای مدیریتی | `man 8 mount` |

مثال: `man 5 passwd` (فرمت فایل) در برابر `man 1 passwd` (دستور).

**بخش‌های یک man page:**

```
NAME          ← نام و توضیح یک‌خطی
SYNOPSIS      ← نحوهٔ استفاده
DESCRIPTION   ← توضیح کامل
OPTIONS       ← گزینه‌ها
EXAMPLES      ← مثال‌ها
SEE ALSO      ← منابع مرتبط
```

### اشکال شایع

**اشکال ۱: حساس بودن به حروف بزرگ/کوچک.**
`ls` و `LS` متفاوتند. راه‌حل: به حروف دقت کنید.

**اشکال ۲: فراموش کردن فاصله.**
`ls-l` کار نمی‌کند؛ `ls -l` درست است. راه‌حل: فاصله بگذارید.

**اشکال ۳: گیج شدن با `..` و `.`.**
`.` پوشهٔ فعلی، `..` پوشهٔ والد. راه‌حل: به خاطر بسپارید.

**اشکال ۴: نبودن دستور در PATH.**
خطای «command not found» می‌گیرید. راه‌حل: `echo $PATH` را چک کنید.

**اشکال ۵: اشتباه در مسیر مطلق/نسبی.**
`/etc/passwd` (مطلق) در برابر `etc/passwd` (نسبی). راه‌حل: `/` اول = مطلق.

**اشکال ۶: نداشتن دسترسی.**
برخی دستورها نیاز به `sudo` دارند. راه‌حل: `sudo` بزنید.

### نکات مهم (Tips & Tricks)

- **با `Tab` خودکارسازی کنید** (تکمیل نام فایل/دستور).
- **با `Ctrl+R` در تاریخچهٔ دستورها جستجو کنید.**
- **`!!` آخرین دستور را تکرار می‌کند.**
- **`history` تاریخچهٔ دستورها را نشان می‌دهد.**
- **`clear` یا `Ctrl+L` صفحه را پاک می‌کند.**
- **`man -k <keyword>` معادل `apropos` است.**
- **`Ctrl+A` ابتدای خط، `Ctrl+E` انتهای خط.**
- **`Ctrl+U` پاک کردن خط، `Ctrl+W` پاک کردن کلمه.**
- **`Ctrl+D` خروج (EOF).**
- **`alias ll='ls -la'` میانبر می‌سازد.**
- **`command -v X` مسیر یا نوع X را نشان می‌دهد.**

### خلاصه فصل

خط فرمان با ساختار `command [options] [arguments]` کار می‌کند. `pwd`, `cd`, `ls` برای ناوبری و `man`, `--help`, `apropos` برای راهنما هستند. راهنماها در «فصل»های مختلف man قرار دارند (۱ دستور، ۵ فرمت، ۸ مدیریتی). به حساسیت حروف و فاصله‌ها دقت کنید. Tab و Ctrl+R کار را سریع‌تر می‌کنند و history برای تکرار مفید است.

## فصل ۲۱: پردازش جریان متن با فیلترها

### مقدمه

یکی از قوی‌ترین ویژگی‌های لینوکس، **پردازش متن** است. تصور کنید باید از یک فایل لاگ ۱۰۰٬۰۰۰ خطی، فقط خطوط خطا را استخراج کنید و بشمارید. با ابزارهای پردازش متن، در یک دستور انجام می‌شود.

ابزارهای زیادی وجود دارند که متن را می‌خوانند، تغییر می‌دهند و می‌نویسند. تسلط بر آن‌ها شما را بسیار کارآمد می‌کند و پایهٔ فصل ۲۶ (regex) است.

### مفاهیم اساسی

**فیلتر (Filter) چیست؟**

برنامه‌ای که ورودی می‌گیرد، تغییر می‌دهد و خروجی می‌دهد. فیلترها می‌توانند با لوله (`|`) ترکیب شوند.

**ابزارهای کلیدی:**

| دستور | کار | نمونه |
|---|---|---|
| `cat` | نمایش محتوای فایل | `cat file.txt` |
| `head` | نمایش ابتدای فایل | `head -5 file.txt` |
| `tail` | نمایش انتهای فایل | `tail -f log.txt` |
| `grep` | جستجوی الگو | `grep error file.txt` |
| `sort` | مرتب‌سازی | `sort -n nums.txt` |
| `uniq` | حذف خطوط تکراری | `sort x \| uniq` |
| `wc` | شمارش خطوط/کلمات | `wc -l file.txt` |
| `cut` | برش ستون‌ها | `cut -d: -f1 /etc/passwd` |
| `tr` | ترجمه/حذف کاراکترها | `tr 'a-z' 'A-Z'` |
| `sed` | ویرایش جریان متن | `sed 's/a/b/g'` |
| `awk` | پردازش قدرتمند ستونی | `awk '{print $1}'` |

### مثال‌های عملی

**نمایش فایل:**

```bash
cat file.txt
cat -n file.txt        # با شماره خط
cat file1 file2        # ادغام
cat > newfile.txt      # ساخت فایل (Ctrl+D برای پایان)

head -n 5 file.txt     # ۵ خط اول
head -c 100 file.txt   # ۱۰۰ بایت اول
tail -n 5 file.txt     # ۵ خط آخر
tail -f /var/log/syslog # دنبال کردن زنده
tail -f -n 20 log.txt  # ۲۰ خط آخر + دنبال کردن
```

**جستجو با grep:**

```bash
grep "error" file.txt
grep -i "error" file.txt    # بی‌توجه به حروف
grep -r "TODO" /project     # بازگشتی
grep -v "error" file.txt    # معکوس (خطوطی که تطبیق ندارند)
grep -c "error" file.txt    # شمارش
grep -n "error" file.txt    # با شماره خط
grep -l "error" *.txt       # فقط نام فایل‌ها
grep -w "cat" file.txt      # کلمهٔ کامل
grep -A3 "error" log.txt    # ۳ خط بعد
grep -B3 "error" log.txt    # ۳ خط قبل
grep -C3 "error" log.txt    # ۳ خط قبل و بعد
grep -E "err|warn" log.txt  # regex توسعه‌یافته
grep -o "error" file.txt    # فقط بخش تطبیق
```

**مرتب‌سازی و حذف تکراری:**

```bash
sort file.txt
sort -n numbers.txt         # عددی
sort -r file.txt            # نزولی
sort -k2 file.txt           # بر اساس ستون ۲
sort -t: -k3 -n /etc/passwd # جداکننده + ستون + عددی
sort -u file.txt            # یکتا (معادل sort | uniq)

sort file.txt | uniq
sort file.txt | uniq -c     # با شمارش
sort file.txt | uniq -d     # فقط تکراری‌ها
sort file.txt | uniq -u     # فقط یکتاها
```

**شمارش:**

```bash
wc -l file.txt              # تعداد خط
wc -w file.txt              # تعداد کلمه
wc -c file.txt              # تعداد بایت
wc file.txt                 # همه
```

**برش:**

```bash
cut -d: -f1 /etc/passwd     # ستون اول (جداکننده :)
cut -d: -f1,3 /etc/passwd   # ستون ۱ و ۳
cut -c1-10 file.txt         # کاراکتر ۱ تا ۱۰
```

**ترجمه:**

```bash
tr 'a-z' 'A-Z' < file.txt   # کوچک به بزرگ
tr -d '\n' < file.txt       # حذف newline
tr -s ' ' < file.txt        # فشرده‌سازی فاصله‌ها
```

### مقایسه و الگوهای مختلف

**`sed` و `awk` — دو ابزار قدرتمند:**

| ابزار | مناسب |
|---|---|
| `sed` | جایگزینی و ویرایش خطی |
| `awk` | پردازش ستونی و محاسبات |

**مثال sed:**

```bash
# جایگزینی اولین تطبیق در هر خط
sed 's/old/new/' file.txt

# جایگزینی همه
sed 's/old/new/g' file.txt

# حذف خطوط خالی
sed '/^$/d' file.txt

# حذف کامنت‌ها
sed '/^#/d' file.txt

# چاپ خطوط ۵ تا ۱۰
sed -n '5,10p' file.txt

# ویرایش درجا (احتیاط!)
sed -i 's/old/new/g' file.txt

# با پشتیبان
sed -i.bak 's/old/new/g' file.txt
```

**مثال awk:**

```bash
# چاپ ستون اول
awk '{print $1}' file.txt

# با جداکننده
awk -F: '{print $1, $3}' /etc/passwd

# شرط
awk '$3 > 1000 {print $1}' /etc/passwd

# محاسبه
awk '{sum += $1} END {print sum}' nums.txt

# با شماره خط
awk '{print NR, $0}' file.txt

# میانگین
awk '{sum += $1; n++} END {print sum/n}' nums.txt

# الگو
awk '/error/ {print}' log.txt
```

### اشکال شایع

**اشکال ۱: `uniq` بدون `sort`.**
`uniq` فقط خطوط تکراری **مجاور** را حذف می‌کند. راه‌حل: اول `sort`.

**اشکال ۲: الگوی grep بدون نقل‌قول.**
فاصله‌ها باعث خطا می‌شوند. راه‌حل: از `"..."` استفاده کنید.

**اشکال ۳: اشتباه گرفتن `>` با `>>`.**
`>` بازنویسی، `>>` افزودن. راه‌حل: به خاطر بسپارید.

**اشکال ۴: `tail -f` بدون `Ctrl+C`.**
ترمینال قفل می‌ماند. راه‌حل: `Ctrl+C` بزنید.

**اشکال ۵: `sed -i` بدون بکاپ.**
اگر اشتباه کنید، فایل خراب می‌شود. راه‌حل: `sed -i.bak`.

**اشکال ۶: اشتباه در جداکننده cut.**
جداکننده پیش‌فرض Tab است. راه‌حل: `-d` برای جداکنندهٔ دیگر.

### نکات مهم (Tips & Tricks)

- **`grep -E` برای عبارات باقاعدهٔ توسعه‌یافته.**
- **`grep -A3 -B3` سه خط بعد/قبل از تطبیق را نشان می‌دهد.**
- **`sort -u` معادل `sort | uniq`.**
- **`sed -i` ویرایش درجای فایل (احتیاط!).**
- **`awk` برای گزارش‌گیری عالی است.**
- **`cut -c1-10` برش بر اساس کاراکتر.**
- **`tr -s` فاصله‌های تکراری را فشرده می‌کند.**
- **`head`/`tail` را با `-n` و `-c` ترکیب کنید.**
- **`paste` دو فایل را کنار هم می‌گذارد.**
- **`column -t` خروجی را جدول‌بندی می‌کند.**
- **`rev` ترتیب کاراکترهای هر خط را معکوس می‌کند.**
- **`tac` فایل را برعکس (از آخر) چاپ می‌کند.**

### خلاصه فصل

ابزارهای پردازش متن قلب کار در لینوکس‌اند: `cat`, `head`, `tail`, `grep`, `sort`, `uniq`, `wc`, `cut`, `tr`, `sed`, `awk`. `grep` برای جستجو، `sed` برای ویرایش و `awk` برای پردازش ستونی به‌کار می‌روند. به تفاوت `>` و `>>` و نیاز `sort` قبل از `uniq` دقت کنید. این ابزارها با لوله ترکیب می‌شوند تا کارهای پیچیده را ساده کنند.

## فصل ۲۲: مدیریت پایهٔ فایل

### مقدمه

مدیریت فایل‌ها (ساخت، کپی، جابجایی، حذف) کار روزمرهٔ هر مدیر سیستم است. تصور کنید می‌خواهید ۱۰۰۰ فایل را به یک پوشه منتقل کنید یا یک پوشه را کامل بکاپ بگیرید. این فصل دستورهای پایه را یاد می‌دهد.

نکتهٔ حیاتی: `rm` بازیافت‌پذیر نیست! یک اشتباه می‌تواند داده‌های مهم را نابود کند. پس با احتیاط کار کنید.

### مفاهیم اساسی

**دستورهای پایه:**

| دستور | کار |
|---|---|
| `touch` | ساخت فایل خالی / تغییر زمان |
| `mkdir` | ساخت پوشه |
| `cp` | کپی |
| `mv` | جابجایی / تغییر نام |
| `rm` | حذف |
| `rmdir` | حذف پوشهٔ خالی |
| `file` | تشخیص نوع فایل |
| `stat` | اطلاعات کامل فایل |
| `ln` | ساخت لینک |

**گزینه‌های مهم:**

| گزینه | معنا | کاربرد |
|---|---|---|
| `-r` / `-R` | بازگشتی | پوشه‌ها |
| `-f` | اجباری | بدون پرسش |
| `-i` | تعاملی | با تأیید |
| `-v` | نمایش | نمایش عملیات |
| `-p` | نگه‌داشتن | مجوز و زمان |
| `-a` | آرشیوی | نگه‌داشتن همه |

### مثال‌های عملی

**ساخت:**

```bash
touch newfile.txt
touch file1 file2 file3    # چند فایل
mkdir mydir
mkdir -p a/b/c             # ساخت مسیر تودرتو
mkdir -m 700 private       # با مجوز
```

**کپی:**

```bash
cp file.txt backup.txt
cp -r mydir mydir-backup   # کپی پوشه (بازگشتی)
cp -p file.txt copy.txt    # نگه‌داشتن مجوزها و زمان
cp -a mydir mydir-copy     # آرشیوی (نگه‌داشتن همه)
cp -v file.txt /tmp/       # با نمایش
cp *.txt /backup/          # کپی همهٔ فایل‌های .txt
cp -u file.txt /backup/    # فقط اگر جدیدتر باشد
cp --parents src/a/b.txt /backup/   # نگه‌داشتن ساختار
```

**جابجایی و تغییر نام:**

```bash
mv file.txt /tmp/
mv oldname.txt newname.txt
mv -i file.txt /tmp/       # پرسش قبل از بازنویسی
mv -n file.txt /tmp/       # بدون بازنویسی
mv dir1 dir2               # اگر dir2 وجود داشته باشد، dir1 داخل آن می‌رود
mv *.log /var/log/archive/ # جابجایی گروهی
```

**حذف:**

```bash
rm file.txt
rm -i file.txt             # با تأیید
rm -v file.txt             # با نمایش
rm -r mydir                # بازگشتی
rm -rf mydir               # اجباری (احتیاط شدید!)
rmdir emptydir             # فقط پوشهٔ خالی
rm -rf /tmp/old/*          # محتوای پوشه
```

**اطلاعات فایل:**

```bash
file image.png             # نوع فایل
file *                     # نوع همهٔ فایل‌ها
stat file.txt              # اطلاعات کامل
ls -li file.txt            # inode
du -sh mydir               # حجم پوشه
```

**لینک (پیش‌نمایش فصل ۳۲):**

```bash
ln file.txt hardlink.txt   # لینک سخت
ln -s /path/to/target symlink  # لینک نمادین
```

### مقایسه و الگوهای مختلف

**گزینه‌های مهم هر دستور:**

| دستور | گزینه‌های کلیدی |
|---|---|
| `cp` | `-r`, `-p`, `-a`, `-u`, `-v` |
| `mv` | `-i`, `-n`, `-v`, `-u` |
| `rm` | `-r`, `-f`, `-i`, `-v` |
| `mkdir` | `-p`, `-m`, `-v` |

**`cp -a` در برابر `cp -r`:**

| ویژگی | `cp -a` | `cp -r` |
|---|---|---|
| مجوزها | حفظ | تغییر |
| زمان | حفظ | تغییر |
| لینک‌ها | حفظ | دنبال |
| مناسب بکاپ | بله | خیر |

**روش‌های ایمن حذف:**

| روش | امنیت |
|---|---|
| `rm -i` | بالا (پرسش) |
| `alias rm='rm -i'` | بالا |
| `trash-cli` | عالی (به سبد بازیافت) |
| `rm -rf` | خطرناک |

**هشدار:** `rm -rf` بسیار خطرناک است. هرگز `rm -rf /` یا `rm -rf *` را بی‌احتیاط اجرا نکنید. یک فاصلهٔ اشتباه (`rm -rf / tmp` به‌جای `rm -rf /tmp`) فاجعه می‌سازد.

### اشکال شایع

**اشکال ۱: `rm` بدون `-r` روی پوشه.**
خطا می‌دهد. راه‌حل: `-r` اضافه کنید.

**اشکال ۲: `cp` بدون `-r` روی پوشه.**
فقط خطا می‌دهد یا ناقص کپی می‌کند. راه‌حل: `-r` اضافه کنید.

**اشکال ۳: حذف اشتباهی.**
`rm` بازیافت‌پذیر نیست! راه‌حل: همیشه `-i` بگذارید.

**اشکال ۴: `mv` بین فایل‌سیستم‌ها.**
mv روی فایل‌سیستم‌های مختلف در واقع کپی+حذف است. راه‌حل: به زمان/فضا دقت کنید.

**اشکال ۵: فاصلهٔ اشتباه در `rm -rf`.**
`rm -rf / tmp` (با فاصله) کل `/` را پاک می‌کند! راه‌حل: دقت کنید.

**اشکال ۶: بازنویسی ناخواسته با `>` یا `cp`.**
داده از دست می‌رود. راه‌حل: از `-i` یا `-n` استفاده کنید.

### نکات مهم (Tips & Tricks)

- **قبل از `rm -rf`، مسیر را با `ls` بررسی کنید.**
- **`cp -a` بهترین گزینه برای بکاپ کامل است.**
- **`install` برای کپی با تعیین مجوز مفید است.**
- **`truncate -s 0 file` فایل را خالی می‌کند (بهتر از حذف).**
- **`rename` برای تغییر نام گروهی (در بعضی توزیع‌ها).**
- **از `alias rm='rm -i'` برای ایمنی استفاده کنید.**
- **`mkdir -p` مسیر تودرتو می‌سازد.**
- **`cp -u` فقط فایل‌های جدیدتر را کپی می‌کند.**
- **`rsync` جایگزین بهتر برای کپی‌های بزرگ است.**
- **`mv` برای تغییر نام سریع‌تر از cp+rm است.**
- **`stat` اطلاعات دقیق (inode، زمان‌ها) می‌دهد.**
- **`touch -t 202601011200 file` زمان دلخواه تنظیم می‌کند.**

### خلاصه فصل

دستورهای پایهٔ فایل: `touch`, `mkdir`, `cp`, `mv`, `rm`, `rmdir`, `file`, `stat`, `ln`. برای پوشه‌ها از `-r` استفاده کنید. `rm` بازیافت‌پذیر نیست — با `-i` ایمن بمانید و از `rm -rf` پرهیز کنید. `cp -a` برای بکاپ کامل مناسب است. گزینه‌های `-i`، `-n`، `-u` از بازنویسی ناخواسته جلوگیری می‌کنند. به فاصله‌ها دقت کنید تا فاجعه رخ ندهد.

## فصل ۲۳: جریان‌ها، لوله‌ها و تغییرمسیر

### مقدمه

**تغییرمسیر (redirection)** و **لوله (pipe)** به شما اجازه می‌دهند خروجی یک دستور را به ورودی دستور دیگر بدهید یا در فایل ذخیره کنید. این مفهوم، پایهٔ «فلسفهٔ یونیکس» است: برنامه‌های کوچک که با هم ترکیب می‌شوند تا کارهای بزرگ انجام دهند.

تصور کنید می‌خواهید ۵ فرآیند پر مصرف را پیدا کنید. با لوله، در یک دستور: `ps aux | sort -k3 -rn | head -5`. این قدرت ترکیب است.

### مفاهیم اساسی

**سه جریان استاندارد:**

| جریان | شماره | توضیح | پیش‌فرض |
|---|---|---|---|
| **stdin** | 0 | ورودی استاندارد | کیبورد |
| **stdout** | 1 | خروجی استاندارد | صفحه |
| **stderr** | 2 | خطای استاندارد | صفحه |

**عملگرهای تغییرمسیر:**

| عملگر | کار |
|---|---|
| `>` | بازنویسی stdout |
| `>>` | افزودن به stdout |
| `<` | ورودی از فایل |
| `2>` | تغییرمسیر stderr |
| `2>>` | افزودن stderr |
| `2>&1` | stderr به stdout |
| `&>` | هر دو (bash) |
| `\|` | لوله (stdout به stdin) |
| `\|&` | لوله با stderr |

**`/dev/null`:** «چاه سیاه» — هر چیزی که به آن بفرستید ناپدید می‌شود.

**`/dev/zero`:** منبع بی‌نهایت بایت صفر.

**`/dev/random`, `/dev/urandom`:** منبع تصادفی.

### مثال‌های عملی

**تغییرمسیر:**

```bash
ls > files.txt              # ذخیره در فایل
echo "line" >> files.txt    # افزودن
sort < unsorted.txt         # ورودی از فایل
ls /nonexistent 2> error.log # خطا به فایل
command > out.log 2>&1      # هر دو به یک فایل
command &> all.log          # هر دو (bash)
command 2> /dev/null        # دور ریختن خطا
command > /dev/null 2>&1    # دور ریختن همه
command >> out.log 2>&1     # افزودن هر دو
```

**لوله (pipe):**

```bash
ls -l | grep ".txt"
cat access.log | grep "404" | wc -l
ps aux | sort -k3 -rn | head -5    # ۵ پروسه پر مصرف CPU
df -h | grep -v tmpfs              # حذف tmpfs
history | grep ssh                 # جستجو در تاریخچه
find . -name "*.log" | xargs wc -l # شمارش خطوط
```

**`tee` — ذخیره و نمایش همزمان:**

```bash
ls -l | tee output.txt
command | tee -a log.txt     # افزودن
command 2>&1 | tee log.txt   # با خطاها
```

**تغییرمسیر پیشرفته:**

```bash
# اجرای دستور در پس‌زمینه با خروجی
command > out.log 2>&1 &

# ورودی از here-document
cat <<EOF > file.txt
line 1
line 2
EOF

# here-string
grep "x" <<< "text with x"

# ترکیب stdin و stdout
command < input.txt > output.txt
```

**xargs:**

```bash
find . -name "*.tmp" | xargs rm
find . -name "*.log" | xargs -I {} cp {} /backup/
echo "a b c" | xargs -n1 echo       # هر کلمه یک خط
ls *.txt | xargs -I {} mv {} {}.bak
```

### مقایسه و الگوهای مختلف

**روش‌های ذخیره و نمایش:**

| هدف | روش |
|---|---|
| فقط ذخیره | `cmd > file` |
| ذخیره + نمایش | `cmd \| tee file` |
| فقط خطا | `cmd 2> err.log` |
| دور ریختن خطا | `cmd 2> /dev/null` |
| دور ریختن همه | `cmd &> /dev/null` |
| ذخیره خطا و خروجی | `cmd > file 2>&1` |

**ترتیب `2>&1`:**

```bash
# درست: خطا به همان‌جای خروجی می‌رود
command > file 2>&1

# اشتباه: خطا روی صفحه می‌ماند
command 2>&1 > file
```

**تغییرمسیر در برابر لوله:**

| ویژگی | تغییرمسیر | لوله |
|---|---|---|
| مقصد | فایل | دستور دیگر |
| نماد | `>`, `<` | `\|` |
| کاربرد | ذخیره | زنجیرهٔ پردازش |

**جایگزینی دستور:**

| نماد | کار |
|---|---|
| `$(cmd)` | خروجی دستور (توصیه‌شده) |
| `` `cmd` `` | خروجی دستور (قدیمی) |
| `<(cmd)` | فایل موقت ورودی |
| `>(cmd)` | فایل موقت خروجی |

### اشکال شایع

**اشکال ۱: `>` به‌جای `>>`.**
فایل قبلی پاک می‌شود! راه‌حل: برای افزودن `>>`.

**اشکال ۲: فراموش کردن `2>&1`.**
خطاها هنوز روی صفحه می‌آیند. راه‌حل: `2>&1` اضافه کنید.

**اشکال ۳: ترتیب اشتباه در `2>&1`.**
باید بعد از `>` بیاید: `> file 2>&1`. راه‌حل: ترتیب درست.

**اشکال ۴: لوله روی دستوری که از stdin نمی‌خواند.**
بی‌اثر است. راه‌حل: دستور باید stdin بپذیرد.

**اشکال ۵: خالی شدن فایل با `>` قبل از خواندن.**
`cat file > file` فایل را خالی می‌کند! راه‌حل: از فایل موقت یا `tee` استفاده کنید.

**اشکال ۶: نبود xargs برای آرگومان‌های زیاد.**
بعضی دستورها سقف آرگومان دارند. راه‌حل: `xargs` استفاده کنید.

### نکات مهم (Tips & Tricks)

- **`cmd 2>&1 | tee log` هم ذخیره می‌کند هم خطاها را می‌گیرد.**
- **`/dev/null` برای خفه‌کردن خروجی‌های مزاحم.**
- **`xargs` خروجی را به آرگومان تبدیل می‌کند:** `find . -name "*.log" | xargs rm`.
- **`$(...)` جایگزینی دستور:** `echo "Today: $(date)"`.
- **لوله‌ها را زنجیره کنید تا کارهای پیچیده انجام دهید.**
- **`tee -a` افزودن (نه بازنویسی).**
- **`process substitution` (`<(cmd)`) برای فایل موقت ورودی.**
- **`2>&1` را همیشه بعد از `>` بگذارید.**
- **`xargs -P` اجرای موازی:** `xargs -P4`.
- **`|&` (bash) معادل `2>&1 |` است.**
- **`/dev/tcp/host/port` (bash) برای تست شبکه.**
- **`<<` here-document برای ورودی چندخطی.**

### خلاصه فصل

سه جریان استاندارد (stdin=0، stdout=1، stderr=2) پایهٔ تغییرمسیر و لوله‌اند. `>` بازنویسی، `>>` افزودن، `2>` خطا، `2>&1` ادغام و `|` لوله است. `tee` همزمان ذخیره و نمایش می‌کند و `/dev/null` خروجی را دور می‌ریزد. `xargs` خروجی را به آرگومان تبدیل می‌کند و `$(...)` جایگزینی دستور است. ترکیب دستورها با لوله، فلسفهٔ یونیکس است.
