## فصل ۳۵: سفارشی‌سازی محیط شل

### مقدمه

**شل (Shell)** برنامه‌ای است که دستورهای شما را می‌گیرد و اجرا می‌کند. **bash** رایج‌ترین شل لینوکس است. تصور کنید هر بار باید مسیر طولانی را تایپ کنید یا دستورهای تکراری بزنید — با سفارشی‌سازی، این کارها خودکار می‌شوند.

در این فصل یاد می‌گیرید چطور محیط شل را سفارشی کنید: alias، متغیرها، prompt و فایل‌های پیکربندی.

### مفاهیم اساسی

**شل‌های رایج:**

| شل | مسیر | ویژگی |
|---|---|---|
| **bash** | `/bin/bash` | پیش‌فرض اکثر توزیع‌ها |
| **sh** | `/bin/sh` | استاندارد POSIX |
| **zsh** | `/bin/zsh` | پیشرفته، محبوب |
| **dash** | `/bin/dash` | سبک (Debian) |
| **fish** | `/usr/bin/fish` | دوستانه |
| **ksh** | `/bin/ksh` | Korn shell |

**متغیرهای محیطی:** متغیرهایی که رفتار شل و برنامه‌ها را تعیین می‌کنند:

| متغیر | کار |
|---|---|
| `PATH` | مسیرهای جستجوی دستورها |
| `HOME` | پوشهٔ خانه |
| `PS1` | متن prompt |
| `EDITOR` | ویرایشگر پیش‌فرض |
| `LANG` | زبان/لوکال |
| `HISTSIZE` | اندازهٔ تاریخچه |
| `PWD` | پوشهٔ فعلی |
| `SHELL` | شل فعلی |
| `USER` | نام کاربر |

**فایل‌های پیکربندی:**

| فایل | زمان بارگذاری |
|---|---|
| `/etc/profile` | همهٔ کاربران (login) |
| `/etc/bash.bashrc` | همهٔ کاربران (interactive) |
| `/etc/profile.d/` | اسکریپت‌های اضافی |
| `~/.bash_profile` | کاربر (login) |
| `~/.bashrc` | کاربر (interactive) |
| `~/.bash_login` | کاربر (login) |
| `~/.profile` | کاربر (login) |
| `~/.bash_logout` | هنگام خروج |

### مثال‌های عملی

**متغیرها:**

```bash
# تعریف متغیر
MYVAR="hello"
echo $MYVAR
echo ${MYVAR}          # با براکت (بهتر)

# export برای دسترسی فرزندان
export MYVAR="hello"

# متغیر محیطی
echo $PATH
export PATH="$PATH:/opt/myapp/bin"

# حذف
unset MYVAR

# متغیر فقط‌خواندنی
readonly PI=3.14

# متغیر با مقدار پیش‌فرض
echo ${MYVAR:-default}

# طول متغیر
echo ${#MYVAR}
```

**سفارشی‌سازی `~/.bashrc`:**

```bash
# alias
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'
alias ..='cd ..'
alias ...='cd ../..'
alias grep='grep --color=auto'
alias rm='rm -i'

# prompt سفارشی (با رنگ)
PS1='\[\e[32m\]\u@\h\[\e[0m\]:\[\e[34m\]\w\[\e[0m\]\$ '

# متغیر
export EDITOR=vim
export HISTSIZE=1000
export HISTFILESIZE=2000
export HISTCONTROL=ignoredups:erasedups

# PATH
export PATH="$HOME/bin:$PATH"

# تابع
mkcd() { mkdir -p "$1" && cd "$1"; }
```

**اعمال تغییرات:**

```bash
source ~/.bashrc      # یا: . ~/.bashrc
# یا باز کردن ترمینال جدید
```

**تاریخچه:**

```bash
history
history -c            # پاک کردن
history -w            # نوشتن در فایل
history | grep ssh
# Ctrl+R جستجوی تعاملی
```

### مقایسه و الگوهای مختلف

**فایل‌های startup:**

| نوع جلسه | فایل‌های خوانده‌شده |
|---|---|
| **Login shell** | `/etc/profile` → `~/.bash_profile` → `~/.bash_login` → `~/.profile` |
| **Interactive non-login** | `~/.bashrc` |

**توصیه:** تنظیمات را در `~/.bashrc` بگذارید و `~/.bash_profile` آن را source کند:

```bash
# در ~/.bash_profile
if [ -f ~/.bashrc ]; then
  . ~/.bashrc
fi
```

**انواع prompt:**

| کد | معنا |
|---|---|
| `\u` | نام کاربر |
| `\h` | نام میزبان |
| `\w` | مسیر کامل |
| `\W` | نام پوشه |
| `\d` | تاریخ |
| `\t` | ساعت |
| `\$` | $ یا # |
| `\e[...m` | رنگ |

**شل در برابر متغیر محیطی:**

| نوع | دامنه |
|---|---|
| متغیر شل | فقط همین شل |
| متغیر محیطی | شل + فرزندان |

### اشکال شایع

**اشکال ۱: نبود `export`.**
متغیر در فرزندان دیده نمی‌شود. راه‌حل: `export`.

**اشکال ۲: فاصله اطراف `=`.**
`MYVAR = "x"` غلط است؛ `MYVAR="x"` درست. راه‌حل: بدون فاصله.

**اشکال ۳: تک‌کوتیشن در برابر دابل‌کوتیشن.**
`'$VAR'` متغیر را expand نمی‌کند؛ `"$VAR"` می‌کند. راه‌حل: `"..."` برای expand.

**اشکال ۴: ویرایش `~/.bash_profile` به‌جای `~/.bashrc`.**
برای جلسات غیر-login اعمال نمی‌شود. راه‌حل: `~/.bashrc`.

**اشکال ۵: خطای syntax در bashrc.**
شل باز نمی‌شود. راه‌حل: با `bash --noprofile --norc` وارد شوید و اصلاح کنید.

**اشکال ۶: فراموش کردن `source`.**
تغییرات اعمال نمی‌شود. راه‌حل: `source ~/.bashrc`.

### نکات مهم (Tips & Tricks)

- **`alias` برای میانبرها؛ `unalias` برای حذف.**
- **`env` همهٔ متغیرهای محیطی را نشان می‌دهد.**
- **`set -o` گزینه‌های شل را نشان می‌دهد.**
- **`history -c` تاریخچه را پاک می‌کند.**
- **برای رنگ‌بندی prompt از `\e[...m` استفاده کنید.**
- **`export PROMPT_COMMAND` برای اجرای دستور قبل از هر prompt.**
- **`HISTCONTROL=ignoreboth` خطوط تکراری و فاصله‌دار را حذف می‌کند.**
- **`shopt -s histappend` تاریخچه را append می‌کند.**
- **`bind` برای تغییر کلیدها.**
- **`complete` برای تکمیل سفارشی.**
- **`/etc/profile.d/` برای تنظیمات سیستمی.**
- **`type X` نوع دستور (alias/function/builtin) را نشان می‌دهد.**

### خلاصه فصل

شل bash رایج‌ترین است و از فایل‌های پیکربندی (`/etc/profile`, `~/.bashrc` و...) استفاده می‌کند. متغیرهای محیطی مثل `PATH` و `PS1` رفتار را کنترل می‌کنند. با `export` متغیر را به فرزندان بدهید، با `alias` میانبر بسازید و با `source` تغییرات را اعمال کنید. تنظیمات را در `~/.bashrc` بگذارید و `~/.bash_profile` آن را source کند. تک‌کوتیشن متغیر را expand نمی‌کند.

## فصل ۳۶: نوشتن اسکریپت‌های ساده

### مقدمه

**اسکریپت شل** برنامه‌ای است که مجموعه‌ای از دستورها را خودکار اجرا می‌کند. تصور کنید هر روز باید ۱۰ کار تکراری انجام دهید — با یک اسکریپت، همه در یک دستور. اسکریپت‌نویسی قدرتمندترین ابزار خودکارسازی در لینوکس است.

در این فصل، از یک اسکریپت ساده تا مفاهیم متوسط (شرط، حلقه، تابع) را یاد می‌گیرید.

### مفاهیم اساسی

**ساختار یک اسکریپت:**

```bash
#!/bin/bash
# این یک کامنت است

echo "سلام دنیا"
```

**نکات کلیدی:**

- **shebang:** خط اول `#!/bin/bash` مفسر را تعیین می‌کند.
- **مجوز اجرا:** `chmod +x script.sh`.
- **کامنت:** با `#`.
- **اجرا:** `./script.sh` یا `bash script.sh`.

**متغیرهای ویژه:**

| متغیر | معنا |
|---|---|
| `$0` | نام اسکریپت |
| `$1`–`$9` | آرگومان‌ها |
| `$#` | تعداد آرگومان‌ها |
| `$@` | همهٔ آرگومان‌ها (جدا) |
| `$*` | همهٔ آرگومان‌ها (یک رشته) |
| `$?` | کد خروج آخرین دستور |
| `$$` | PID اسکریپت |
| `$!` | PID آخرین فرآیند پس‌زمینه |

### مثال‌های عملی

**اسکریپت پایه:**

```bash
#!/bin/bash
# greeting.sh — نمایش خوش‌آمد

NAME="${1:-کاربر}"
echo "سلام $NAME!"
echo "تاریخ: $(date)"
```

**اجرا:**

```bash
chmod +x greeting.sh
./greeting.sh
./greeting.sh علی
```

**متغیرها و ورودی:**

```bash
#!/bin/bash
# variables.sh

# آرگومان‌ها
echo "نام اسکریپت: $0"
echo "آرگومان اول: $1"
echo "تعداد آرگومان: $#"
echo "همهٔ آرگومان‌ها: $@"

# ورودی کاربر
read -p "نام خود را وارد کنید: " name
echo "سلام $name"

# با timeout
read -t 5 -p "سریع! " answer
```

**شرط:**

```bash
#!/bin/bash
# condition.sh

if [ -f "$1" ]; then
  echo "فایل وجود دارد"
elif [ -d "$1" ]; then
  echo "پوشه است"
else
  echo "چیزی پیدا نشد"
fi

# با [[ ]] (bash)
if [[ "$1" == *.txt ]]; then
  echo "فایل متنی"
fi
```

**حلقه:**

```bash
#!/bin/bash
# loop.sh

# for روی لیست
for fruit in سیب پرتقال موز; do
  echo "میوه: $fruit"
done

# for عددی
for i in {1..5}; do
  echo "شماره: $i"
done

# for با گام
for i in {0..10..2}; do
  echo "زوج: $i"
done

# while
count=1
while [ $count -le 5 ]; do
  echo "count = $count"
  ((count++))
done

# until
n=1
until [ $n -gt 5 ]; do
  echo "n = $n"
  ((n++))
done

# روی خطوط فایل
while IFS= read -r line; do
  echo "خط: $line"
done < file.txt
```

**تابع:**

```bash
#!/bin/bash
# function.sh

greet() {
  local name="$1"
  echo "سلام $name"
}

greet "علی"
greet "مریم"

# تابع با بازگشت مقدار
add() {
  echo $(($1 + $2))
}
result=$(add 3 5)
echo "نتیجه: $result"
```

**case:**

```bash
#!/bin/bash
case "$1" in
  start)
    echo "شروع..."
    ;;
  stop)
    echo "توقف..."
    ;;
  restart)
    echo "ری‌استارت..."
    ;;
  *)
    echo "استفاده: $0 {start|stop|restart}"
    exit 1
    ;;
esac
```

### اشکال شایع

**اشکال ۱: فراموش کردن shebang.**
اسکریپت با شل اشتباه اجرا می‌شود. راه‌حل: `#!/bin/bash`.

**اشکال ۲: فراموش کردن `chmod +x`.**
خطای «Permission denied». راه‌حل: `chmod +x`.

**اشکال ۳: نبود فاصله در `[ ]`.**
`[$x -eq 1]` غلط است؛ `[ $x -eq 1 ]` درست. راه‌حل: فاصله.

**اشکال ۴: کوتیشن نگذاشتن دور متغیرها.**
فاصله‌ها باعث خطا می‌شوند؛ `"$var"`. راه‌حل: کوتیشن.

**اشکال ۵: `=` در برابر `==`.**
در `[ ]` از `=`، در `[[ ]]` هر دو. راه‌حل: آگاه باشید.

**اشکال ۶: بررسی نکردن `$?`.**
خطاها نادیده می‌مانند. راه‌حل: `if [ $? -ne 0 ]`.

### نکات مهم (Tips & Tricks)

- **`set -e` اسکریپت را در اولین خطا متوقف می‌کند.**
- **`set -u` استفاده از متغیر تعریف‌نشده را خطا می‌کند.**
- **`set -x` دستورها را برای دیباگ چاپ می‌کند.**
- **`$(command)` خروجی دستور را جایگزین می‌کند.**
- **`(( ))` برای محاسبات حسابی.**
- **همیشه متغیرها را در `"..."` بگذارید.**
- **`local` در توابع برای متغیر محلی.**
- **`return` در تابع کد خروج می‌دهد.**
- **`trap` برای پاک‌سازی در خروج.**
- **`getopts` برای پردازش آرگومان‌های گزینه‌دار.**
- **`mktemp` برای فایل موقت امن.**
- **`readonly` برای ثابت‌ها.**

### خلاصه فصل

اسکریپت شل با shebang شروع می‌شود و دستورها را خودکار اجرا می‌کند. متغیرها (`$1`, `$@`, `read`)، شرط (`if [ ]`)، حلقه (`for`, `while`, `until`)، تابع و `case` پایهٔ اسکریپت‌نویسی‌اند. `set -e/-u/-x` برای ایمنی و دیباگ مفیدند. متغیرها را همیشه در کوتیشن بگذارید. `[[ ]]` قوی‌تر از `[ ]` است. `trap` و `getopts` ابزارهای حرفه‌ای‌اند.

## فصل ۳۷: آزمایشگاه: اسکریپت‌نویسی حرفه‌ای و عیب‌یابی

### مقدمه

در این آزمایشگاه یک اسکریپت واقعی و کاربردی می‌سازیم: یک اسکریپت بکاپ که مفاهیم قبلی را ترکیب می‌کند. هدف: یادگیری نوشتن اسکریپت‌های حرفه‌ای با مدیریت خطا و لاگ.

### مفاهیم اساسی

هدف: ساخت اسکریپت `backup.sh` که:
1. آرگومان‌ها را بررسی کند.
2. پوشهٔ مقصد را بسازد.
3. بکاپ فشرده بگیرد.
4. لاگ بنویسد.
5. خطاها را مدیریت کند.
6. بکاپ‌های قدیمی را پاک کند.

### مثال‌های عملی

**اسکریپت بکاپ کامل:**

```bash
#!/bin/bash
# backup.sh — بکاپ فشرده از یک پوشه
set -euo pipefail

# رنگ‌ها
RED='\033[0;31m'
GREEN='\033[0;32m'
NC='\033[0m'

# بررسی آرگومان
if [ $# -lt 1 ]; then
  echo -e "${RED}استفاده: $0 <source_dir> [dest_dir]${NC}"
  exit 1
fi

SOURCE="$1"
DEST="${2:-/backup}"
STAMP=$(date +%Y%m%d_%H%M%S)
LOG="$DEST/backup.log"

# بررسی وجود منبع
if [ ! -d "$SOURCE" ]; then
  echo "خطا: پوشهٔ منبع وجود ندارد: $SOURCE" >&2
  exit 2
fi

# ساخت مقصد
mkdir -p "$DEST"

# تابع لاگ
log() {
  echo "[$(date '+%Y-%m-%d %H:%M:%S')] $*" | tee -a "$LOG"
}

log "شروع بکاپ از $SOURCE"

# بکاپ
ARCHIVE="$DEST/backup_${STAMP}.tar.gz"
if tar -czf "$ARCHIVE" -C "$(dirname "$SOURCE")" "$(basename "$SOURCE")"; then
  SIZE=$(du -h "$ARCHIVE" | cut -f1)
  log "بکاپ موفق: $ARCHIVE ($SIZE)"
else
  log "خطا در بکاپ!"
  exit 3
fi

# پاک‌سازی بکاپ‌های قدیمی‌تر از ۷ روز
find "$DEST" -name "backup_*.tar.gz" -mtime +7 -delete
log "پاک‌سازی بکاپ‌های قدیمی انجام شد"

log "پایان"
exit 0
```

**اجرا و تست:**

```bash
chmod +x backup.sh
sudo ./backup.sh /etc /tmp/backup-test
ls -lh /tmp/backup-test
cat /tmp/backup-test/backup.log
```

**دیباگ اسکریپت:**

```bash
# اجرای trace
bash -x backup.sh /etc

# بررسی syntax بدون اجرا
bash -n backup.sh

# shellcheck (نصب جداگانه)
shellcheck backup.sh
```

**اسکریپت با trap:**

```bash
#!/bin/bash
set -euo pipefail

TMPFILE=$(mktemp)

cleanup() {
  echo "پاک‌سازی..."
  rm -f "$TMPFILE"
}
trap cleanup EXIT

# کار با فایل موقت
echo "data" > "$TMPFILE"
```

**اسکریپت با getopts:**

```bash
#!/bin/bash
VERBOSE=0
OUTPUT=""

while getopts "vo:h" opt; do
  case $opt in
    v) VERBOSE=1 ;;
    o) OUTPUT="$OPTARG" ;;
    h) echo "استفاده: $0 [-v] [-o output]"; exit 0 ;;
    *) exit 1 ;;
  esac
done

[ "$VERBOSE" -eq 1 ] && echo "حالت verbose"
echo "خروجی: $OUTPUT"
```

**سطوح خطا:**

| کد خروج | معنا |
|---|---|
| 0 | موفق |

| 2 | استفادهٔ نادرست |
| 126 | غیرقابل اجرا |

| 128+N | خاتمه با سیگنال N |

**`set` options:**

| گزینه | اثر |
|---|---|
| `-e` | توقف در خطا |
| `-u` | خطا در متغیر تعریف‌نشده |
| `-x` | چاپ دستورها (دیباگ) |
| `-o pipefail` | خطای لوله را تشخیص می‌دهد |
| `-n` | بررسی syntax بدون اجرا |

**ابزارهای کیفیت:**

| ابزار | کار |
|---|---|
| `shellcheck` | تحلیل استاتیک |
| `bash -n` | بررسی syntax |
| `bash -x` | trace |
| `shfmt` | قالب‌بندی |

### اشکال شایع

**اشکال ۱: نبود بررسی آرگومان.**
اسکریپت با ورودی خالی خطا می‌دهد. راه‌حل: بررسی `$#`.

**اشکال ۲: مسیرهای نسبی.**
از مسیر مطلق استفاده کنید یا `cd` درست بزنید. راه‌حل: مسیر مطلق.

**اشکال ۳: نادیده گرفتن کد خروج.**
همیشه `$?` را بررسی کنید. راه‌حل: `if`/`set -e`.

**اشکال ۴: لاگ نکردن.**
برای دیباگ، لاگ ضروری است. راه‌حل: تابع log.

**اشکال ۵: نبود `set -euo pipefail`.**
خطاها نادیده می‌مانند. راه‌حل: در ابتدای اسکریپت.

**اشکال ۶: فراموش کردن trap.**
فایل‌های موقت باقی می‌مانند. راه‌حل: `trap cleanup EXIT`.

### نکات مهم (Tips & Tricks)

- **`shellcheck` ابزار عالی برای پیدا کردن باگ‌های اسکریپت است.**
- **`trap 'cleanup' EXIT` برای پاک‌سازی در خروج.**
- **`mktemp` برای فایل‌های موقت امن.**
- **از توابع برای جلوگیری از تکرار استفاده کنید.**
- **همیشه shebang و `set -euo pipefail` بگذارید.**
- **اسکریپت را با کاربر کم‌دسترسی تست کنید.**
- **`set -x` را برای دیباگ موقت فعال کنید.**
- **`readonly` برای متغیرهای ثابت.**
- **رنگ‌ها را برای خروجی خوانا استفاده کنید.**
- **`exit N` کد خروج مشخص می‌دهد.**
- **`getopts` برای آرگومان‌های استاندارد.**
- **اسکریپت‌ها را در `/usr/local/bin/` بگذارید تا در PATH باشند.**

### خلاصه فصل

در این آزمایشگاه یک اسکریپت بکاپ واقعی ساختیم که آرگومان‌ها را بررسی، پوشهٔ مقصد را می‌سازد، بکاپ فشرده می‌گیرد، لاگ می‌نویسد و خطاها را مدیریت می‌کند. `set -euo pipefail`، توابع، `trap`، `getopts` و `shellcheck` ابزارهای حرفه‌ای‌اند. همیشه کد خروج و لاگ را جدی بگیرید. اسکریپت را با کاربر کم‌دسترسی تست کنید.
